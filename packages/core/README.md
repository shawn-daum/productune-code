# @productune/core

Core for productune v1 (prdt) — persona agent thin-pointers, discipline SoT, the `prdt` CLI, hooks, and the TypeScript layer the GUI imports.

## Layout

```
packages/core/
├── agents/                 # ≤10-line thin pointers (installed to ~/.claude/agents/)
│   ├── prdt-po.md
│   ├── prdt-designer.md
│   ├── prdt-developer.md
│   └── prdt-qa.md
├── doctrine.md             # beliefs (injected into every persona)
├── discipline/             # SoT — contracts.md + <persona>/{habit.md, playbooks/}
├── migrations/             # project schema migrations (schema-v-guard derives latest id)
├── scripts/
│   ├── prdt                # CLI entrypoint (init · migrate · doctor · menus · update …)
│   ├── install.sh          # mirror discipline → ~/.prdt, agents + hook 3종 등록 (idempotent)
│   ├── uninstall.sh        # reverse of install.sh
│   ├── prdt-flip.sh        # machine flip: retire legacy pdt-*/pdtl-* (transitional, --rollback)
│   ├── statusline-prdt.sh  # display-only statusline
│   ├── hooks/              # prdt-session-start · prdt-post-compact · prdt-post-dispatch
│   └── lib/init-project.mjs  # shared project-init implementation (CLI + GUI initProject)
├── src/                    # TS layer for the GUI (@productune/core exports)
└── test/                   # vitest + schema-v-guard gate
```

## Discipline flow

`install.sh` mirrors `doctrine.md` + `discipline/` to `~/.prdt/` (1-way; user overlays live in `~/.prdt/overrides/<persona>.md`). The 3 hooks inject doctrine → contracts → habit → overrides into every prdt session; playbook menus (`playbooks/_index.md`) are generated by `prdt menus` — never hand-edit.

## Install

From the repo root:

```sh
packages/core/scripts/install.sh            # statusline registers by default; add --no-statusline to opt out
```

Idempotent — re-run after pulling to refresh the mirror, agents, and hook registration (`prdt update` does pull + re-run in one command). Discipline edits go in `packages/core/discipline/` (SoT); never edit `~/.prdt/discipline/` directly (overwritten on install).

## Build / test (TypeScript layer)

```sh
pnpm --filter @productune/core build
pnpm --filter @productune/core test
```
