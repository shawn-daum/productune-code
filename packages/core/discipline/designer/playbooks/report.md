# Report — report page · slide deck the user reads

Readers: Designer · Developer (its habit points here). Sharpens habit §Artifacts first screen; the method + conditions behind the headline number leave its closed `<details>` (Under top).

## Before writing
- Name purpose = decision it serves + comparison axes that decision implies (model · prompt · dataset).

## Top
- Answer to user's latest question + 1 table comparing options across those axes, 1 recommended row marked + what makes it final.
- Conclusion = labelled bullets or that table, never prose sentences; summary once, never restated lower.

## Under top
- Method + conditions behind headline number as labelled bullets, 1 fact each, never 1 dotted paragraph, never only in `<details>`.
- Headline number resting on judgment (match · pass · similar) → table directly under conclusion: verdict · criterion · example per row.

## Lower sections
- Each answers question section above raises, detail growing downward.
- Info-dense sections → labelled bullets, never full sentences.
- Per-axis choice → table of alternatives tried, chosen row marked.
