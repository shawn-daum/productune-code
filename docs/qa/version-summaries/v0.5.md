## 반복 실패 모드 (카테고리)

### 1. IPC path-traversal / containment (security) — 최다 반복
- T-014: `artifacts:readFile` — `startsWith(projectDir + path.sep)` 가드 부재, 확장자 whitelist만 있었음.
- T-016: `tickets:read` — `ticketId`를 `path.join`에 직결, `startsWith(ticketsRoot)` 검사 없음.
- T-PATCH-098: clipboard paste 디스크 저장 경로가 `projectDir` 하위 벗어남 → IPC containment 가드 필요.
- 패턴: **새 IPC fs 핸들러는 거의 매번 traversal/containment 가드 누락으로 1차 FAIL**. fail-patterns.md에 T-014/T-016 area-tag `*/ipc-security` 2건 등록됨(같은 area-tag ≥3이면 `type:test` 트리거).

### 2. 시각 렌더 / smoke 사각지대 (regression-adjacent)
- T-PATCH-095(loops=5): sticky-scroll의 bleed → stale ancestor → 레벨 reorder → depth-1 collapse가 라운드마다 재보고. 근본 원인은 매번 코드 검증(tsc clean·console 0)을 통과했으나 **`tests/smoke.spec.ts`가 mount + console error만 확인하고 sticky 시각 렌더를 미검증**. dev가 임시 vite+chromium 스크린샷 하니스로 경험적 검증 후에야 수렴.
- 교훈(habit.md 기등록): green build ≠ pass. 시각/스크롤 산출물은 user-verify eyeball 또는 스크린샷 하니스 필요.

### 3. doctrine ghost-ref / cap breach
- T-016: `pdt-persona-blink` CSS class가 TSX에서 참조되나 어떤 스타일시트에도 미정의 → blink 애니메이션 silent no-op (ghost-ref).
- T-PATCH-248(loops=3): artifact-lifecycle doctrine cap breach(154/100)로 1차 FAIL → trim(150) → 모델 통합 재author.
- backlog 잔존 cap breach: `phase2-3-ticket-sequence.md`(150/100 — 악화), `ux-principles.md`(108/100), `design-review.md`(100/100 — 한 줄도 못 늘림). doctrine trim debt 누적.

### 4. regression (silent drop / 파서)
- T-017: 티켓 로더 정규식 `/^T-[A-Z0-9-]+\.md$/`가 소문자 파일명(`T-P4-048-em.md`) silent drop → 티켓 유실. PO 선조치(`[A-Za-z0-9-]`)로 수정, 회귀 관점 확인.
- backlog OPEN: `skills.ts:62` `parseSkillFrontmatter`가 tickets.ts와 동일한 regex-only 파서 버그(인라인 `#` 미처리 + 무조건 unquote) — tickets.ts만 fix됨, skills.ts 잔존(진짜 OPEN).
- backlog OPEN: settings round-trip 회귀 테스트 부재 — T-PATCH-083에서 `loadSettings()` integrations silent-wipe 버그 발견·수정됐으나 재발 방지 테스트 없음(2026-06-23 재검증 여전).

### 5. fail-open / fail-safe 게이팅
- T-PATCH-249(loops=2): manifest-enforce hook이 malformed manifest에 fail-CLOSE(차단)되어 1차 FAIL → `jq -e .` 파싱가능 pre-check로 unparseable=skip/pass(fail-open)로 수정. productune 훅 공통 규약(jq/의존성 부재·non-productune·corrupt = 무해통과, block만·no auto-mutate) 준수 확인이 grill 핵심.

### 6. TCC-permission (real-OS, 이월)
- T-PATCH-255(이월): PO 턴의 tool 실패 — 특히 macOS TCC Downloads/Desktop/Documents 접근 거부 — 가 응답 텍스트 없이 silent 종료("도구 1개" + 대기중, 사용자 무안내). 5차 dmg cua 재현 확정(Allow → 정상, Don't Allow → silent kill). v0.6로 이월(dev+QA L2).
- cua-vm-harness.md 교훈: stale keychain 401은 **harness 아티팩트지 제품 버그 아님**(T-PATCH-230/221/231 장기 헌트의 근본). 제품 비난 전 fresh keychain auth 확인 필수.
