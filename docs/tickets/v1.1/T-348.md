## Request

**UI 재배치 결정 (shawn, 2026-07-14)**:

1. **아티팩트 탭 내용을 프로젝트 탭 안으로 이관** — 프로젝트 카드 하단에 아티팩트 섹션 배치.
2. **기존 아티팩트 탭 자리에는 "프로젝트 히스토리"** — 버전 타임라인. shawn 정의: "v1 → v1.1이 되면 v1은 히스토리에 들어간다" — 닫힌 버전들의 기록(그 버전의 티켓들, 회고, 결과)을 열람하는 뷰.
3. **(추가, 2026-07-14) PRD도 프로젝트 탭으로 이관** — 현재 버전 탭 main pane에 있는 PRD를 프로젝트 탭 안으로. 프로젝트 탭 = 카드 + PRD + 아티팩트 + .ENV (배치·계층은 Designer 판단), 버전 탭은 티켓/진행 중심으로 남음.

- Designer 산출물: 두 화면의 레이아웃/정보구조 스펙 (+ 필요시 hi-fi mockup) —
  - 프로젝트 탭: 카드 + .ENV + 아티팩트 섹션의 배치·우선순위, 아티팩트 다수일 때/없을 때 상태.
  - 히스토리 탭: 버전 엔트리에 뭘 보여줄지(티켓 수/닫힌 날짜/retro 링크/북스타 결과 등), 현재 진행 중 버전의 취급(표시 여부), 히스토리 없음(첫 버전 진행 중) 빈 상태.
- 데이터 소스 제약: `docs/tickets/v<N>/`, `docs/wiki/retro--v<N>.md`, git tag — 파생 가능해야 함 (구현 시 developer가 판단).
- 구현은 별도 impl 티켓 — T-347(프로젝트 탭 카드 버그) 종료 후 착수.
