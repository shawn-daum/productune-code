## Request

**GUI follow-up (shawn, 2026-07-13, 스크린샷 리포트)**: T-335 이후에도 모델 표기가 기대에 못 미침.

1. **표기 형식**: `claude-sonnet-5` 같은 raw id 형태 말고 **"Claude Sonnet 5"** — 공간이 넓은 곳(모달 옵션, FreshComposer 선택 등)은 "Claude Sonnet 5" 풀네임, **좁은 곳**(스프라이트 칩, 전송버튼 배지)은 **"Sonnet 5"**.
2. **버전 미표시 잔존**: 실사용 세션 스크린샷에서 PO 스프라이트 칩과 전송버튼 배지가 여전히 "Opus"로만 표시 — PO가 이미 응답한 활성 세션인데도 버전 승격("Opus 4.8")이 안 일어남. T-335의 실모델 id 캡처(`po:model-id`)가 실제 GUI 세션에서 발화하는지 진단 필요 (resume 세션 경로, 빌드 미반영 가능성 포함).
3. **모달/선택 UI도 버전 표시**: alias 전용 표면(스위처 모달, FreshComposer 옵션)도 "opus"가 아니라 버전 포함 표기를 원함 — alias→실모델 해석 수단이 필요 (관측된 id 활용, 매핑, 기타 — 설계 판단. 단 하드코딩 드리프트와 버전 발명 금지 원칙은 유지, 해석 불가 시 "Claude Opus" 같은 graceful 표기).

## Acceptance

- No surface ever renders a raw model id (`claude-sonnet-5`) or bare lowercase alias (`opus`): wide surfaces (switcher modal options, FreshComposer selector) render "Claude Sonnet 5"-style full names, narrow surfaces (sprite chips, send-button badge) render "Sonnet 5"-style short names.
- In a real GUI session, the PO chip and send-button badge show the version (e.g. "Opus 4.8") once the session has streamed at least one assistant line — the screenshot scenario (active session, still "Opus") is diagnosed and fixed.
- Alias-only surfaces show a versioned name when the alias can be resolved to a real id without inventing a version; unresolvable aliases degrade gracefully ("Claude Opus" / "Opus").
- No regression in T-334/T-335 behavior (selection, switch-restart, worker forwarding, stale-version clearing).
