## Request

**GUI follow-up (shawn, 2026-07-13)**: 선택 UI(스위처 모달, FreshComposer, GeneralSettings)에서 미관측 모델이 "Claude Sonnet"으로만 나옴 — 사용자는 **항상 "Claude Sonnet 5"처럼 버전이 보이길** 원함. T-338의 관측-기반-만 정책(미관측 = 무버전)은 사용자 기대 미달로 판명.

- 방향:
  1. **번들 기본 매핑**: 빌드 시점의 alias→모델명 기본값("Claude Sonnet 5" 등)을 포함해 관측 전에도 버전 표시.
  2. **관측 우선**: 라이브 스트림에서 실 id가 관측되면 번들 값을 덮어씀 (T-338 observedByAlias 유지).
  3. **디스크 persist**: 관측 id를 로컬에 저장해 앱 재실행에도 유지 — 번들 매핑이 구식이 되어도 한 번 관측되면 자가 교정됨.
- 드리프트는 (2)+(3)의 자가 교정으로 수용 — "버전 발명 금지"보다 "항상 버전 표시"가 사용자 결정.

## Acceptance

- On first app run with no observations, the switcher modal / FreshComposer / GeneralSettings options all show versioned names (e.g. "Claude Sonnet 5") from the bundled defaults.
- Once a real id is observed, it overrides the bundled default and persists across app restarts (per machine).
- Sprite chips / send badge behavior unchanged except they may also use the bundled default before first capture (short form "Sonnet 5").
- No regression in T-334/335/338 behavior.
