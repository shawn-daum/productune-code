## Request

Ship 눈검 중 발견한 crash + CLI 정리 3건 (사용자 지시):

1. **crash**: GUI에서 새 프로젝트(enneagram-mentor)를 만들어 열었더니 `claude --agent 'pdt-po' not found`로 종료(code 1). 원인 = 새 프로젝트가 **레거시 `.productune`로 생성**됨 → `po-runner.ts`의 `poAgentFor`가 은퇴된 `pdt-po`를 스폰. `pdt-*` 에이전트는 T-293/T-311에서 폐기됨(설치 목록에 `prdt-*`만 존재).
2. **pdt-\<persona\> 잔재 스윕**: 소스 전반의 `pdt-po`/`pdt-designer`/`pdt-developer`/`pdt-qa` 참조(런타임 스폰·UI persona id·allowlist·presence 맵 등)가 crash/오작동 원인. 죽은 이름이 스폰·resolve 경로에 남지 않도록 정리.
3. **`prdt po` 제거**: 사용자가 `prdt po`를 안 씀. `packages/core/scripts/prdt`의 `po` 서브커맨드/인자 제거(= bare `prdt`가 유일 진입), README의 `prdt po` 줄도 삭제.
4. **레거시 마이그레이션 버튼**: 레거시 `.productune` 프로젝트를 열었을 때 뜨는 안내 영역에 **[마이그레이션] 버튼**을 추가. 클릭 시 그 프로젝트를 `.prdt`로 전환하고(단일 migrate SoT `~/.prdt/bin/prdt migrate <path>` 재사용, doctrine #2), 성공 후 UI가 재감지되어 `prdt-po`가 정상 스폰되도록.

관측 리드(참고): enneagram-mentor 경로 `~/productune/projects/enneagram-mentor` = `.productune`. `prdt init`은 `.prdt`를 만드는데 GUI 생성 경로가 레거시를 만들고 있음 — 현재 GUI 생성 플로우가 `prdt init --json`(또는 `.prdt` 생성)을 쓰는지 확인·수정.
