## Request

**Ship 눈검 결함**: 워커 라이브 활동 팝오버(`PersonaPresenceBar.tsx`의 WorkerStreamSlot / 호버 tooltip)가 **내용이 컨테이너(둥근 박스) 위·아래로 튀어나감**. 라인 목록이 박스 높이를 넘겨 시각적으로 넘치고 클리핑/스크롤이 안 먹음.

## Acceptance

- 워커 라이브 팝오버의 라인 목록이 컨테이너 경계 안에 머무름 — 위·아래 오버플로 없음, 내용이 많으면 내부 스크롤(auto-follow 유지)로 담김.
- 두 레이아웃(compact slot · expand overlay)·라이브/frozen 상태 모두에서 넘침 없음.
- 기존 auto-follow(최신 라인 하단 고정)·persona 라벨·live dot·tok/duration 표시 회귀 없음.
- build green · lint clean · typecheck clean · relevant tests green.

### 재오픈 (2026-07-07) — 조각패치 종료, 통으로 정합
1차 fix(barStyle center→stretch, 고정 92px)는 담김만 잡고 **스크롤이 안 돼(compact tail Chromium flex quirk) 줄이 겹쳐(짜부)** 버림 — 담김과 스크롤이 커플링돼 있는데 스크롤 quirk를 non-blocking으로 미룬 게 원인. 이번엔 팝오버 레이아웃을 **전 상태 매트릭스로 한 번에** 고친다:
- 줄 수 매트릭스: 0·1·소수(≤슬롯)·다수(슬롯 초과) 모두에서 **줄이 겹치지 않고**(각 라인 정상 line-height), 초과분은 **실제로 스크롤**(마우스휠 위-스크롤 포함)되며 auto-follow 유지.
- 상태 매트릭스: inline(wide)·stacked(narrow)·live·frozen·ExpandOverlay 전부.
- compact tail 스크롤 quirk(`justify-content:flex-end` + `overflow-y:auto`의 scrollHeight 오보고)도 이번 스코프에 포함해 실제 스크롤되게 해결.
- 워커가 실제로 자주 만드는 라인 수(수십 줄)로 재현·검증할 것.

## Outcome

- **Root cause**: `barStyle.alignItems: 'center'`가 definite-height 체인을 끊어 WorkerStreamSlot(flex:1/alignSelf:stretch)이 콘텐츠 크기로 팽창(137.9px) → 클립/스크롤 미작동, 위·아래 오버플로.
- **Fix**: `barStyle.alignItems` `center`→`stretch` (1줄, 근거 주석). 슬롯이 고정 92px(inline)/76px(stacked)로 바운드 → 클립+내부 스크롤 정상.
- **QA PASS 0.95 (smoke+grill)**: inline/stacked/frozen·6→14줄 강제 오버플로 시나리오 모두 getBoundingClientRect로 경계 안 확인(overflowsTop/Bottom=false), auto-follow·라벨·live dot·tok/duration 정상, ExpandOverlay 무회귀, build/lint/typecheck/test green(27+26). 검증 harness 작업트리 미잔류.
- files: `PersonaPresenceBar.tsx`.

### 최종 해결 (재오픈 후, 2026-07-07)
- 1차 fix가 "담김만·스크롤X→줄겹침(짜부)"를 유발 → 재오픈해 통합 수정. **2개 커플링 CSS 버그**:
  1. `justify-content:flex-end` + `overflow-y:auto` = Chromium quirk(넘친 내용이 스크롤 원점 위로 escape, wheel-up 死) → `justify-content` 제거 + content wrapper(`flexShrink:0`)에 `margin-top:auto` 바텀앵커.
  2. stream-log 라인 children이 `flex-shrink:1`로 버퍼 오버플로 시 line-height 밑으로 압축(겹침) → 공유 prose/tool 라인 스타일에 `flexShrink:0` + 명시 `lineHeight`/`minHeight`.
- **QA PASS 0.94 (grill, 재오픈 후)**: 34-case 매트릭스(줄 0/1/4/40 × inline/stacked × live/frozen/ExpandOverlay) 전부 수치 검증 — overlaps=0, 슬롯 92px/76px 준수, wheel-up scrollTop=0 도달(slot+overlay), auto-follow scrollTop=max, frozen 헤더 'live' 없음, 라벨·dot·tok/duration 무회귀, console error 0. build/lint/typecheck/test green.
- **프로세스 교훈(Retro)**: 커플링된 결함(담김↔스크롤)을 non-blocking으로 쪼개 미룬 게 3라운드 재작업 유발. fragile CSS 컴포넌트는 상태 매트릭스 통검증이 정답. QA에 경량 검증 기법(electron 플러그인 뺀 임시 Vite + store window 노출 + chromium)이 매트릭스 커버를 가능케 함.
