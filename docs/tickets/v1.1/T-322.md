## Request

새 프로젝트 init의 **버전 지정을 자유 입력 → `v0.1` / `v1` 가이드 선택**으로 바꾼다. GUI·CLI 프롬프트 양쪽 정합(사용자 결정 B). **default·추천 = `v0.1`** (사용자 결정 2026-07-07: 보통 확고한 출시 플랜 없이 시작하니까). 대상 사용자가 비개발 기획자라 UX·카피가 중요.

각 선택지 의미(다듬은 카피 초안 — 워커가 최종 다듬기):
- **v0.1** — "아이디어 검증부터. 공개 여부는 아직 미정, 일단 만들어보며 방향을 잡는 실험 단계."
- **v1** — "출시를 목표로. 확고한 아이디어와 배포 계획이 있어 처음부터 완성형 제품을 만드는 단계."

(원문 의도: v0.1=제품 아이디어만 있고 공개 불확실, 빌드부터 해보고 싶은 경우 / v1=확고한 아이디어+배포 계획, 바로 배포 가능한 제품.)
