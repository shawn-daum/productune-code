## Request

**Ship 도그푸딩 버그 → discipline 수정 (사용자 결정 a: 즉시 적용)**: PO가 사용자 선택 시작 버전을 무시하고 self-promote함 — v0.1로 생성한 신규 프로젝트인데 PO가 Define 턴에서 `po-state.version`을 `v1.0`으로 덮어씀(init은 v0.1/v1만 쓸 수 있어 ".0"은 PO 소행 확정). PRD를 "v1" 프레임으로 쓰며 제품비전 v1과 라이프사이클 version을 혼동, v0.1(실험적 시작) 기능 취지 위배.

`fact--discipline-editing` 룰 준수: SoT = `packages/core/discipline/po/habit.md`, SSoT-first 병합(version-roll 절과 같은 Lifecycle 섹션), act-time voice, cap≤60, impact sweep, QA grill + doctor.
