## Outcome

Implemented the approved T-348 spec. Verified end-to-end against this repo's real data (git tags v0.5/v1.0, retro/PRD/artifact files): the derived history exactly matches the spec's expected states.

**What shipped**
- **Prerequisite git-tag IPC** (`electron/ipc/git.ts`, `git:listTags`): read-only `git for-each-ref` → `{name, date}[]` newest-first. Safe on tag-less repos and non-git dirs (both → `[]`). Pure `parseTagLines` unit-tested (6 cases). Registered in `main.ts`, exposed in `preload.ts`.
- **Project tab reorder** (`LeftSidebar.tsx`): card → PRD → artifacts → (legacy past) → .ENV.
  - PRD: new compact sidebar variant of `PrdSection` (`compact` prop) — sp-sec chrome, always-present with graceful `prdNone` placeholder.
  - Artifacts: `SidePanelArtifacts` rewritten from session-only list → disk-backed current-version section (`artifacts:listTree`), count badge = flat+archived on-disk total (survives restart — kills the old `files.length===0 → return null` disappearance bug), archive sub-toggle, open-all (>3), session-opened files render dim as an overlay.
- **Project History tab** (activity slot 2, `Package`→`History`, `ActivityIcon` value `artifacts`→`history`):
  - `HistoryPane` (sidebar): closed-version timeline (git-tag SoT, VERSION_RE filter, date-desc), in-progress banner (routes to Project tab via new `activity:select` window event → `WorkspaceShell` setter), empty state + CTA, git-unreadable error banner.
  - `HistoryDetailView` + `HistoryDetailTab` (new `history-detail` TabType): outcome-first order (Outcome → PRD → Tickets → Artifacts → Retro). Outcome parsed from `retro--<v>.md ## Outcome`; Tickets summary (done/dropped/open, amber anomaly for leftover open) reuses `ticket-review:<v>` board (no re-drawn kanban); Artifacts via new `artifacts:listVersion` IPC.
- **Version tab**: `PrdSection` removed from `TicketReviewTab` (§3.1) — pane is single-content (kanban) again. `VersionDetailView` left untouched (§3.2, out of scope).
- Locale keys added (`workspace.history.*`, `activityBar.history`) en+ko, parity check green.
- Deleted orphaned `ArtifactsPane.tsx` (its tab was removed; body still carried the spec-killed "version history" toggle; not imported → not bundled).

**Deviations from spec (deliberate, low-risk)**
- Empty history state rendered in the **sidebar** body (icon+headline+helper+CTA), not the main pane. The main pane is purely tab-driven; hijacking it on activity-select would be a real architecture change with regression risk. CTA still navigates to Project tab. Follow-up if the main-pane treatment is wanted.
- History-detail Artifacts + PRD are rendered **inline** rather than reusing `ArtifactsPane.VersionNode` / `PrdSection`'s closed branch: `VersionNode` was un-exported and tightly coupled; `PrdSection`'s prdt override forces the master PRD (defeats a version snapshot). Inlining kept the diff self-contained and correct for prdt.
- New `artifacts:listVersion` IPC added (beyond the spec's single flagged git IPC): `artifacts:listTree`'s prdt branch ignores version subdirs and walks flat, so there was no existing path to `docs/artifacts/<v>/` for a prdt project's history detail. Reuses `buildVersionArtifacts` (~12 lines).
