# T-026: Main-panel width restructure + remove PO-chat minimize (#14)

> Phase 3-B layout fix. PO chat must be a permanent sibling, never an overlay.

## Request

### Problem

The current shell grid (`WorkspaceShell.tsx`) treats the PO chat as an optional column that can
collapse to `0px` width when hidden (`chatPanelVisible` conditional). The main panel's
`minmax(0, 1fr)` then expands to fill the reclaimed space. The user observes that even when the
panel IS visible, the main-panel width behaves as though the chat column is absent or overlapping
it (likely a grid measurement artefact of the collapse/show toggle). The root cause: `chatPanelVisible`
drives a two-branch `gridTemplateColumns` that sets the chat columns to `0px 0px`, and the
show/hide path is wired through `panelVisible` state in `poChat` store + a FAB to restore.

### Required changes

**1. Remove PO-chat minimize / hide entirely**

The PO chat is always active and must always be visible. Remove the minimize mechanism:
- `ChatPanel.tsx`: remove the minimize button (the `<button>` at line ~226–234 with
  `aria-label={t('workspace.chat.minimize')}` and `onClick={() => setPanelVisible(false)}`),
  the `minimizeHover` state, and the `{!panelVisible && <PoFab />}` branch. The outer
  `display: panelVisible ? 'flex' : 'none'` toggle becomes unconditional `display: 'flex'`.
- `store/poChat.ts`: remove `panelVisible`, `setPanelVisible`, `togglePanel` (keep remaining
  state — messages, streaming, health, etc.).
- Remove `PoFab` component entirely (it only exists to restore the minimized chat).
- Remove the `workspace.chat.minimize` i18n key from `en.json` / `ko.json`.

**2. Fix the shell grid so main panel never overlaps PO chat**

`WorkspaceShell.tsx`:
- Remove the `chatPanelVisible` conditional in `dynamicGrid`. The grid always has 6 columns:
  `${ACTIVITY_BAR_WIDTH}px ${sidebarWidth}px ${RESIZE_HANDLE_WIDTH}px minmax(0,1fr) ${RESIZE_HANDLE_WIDTH}px ${poChatWidth}px`
- Remove the `chatResizeArea` conditional render — resize handle is always present.
- Remove the `ChatPanel` conditional render (`{chatPanelVisible && ...}`) — `ChatPanel` always
  renders.
- Remove `chatPanelVisible` / `usePoChat(s => s.panelVisible)` read from `WorkspaceShell`.

**3. Fix `useResizeLayout`**

`useResizeLayout.ts` accepts `chatPanelVisible: boolean` and uses it throughout to branch width
clamping. After removing the hidden state:
- Remove the `chatPanelVisible` parameter; treat it as permanently `true` internally.
- Remove all `chatPanelVisibleRef` tracking and the branches that gate on it.
- The `syncLayoutWidthsToViewport` always clamps both sidebar and chat widths.

**4. `clampSidebarWidth` / `clampPoChatWidth` helpers**

`shell/helpers.ts`: remove the `chatVisible` parameter from `clampSidebarWidth` if present;
always apply the chat-width budget deduction.

## Acceptance

- [ ] **[AC-1]** The PO chat panel is always visible; there is no minimize button, no FAB, and no
      way to hide the chat from the UI.
- [ ] **[AC-2]** At any window width the main panel and PO chat column do not overlap — they are
      true siblings in the CSS grid.
- [ ] **[AC-3]** Dragging either resize handle (sidebar ↔ main, main ↔ chat) behaves correctly and
      clamps within bounds.
- [ ] **[AC-4]** `panelVisible`, `setPanelVisible`, `togglePanel` are removed from `poChat` store;
      `PoFab` component is deleted.
- [ ] **[AC-5]** `useResizeLayout` no longer accepts `chatPanelVisible`; no conditional 0-width
      chat column logic remains in the codebase.
- [ ] **[AC-6]** `pnpm tsc --noEmit` passes with no new errors.

## Plan

1. Remove `PoFab` component file; remove minimize button + `panelVisible` from `ChatPanel.tsx`.
2. Prune `poChat` store.
3. Update `WorkspaceShell.tsx`: single unconditional `gridTemplateColumns`, always render
   resize handle + ChatPanel, remove `chatPanelVisible` reads.
4. Refactor `useResizeLayout` — drop `chatPanelVisible` param, simplify viewport sync.
5. Update `clampSidebarWidth` helper signature if it branched on `chatVisible`.
6. Remove `workspace.chat.minimize` i18n key from both locale files.
7. `pnpm tsc --noEmit` green; manual smoke: resize both handles, confirm no overlap at narrow
   and wide window sizes.
