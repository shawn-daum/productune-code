# T-020: B4 — 무서명 .dmg 배포

> v0.5 Track B, item B4. Full spec = **PRD §B4** (`docs/prd/productune.md` lines 415–423).
> `install.sh` 와 `.dmg` 분리 유지 (option A). deferred_candidate `v0.5-gui-distribution` 참조.

## Request

코드 서명 없이 팀원에게 설치 가능한 빌드를 제공한다.

- electron-builder devDependency + config 추가.
- `.icns` 앱 아이콘.
- `dist:mac` 스크립트 (electron-builder --mac dmg, 무서명).
- 팀 README 에 우클릭→열기 Gatekeeper 우회 가이드.
- `install.sh` 플로우는 불변.

## Acceptance (PRD §B4 AC)

- [ ] **[AC-1]** `dist:mac` 이 무서명 `.dmg` 를 생성한다.
- [ ] **[AC-2]** 문서화된 우클릭→열기 경로로 clean mac 에 설치된다.
- [ ] **[AC-3]** `install.sh` 플로우가 변경되지 않는다.

## Plan

### 1. `packages/gui/package.json`

- `electron-builder@26.8.1` 을 **devDependency** 로 추가.
- `dist:mac` 스크립트 추가:
  `"dist:mac": "pnpm run build && electron-builder --mac dmg --config electron-builder.yml"`
  - 기존 `build` 스크립트 (locale 검증 + `tsc --noEmit` + `vite build`) 를 선행 → renderer (`dist/`) + electron main/preload (`dist-electron/`) 산출.
- `version: "0.0.0"` (workspace placeholder) 는 다른 tooling 이 소비하므로 **불변** — artifact version 은 config 의 `extraMetadata.version` 로 override.

### 2. `packages/gui/electron-builder.yml` (신규)

- `appId: com.productune.gui`, `productName: productune`.
- `extraMetadata.version: 0.5.0` — asar 내 package.json 만 patch (on-disk `version` 불변), artifact 이름 + CFBundleVersion 에 반영.
- `directories.output: release`, `buildResources: build`.
- `files` from→to 매핑 (vite-plugin-electron/simple 레이아웃):
  - `dist-electron` → `dist-electron` (package.json `main = dist-electron/main.js` 가 literal lookup 이므로 경로 보존 필수)
  - `dist` → `renderer` (main.ts 의 `../renderer/index.html` 로드 경로와 정합)
- `mac.target: dmg` (arm64 + x64), `mac.icon: build/icon.icns`, `mac.identity: null` (무서명 — signing/notarization 스킵).

### 3. `.icns` 앱 아이콘 — `packages/gui/build/icon.icns` (신규)

- repo 전체에 source 아이콘/PNG 가 **없음** → 1024² placeholder PNG 를 생성 후 `sips` + `iconutil` 로 `.icns` 변환. 실제 브랜드 아이콘은 후속 디자인 산출물로 교체 필요 (Outcome 에 flag).

### 4. `packages/gui/.gitignore` (신규)

- `release/` (electron-builder 출력, ~226MB) 무시.

### 5. `README.md`

- Install 섹션 뒤에 "GUI 데스크톱 빌드 (무서명 `.dmg`)" 섹션 추가: `dist:mac` 사용법 + 우클릭→열기 Gatekeeper 우회 4-step 가이드 + macOS 15+ "Open Anyway" fallback. `install.sh` 와 `.dmg` 분리 (option A) 명시.

### 6. `install.sh` — **불변** (AC-3)

- CLI 설치 플로우 (`packages/core/scripts/install.sh`) 는 전혀 건드리지 않음.

### 검증 방법

1. `pnpm --filter @productune/gui tsc --noEmit` — pass.
2. `electron-builder --mac dmg --arm64` 실제 실행 → 무서명 `.dmg` 산출 확인 (`skipped macOS code signing reason=identity explicitly is set to null`).

## Out of scope

- 코드 서명 / notarization.
- auto-update (electron-updater → v0.6).

   - `release/` 무시.

### 이탈 사항

- **placeholder 아이콘**: repo 에 source 아이콘/PNG 가 없어 `build/icon.icns` 를 임시 solid-color placeholder 로 생성함. 실제 브랜드 `.icns` 로 교체 필요 (디자인 산출물 후속).
