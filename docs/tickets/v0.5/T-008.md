# T-008: A1 — 좌측 패널 탭 재배치

> v0.5 Track A, item A1. 좌측 ActivityBar 의 탭 순서를 PRD A1 스펙에 맞게 고정 5-탭으로 재배치하고,
> Artifacts 슬롯을 추가한다. 탭 콘텐츠 구현(A2)은 별도 ticket 범위.

## Request

ActivityBar 의 현재 탭 순서(`explorer / project / team / settings`)를 **`project / artifacts / team / explorer / settings`** 5-탭 고정 순서로 변경한다.

- **순서 변경**: `explorer` 를 맨 앞에서 4번째로 이동, `artifacts` 슬롯을 2번째에 신규 삽입.
- **고정 순서**: 사용자가 탭 순서를 변경할 수 없다 (drag-to-reorder 없음).
- **Artifacts 콘텐츠 제외**: 탭이 활성화될 때 사이드바에는 placeholder 유지 (이미 `LeftSidebar.tsx` 에 `artifactsHint` placeholder 존재). 실제 콘텐츠 구현은 T-009(A2) 범위.

### KR

| # | 요건 |

| KR-1 | ActivityBar 탭이 정확히 `project / artifacts / team / explorer / settings` 5개, 이 순서로 렌더됨 |

| KR-3 | 탭 순서를 사용자가 변경하는 UI가 없음 (drag 핸들, 순서 설정 메뉴 없음) |
| KR-4 | `project` 탭이 default active 상태 유지 (WorkspaceShell 초기값 `'project'` 불변) |

## Plan

### 1. `packages/gui/src/components/workspace/ActivityBar.tsx`

**변경: `ICONS` 배열 순서 및 artifacts 항목 추가**

현재 `ICONS` 배열:
```
explorer / project / team / settings   (4개)
```

변경 후 `ICONS` 배열 (순서 고정, 5개):
```typescript
const ICONS: IconDef[] = [
  { id: 'project',   Icon: LayoutDashboard,  titleKey: 'workspace.activityBar.project'   },
  { id: 'artifacts', Icon: Package,          titleKey: 'workspace.activityBar.artifacts' },
  { id: 'team',      Icon: Users,            titleKey: 'workspace.activityBar.team'      },
  { id: 'explorer',  Icon: FolderOpen,       titleKey: 'workspace.activityBar.explorer'  },
  { id: 'settings',  Icon: Settings,         titleKey: 'workspace.activityBar.settings'  },
]
```

**변경: import 추가**

기존 import 행:
```typescript
import { FolderOpen, LayoutDashboard, Users, Layers, KanbanSquare, Settings } from 'lucide-react'
```
→ `Package` 추가:
```typescript
import { FolderOpen, LayoutDashboard, Users, Layers, KanbanSquare, Settings, Package } from 'lucide-react'
```

주석 업데이트: `/** Primary activity icons — Project / Artifacts / Team / Explorer / Settings */`

- `en`: `"Artifacts"`
