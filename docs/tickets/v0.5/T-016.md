# T-016: A7 — 티켓 상세 탭 (ticket-detail)

> v0.5 Track A, item A7. 티켓 선택 시 메인 패널에 실제 상세 페이지를 여는 `ticket-detail` 탭 타입을 구현한다.
> PRD A7 intent: "selecting a ticket shows a real detail page, not a jump into the Tickets tab."

## Request

### KR

`ticket-open { ticketId }` intent 수신 시 메인 패널에 `type: ticket-detail` 탭을 열고, 티켓 md 파일을 읽어 **3-영역 상세 페이지**를 렌더한다.

**§2.0 Header**
- breadcrumb `← Tickets / T-NNN` — 클릭 시 Tickets 탭으로 포커스
- ticket ID + title (heading-pane recipe)
- `status` pill (§8.2 status variant, T-006 Option B hex)
- Lock 글리프 + "읽기 전용" 마커 (편집 affordance 없음)

**§2a KR 본문**
- 티켓 md 의 `## Request (KR)` 또는 `(KR)` suffix 섹션 추출
- `MdRenderer` (`md-*` recipe set, `docs/designer/archive/v0.5/T-004-a9-flow.md` §1.1 재사용 by name) 로 렌더
- KR 섹션 없을 때 → hint 메시지 (빈 패널 금지, §1.5.3 Empty vs Pending)
- "Show full spec" 접기/펼치기 버튼으로 전체 body 제공

**§2b DispatchProgress**
- 페르소나 레일 4개 (PO/designer/developer/qa) — T-006 Option B hex
- `assignee` → active (persona-blink CSS class), `persona_sessions` 있으면 idle, 없으면 off
- 다음-action 라인: `status` + `assignee` + `qa_status` 파생 한 문장
- **read-only/informational** — action 버튼 없음 (decisions.md 2026-06-01 T-003 결정)

**IPC**
- `tickets:read(projectDir, ticketId)` — `docs/tickets/<version>/<ticketId>.md` 탐색 + 반환 `{ frontmatter, body, krBody }`
- `po-state:get` 별도 불필요 — workspace store 의 `poState` 를 직접 구독

**탭 dedup**
- 동일 `ticketId` 의 `ticket-detail` 탭이 이미 열려 있으면 focus (T-015 `openTab` 이미 id 기반 dedup 처리)
- tab id = `ticket-detail:{ticketId}`, type = `ticket-detail`

## Plan

### 1. `packages/gui/electron/ipc/tickets.ts`

**추가: `tickets:read` IPC 핸들러**

- `stripFrontmatter(content)` — YAML frontmatter 블록 제거 후 body 반환
- `extractKrSection(body)` — `## ... (KR)` heading 으로 시작하는 첫 번째 섹션 추출
- `ipcMain.handle('tickets:read', ...)` — `docs/tickets/<version>/<ticketId>.md` 전체 탐색, 반환 타입: `{ frontmatter, body, krBody }`

### 2. `packages/gui/electron/preload.ts`

**추가: `ticketsRead` API surface**

```ts
ticketsRead: (projectDir: string, ticketId: string) =>
  ipcRenderer.invoke('tickets:read', projectDir, ticketId)
```

### 3. `packages/gui/src/components/workspace/main/panes/TicketDetailTab.tsx` (신규)

**3-영역 구조:**
- `§2.0` Header: breadcrumb (ChevronLeft → Tickets tab openTab) + dhTitle + status pill + Lock + "읽기 전용"
- `§2a` KR body: `MdRenderer` 로 `krBody` 렌더; 없으면 Info hint
- "Show full spec" 접기/펼치기: `MdRenderer` 로 `body` 렌더
- `§2b` DispatchProgress: Activity 아이콘 + dp-meta + PersonaCard 4개 (railGrid) + next-action (ArrowRight + 파생 문장)

**데이터 소스:**
- `(window as any).api.ticketsRead(projectDir, ticketId)` — ticket md 로드
- `useWorkspace((s) => s.poState)` — `persona_sessions` 구독 (read-only)
- `useWorkspace((s) => s.openTab)` — breadcrumb 클릭 시 Tickets tab 열기

**PersonaCard sub-component** — inline, `pdt-persona-blink` CSS class (기존 CSS 재사용)

### 4. `packages/gui/src/components/workspace/main/TabContent.tsx`

- `import TicketDetailTab from './panes/TicketDetailTab'` 추가
- `case 'ticket-detail':` stub 교체 → `<TicketDetailTab props={tab.props} />`
