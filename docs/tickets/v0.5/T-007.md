## Request

1. **Dispatch = foreground (delegation.md)** — root-caused: a backgrounded nested `claude --agent`
   deadlocks at startup (cmux injects session hooks into the child). Foreground synchronous works in
   cmux + plain terminals. Portable form:
   `claude --add-dir ~/.productune -p --agent pdt-<persona> --permission-mode acceptEdits --model <tier> "[ctx]{…} <prompt>"`
   — `--add-dir` FIRST (late placement drops the prompt → "Input must be provided"); never background.
2. **Effort default (routing.md)** — `opus = xhigh (always)` → `opus = high`. Floor rows `opus + xhigh`
   → `opus + high`. Keep R1-MVP-PRD `opus + max` (special). xhigh becomes the step-up level.
3. **Cost-strip scope (post-bash-strip-cost.sh)** — broaden beyond the JSON `total_cost_usd` fast-path
   to also strip text-mode cost (`$N.NN`, `Cost:` lines, token/usage summary) so cost never leaks via
   text output. Keep JSON-field strip + pass-through fallbacks.
