# T-021: C1 — fresh-install CI smoke

> v0.5 Track C, item C1. Full spec = **PRD §C1** (`docs/prd/productune.md` lines 425–434).
> deferred_candidate `v0.5-fresh-install-ci-smoke` 참조 (절대경로 symlink + env seed key mismatch 재발 방지).

## Request

teammate 에게 도달하기 전에 install 회귀를 잡는 CI smoke 를 추가한다. GitHub Actions, 격리된 `$HOME` 에서 4개 검사:

1. `install.sh < /dev/null` 비대화형 통과.
2. 절대경로 symlink target grep/차단 (lint hook).
3. bootstrap-doctrine ↔ install.sh env-file key 일치 검사.
4. post-install PO 세션 1회 → dispatch-cost-strip 동작 확인.

## Acceptance (PRD §C1 AC)

- [ ] **[AC-1]** CI 가 다음 중 하나라도 실패 시 fail: 비대화형 install 깨짐 / 절대경로 symlink target / env-key drift / dispatch-cost-strip 깨짐.
- [ ] **[AC-2]** clean install 에서 CI 통과.

## Out of scope

- full e2e GUI CI.

## Plan

### 1. `.github/workflows/fresh-install-smoke.yml`

GitHub Actions job `fresh-install-smoke` (ubuntu-latest, `permissions: contents: read`, 15-min timeout), triggers on push/PR to `main` + `workflow_dispatch`. Runs the four checks in order: (b) symlink lint → (c) env-key parity → (a) non-interactive install → (d) dispatch-cost-strip. Each step shells out to a script under `scripts/ci/`.

### 2. `scripts/ci/check-symlink-targets.sh` — check (b)

Walks `git ls-files -s`, reads each mode-`120000` (symlink) blob via `git cat-file blob`, and fails if any target starts with `/` or `~`. Inspecting the blob (not the checked-out FS) makes it OS-independent. Guards the first deferred bug — absolute-path symlink targets that dangle on a teammate machine. Relative targets (e.g. `my-po -> productune`) pass.

### 3. `scripts/ci/check-env-key-parity.mjs` — check (c)

Statically scans `install.sh` and `lib/bootstrap-doctrine.sh` for the engine-selector key each one WRITES into `~/.productune/productune.env` (printf/echo redirect or `sed -i` seed only — `say`/log lines excluded). Fails if both seed an engine key but disagree. Guards the second deferred bug — env seed key mismatch.

### 4. `scripts/ci/run-install-smoke.sh` — check (a)

Creates a throwaway `$HOME` (`mktemp -d`), drops `claude`/`npm` stubs at the front of `PATH` so install.sh's auth preflight passes and the install BODY runs, executes `install.sh < /dev/null`, then asserts fresh-install invariants: four persona agent symlinks resolvable, `productune.env` seeded with the engine marker, `settings.json` valid JSON with the strip-cost hook registered. Cleans up via EXIT trap.

### 5. `scripts/ci/check-dispatch-cost-strip.sh` — check (d)

Drives the installed PostToolUse hook `post-bash-strip-cost.sh` with fixtures (a real PO session needs an authed CLI, unavailable on a clean runner): JSON-mode cost-field strip + payload survival, text-mode cost-line strip + prose preservation, the JSON-fast-path pass-through arm, and a no-cost pass-through.

### 검증 방법

1. `bash scripts/ci/check-symlink-targets.sh` → OK on clean tree.
2. `node scripts/ci/check-env-key-parity.mjs` → catches current `engine=` vs `MY_PO_ENGINE=` drift.
3. `bash scripts/ci/run-install-smoke.sh` → non-interactive install passes in isolated `$HOME`.
4. `bash scripts/ci/check-dispatch-cost-strip.sh` → strip contract holds.
5. Full GitHub Actions run cannot execute locally — validated per-script.

## Outcome

### 변경 파일

1. **`.github/workflows/fresh-install-smoke.yml`** — Actions job wiring the four checks, least-privilege `contents: read`, push/PR-to-main + manual triggers.
2. **`scripts/ci/check-symlink-targets.sh`** — git-tracked absolute/HOME symlink-target lint (check b).
3. **`scripts/ci/check-env-key-parity.mjs`** — install.sh ↔ bootstrap-doctrine engine-key parity (check c).
4. **`scripts/ci/run-install-smoke.sh`** — isolated-`$HOME` non-interactive install harness + invariant asserts (check a).
5. **`scripts/ci/check-dispatch-cost-strip.sh`** — strip-hook fixture-driven contract check (check d).

### 로컬 검증 결과

- (a) install smoke — **PASS** (full install in isolated `$HOME`, all invariants hold).
- (b) symlink lint — **PASS** (no absolute-path symlink targets in tracked tree).
- (c) env-key parity — **FAIL (정상 — 실제 버그 검출)**. `install.sh` seeds canonical `MY_PO_ENGINE=claude`; `lib/bootstrap-doctrine.sh:82` seeds stale `engine=claude` into the same env file. This IS the "env seed key mismatch" the deferred candidate records. The check is correct; the underlying drift must be reconciled (one-token fix in bootstrap-doctrine.sh, outside this ticket's scope lock) before clean CI can pass.
- (d) dispatch-cost-strip — **PASS** (JSON strip, text strip, fast-path pass-through, no-cost pass-through all hold).

### 이탈 사항

Per scope lock (`.github/** + CI check scripts + lint hook ONLY`, do not rewrite install.sh / touch packages/gui), the fix to `lib/bootstrap-doctrine.sh` is NOT applied here — routed to PO. Until reconciled, AC-2 (clean install passes) cannot hold for check (c).
