# T-010: A8 — cmd 1/2/3/4 탭 단축키

> v0.5 Track A, item A8. 활성 탭 그룹(LeafPaneNode)에서 cmd+1/2/3/4 로
> Nth 탭으로 즉시 이동. N 이 탭 수보다 크면 no-op.

## Request

현재 탭 간 이동은 마우스 클릭 전용이다. 기획자가 여러 산출물 (PRD / 티켓 상세 / 디자인 파일 등)
을 탭으로 열어 두고 빠르게 전환할 방법이 없어 작업 흐름이 끊긴다.

cmd+1 ~ cmd+4 단축키를 추가해 활성 `LeafPaneNode` 의 `tabs[N-1]` (0-indexed) 를 바로 활성화한다.
탭이 N 개 미만이면 단축키는 아무 효과 없이 무시된다 (no-op).

범위:
- cmd+1 → `tabs[0]` / cmd+2 → `tabs[1]` / cmd+3 → `tabs[2]` / cmd+4 → `tabs[3]`
- 크로스-pane 이동 없음 — 항상 `activePaneId` 기준 `LeafPaneNode`
- cmd+5 이상은 이번 scope 밖

### KR

| # | 요건 |
|---|---|
| KR-1 | 활성 pane 에 ≥N 개의 탭이 있을 때 cmd+N 을 누르면 Nth 탭이 활성화된다 |
| KR-2 | 활성 pane 의 탭 수가 N 미만이면 cmd+N 은 아무 효과 없이 무시된다 |
| KR-3 | 입력 필드(input / textarea / contenteditable)에 포커스된 상태에서 cmd+1~4 는 동작하지 않는다 |
| KR-4 | 다른 기존 단축키(cmd+w / cmd+\\ / cmd+t / cmd+k / cmd+p)에 영향을 주지 않는다 |

  - 탭 제목 또는 탭 바 활성 인디케이터 기준으로 전환 확인.

- [ ] **[AC-3]** 활성 pane 에 탭이 4개 이상일 때 cmd+4 가 4번째 탭을 활성화한다.

### 구현 상세

#### `packages/gui/src/views/workspace/shell/useKeyboardShortcuts.ts`

**1. `KeyboardShortcutsParams` 인터페이스에 `setActiveTab` 추가**

```typescript
  splitRight: (paneId: string) => void
  splitDown: (paneId: string) => void

}
```

**2. `useKeyboardShortcuts` 파라미터 구조분해에 `setActiveTab` 추가**

```typescript
const { closeTab, closePane, splitRight, splitDown, addNewTab, setActiveTab } = params
```

**3. `onKeyDown` 핸들러에 cmd+1~4 분기 추가 (기존 `key === 'p'` 블록 이후)**

```typescript
// cmd+1 ~ cmd+4: jump to Nth tab in active leaf
const n = parseInt(key, 10)
if (n >= 1 && n <= 4) {
  e.preventDefault()
  const s = useWorkspace.getState()
  const leaf = findLeafByIdLocal(s.panes, s.activePaneId)
  if (leaf && leaf.tabs.length >= n) {
    setActiveTab(s.activePaneId, leaf.tabs[n - 1].id)
  }
  // no-op if leaf has fewer than n tabs
  return
}
```

- `parseInt(key, 10)` 는 `e.key` 가 `'1'~'4'` 일 때만 1~4 를 반환, 나머지 키는 NaN 이므로 `n >= 1 && n <= 4` 가 false.
- `leaf.tabs.length >= n` 조건이 no-op 분기를 처리한다.
- `targetIsEditable` 가드는 함수 최상단 `if (targetIsEditable(e) && ...)` 블록에 이미 적용되어 있어 입력 필드 포커스 시 조기 반환됨 (AC-4 자동 충족). 단, 현재 가드 조건 `e.key !== 'w' && e.key !== '\\'` 에 숫자 키 예외도 없으므로 `targetIsEditable` 반환 시 바로 skip — 추가 수정 불필요.

**4. `WorkspaceShell.tsx` 호출 측 업데이트**

`WorkspaceShell.tsx:58` 에서 `useKeyboardShortcuts` 를 호출할 때 `setActiveTab` 를 추가 전달한다.

```typescript
const setActiveTab = useWorkspace((s) => s.setActiveTab)
// ...
useKeyboardShortcuts({ closeTab, closePane, splitRight, splitDown, addNewTab, setActiveTab })
```

### no-op 처리 상세

| 조건 | 동작 |
|---|---|
| `leaf === null` (activePaneId 가 leaf 가 아닌 경우) | `if (leaf && ...)` false → skip |
| `leaf.tabs.length < n` | 조건 미충족 → skip (no-op) |
| `leaf.tabs.length >= n` | `setActiveTab(paneId, tabs[n-1].id)` 호출 |
