# T-009: A3 — Project 메뉴 정리

> v0.5 Track A, item A3. (a) File → Open Project = OS 폴더 다이얼로그 직접 (홈스크린 경유 제거),
> (b) File → Open New Window = 홈스크린 진입, (c) 홈스크린 Recent ↔ 상태바 Recent 단일 소스 통합.

## Request

현재 Project 관련 세 가지 흐름에서 UX 마찰이 있다.

**(a) File → Open Project 경로** — 현재 `menu:open-project` IPC → `WorkspaceShell` 의 `onMenuOpenProject` → `onBack()` → HomeView 로 돌아간 후 사용자가 [기존 폴더 열기] 를 다시 클릭해야 OS 다이얼로그가 열린다. 두 번의 클릭이 필요하며 의미 없는 홈스크린 중간 단계가 포함된다.
→ **Fix**: `App.tsx` 에서 `menu:open-project` 이벤트를 직접 구독해 `handleOpenFolder()` 를 즉시 호출한다. WorkspaceShell 이 `onBack()` 을 호출하는 경유 경로를 제거한다.

**(b) File → New Window 경로** — 현재 `main.ts` 의 `New Window` 클릭 핸들러가 `createWindow()` 를 그대로 호출한다. 새 윈도우는 `localStorage.getItem('productune.lastProject')` 의 lazy-init 로직에 의해 직전 열었던 프로젝트를 복원할 수 있다. 즉 같은 프로젝트가 두 윈도우에 동시에 열릴 수 있고, "새 윈도우 = 프로젝트 선택 화면" 이라는 PRD 의도와 다르다.
→ **Fix**: 새 윈도우는 항상 HomeView 에서 시작한다. `createWindow()` 호출 후 `did-finish-load` 에서 `reset-to-home` 이벤트를 보내고, App.tsx 에서 그 이벤트를 받으면 `setProject(null)` 을 실행한다.

**(c) Recent 단일 소스** — HomeView 는 `api.listProjects()` → `projects:list` IPC → `~/productune/projects/` 디렉터리 스캔으로 최근 프로젝트를 표시한다. StatusBar 는 현재 Recent 목록 UI 가 전혀 없다(현재 slug 표시만). PRD A3 에 따르면 홈스크린과 상태바 양쪽에 동일한 Recent 목록이 보여야 한다.
→ **Fix**: StatusBar 에 프로젝트 slug 를 클릭 가능한 버튼으로 만들고, 클릭 시 `api.listProjects()` 를 호출해 Recent 드롭다운을 표시한다. 드롭다운 항목 선택 시 `onOpenRecent(path, slug)` 콜백을 호출한다. 이렇게 하면 HomeView 와 StatusBar 모두 동일 IPC(`projects:list`)를 소스로 사용한다.

## Acceptance

### (a) Open Project

- [ ] **[AC-1]** 프로젝트가 열린 상태에서 File → Open Project 를 클릭하면 **홈스크린 전환 없이** OS 폴더 선택 다이얼로그가 즉시 열린다.
  - 프로젝트 워크스페이스 내에서 Cmd+O / 메뉴 클릭 → 다이얼로그 직접 열림. HomeView 가 렌더되지 않는다.
- [ ] **[AC-2]** 홈스크린 상태에서도 동일하게 동작한다 (다이얼로그 직접 열림).
  - 홈 → File → Open Project → 다이얼로그 열림.
- [ ] **[AC-3]** 다이얼로그에서 폴더 선택 시 기존 `handleOpenFolder()` 결과 처리 흐름(`self` / `descendant` / `install` / `legacy`)이 그대로 동작한다.

- [ ] **[AC-4]** File → Open New Window 클릭 시 새 윈도우가 열리고, 그 윈도우는 이전 프로젝트 복원 없이 HomeView 부터 시작한다.

- [ ] **[AC-5]** 기존 윈도우의 프로젝트 상태가 영향받지 않는다.
  - New Window 이후 기존 윈도우는 열던 프로젝트를 그대로 표시한다.

### (c) Recent single source

- [ ] **[AC-6]** HomeView Recent 목록과 StatusBar Recent 드롭다운에 동일한 프로젝트 목록이 같은 순서로 노출된다.
  - 두 곳의 항목 리스트가 `projects:list` IPC 반환 배열 기준 1:1 일치한다.
- [ ] **[AC-7]** StatusBar 에서 현재 프로젝트 slug 를 클릭하면 Recent 드롭다운이 열린다.
  - 드롭다운에 최근 프로젝트 목록이 나타난다.
- [ ] **[AC-8]** StatusBar Recent 드롭다운에서 다른 프로젝트를 선택하면 해당 프로젝트가 열린다.
  - 선택한 프로젝트로 전환된다 (`onOpenRecent` 호출 → `setProject` 실행).

### (a) Open Project — 직접 다이얼로그 흐름

#### `packages/gui/src/views/WorkspaceShell.tsx`

`useEffect` 블록에서 `onMenuOpenProject` 구독을 제거한다.

변경 전:
```typescript
const offNew  = api.onMenuNewProject?.(() => onBack())
const offOpen = api.onMenuOpenProject?.(() => onBack())
return () => { offNew?.(); offOpen?.() }
```

변경 후:
```typescript
const offNew = api.onMenuNewProject?.(() => onBack())
return () => { offNew?.() }
```

#### `packages/gui/src/App.tsx`

`onMenuOpenProject` 를 `App` 레벨에서 구독해 `handleOpenFolder()` 를 즉시 호출한다.
기존 `onMenuNewProject` 구독이 있는 `useEffect` 와 별도로, App 최상위에 신규 `useEffect` 추가:

```typescript
useEffect(() => {
  const unsub = (window as any).api.onMenuOpenProject?.(() => {
    handleOpenFolder()
  })
  return () => unsub?.()
}, []) // eslint-disable-line react-hooks/exhaustive-deps
```

위치: `handleOpenFolder` 함수 정의 이후, 기존 `onOpenRecentProject` 구독 useEffect 인근.

### (b) New Window — 항상 HomeView 시작

#### `packages/gui/electron/main.ts`

`New Window` 메뉴 클릭 핸들러를 수정한다.

변경 전:
```typescript
click: () => createWindow(),
```

변경 후:
```typescript
click: () => {
  const win = createWindow()
  win.webContents.once('did-finish-load', () => {
    win.webContents.send('reset-to-home')
  })
},
```

`createWindow()` 가 `BrowserWindow` 를 반환하도록 수정 (현재 반환값 없음):
```typescript
function createWindow(): BrowserWindow { ... return win }
```

#### `packages/gui/electron/preload.ts`

`onResetToHome` 브리지 추가 (기존 `onOpenRecentProject` 패턴과 동일):
```typescript
onResetToHome: (cb: () => void) => {
  const listener = () => cb()
  ipcRenderer.on('reset-to-home', listener)
  return () => ipcRenderer.removeListener('reset-to-home', listener)
},
```

#### `packages/gui/src/App.tsx`

`reset-to-home` 이벤트를 구독해 `setProject(null)` 실행:
```typescript
useEffect(() => {
  const unsub = (window as any).api.onResetToHome?.(() => {
    try { localStorage.removeItem('productune.lastProject') } catch { /* unavailable */ }
    setProject(null)
  })
  return () => unsub?.()
}, []) // eslint-disable-line react-hooks/exhaustive-deps
```

### (c) Recent 단일 소스 — StatusBar 드롭다운

#### `packages/gui/src/components/workspace/StatusBar.tsx`

Props 에 `onOpenRecent` 콜백 추가:
```typescript
interface Props {
  onOpenHealthBanner?: () => void
  onOpenRecent?: (projectDir: string, slug: string) => void
}
```

컴포넌트 내부:
- `useState<Array<{ slug: string; created_at: string; path: string }>>` 로 recents 상태 관리.
- `useState<boolean>` 으로 드롭다운 표시 상태 관리.
- project slug 를 `<button>` 으로 변경 (현재 `<span>`). 클릭 시 `api.listProjects()` 호출 후 recents 세팅 + 드롭다운 토글.
- 드롭다운은 StatusBar 위로 올라오는 `position: absolute, bottom: 28px` 소형 팝업 (`background: '#1A1A1A'`, `border: '1px solid #2A2A2A'`, `borderRadius: 6`).
- 드롭다운 항목 클릭 → `onOpenRecent(path, slug)` 호출 + 드롭다운 닫기.
- 드롭다운 외부 클릭 시 닫힘 (`useEffect` + `mousedown` 이벤트로 `dropdownRef` 외부 감지).
- 드롭다운이 열릴 때 현재 프로젝트 slug 와 동일한 항목은 `color: '#505050'` 으로 dimmed 표시 (현재 위치 시각화, 클릭 무반응).
- icon: lucide-react `ChevronDown` (10px) — slug 버튼 오른쪽에 인라인 배치.

#### `packages/gui/src/views/WorkspaceShell.tsx`

`StatusBar` 에 `onOpenRecent` prop 전달. WorkspaceShell 은 `onBack` 을 받으므로, 내부에서는 `project` switch = `onBack()` 호출 후 App.tsx 의 `openRecent` 경로로 흘러가면 안 된다. 대신 `WorkspaceShell` 의 Props 를 확장하거나, App-level 의 `openRecent` 를 prop-drilling 한다.

**권장 방법 (prop drilling 최소화)**: `WorkspaceShell` Props 에 `onOpenRecent: (projectDir: string, slug: string) => void` 추가. `App.tsx` 에서 `<EntryGate>` → `<WorkspaceShell>` 로 `App` 의 `openRecent` 함수를 전달.

`EntryGate.tsx` 도 `onOpenRecent` prop 을 받아 `WorkspaceShell` 로 투과 (pass-through). 변경 파일 추가: `packages/gui/src/components/EntryGate.tsx`.

#### `packages/gui/src/App.tsx`

`EntryGate` 에 `onOpenRecent={openRecent}` prop 추가:
```tsx
<EntryGate project={project} onBack={() => setProject(null)} onOpenRecent={openRecent} />
```
