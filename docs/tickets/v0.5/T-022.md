# T-022: Small UI additions — tab shortcut cmd+1~9 + artifact zoom (#9, #13)

> Phase 3-B. Two small, independent additions. Light design: confirm zoom-button placement /
> step against design-system tokens; no full mockup.

## Request

### #9 — Extend tab shortcut cmd+1~4 → cmd+1~9
Extend the active-pane tab shortcut (T-010) to activate the Nth tab for N = 1…9; no-op if the pane
has fewer than N tabs.
- Site: `useKeyboardShortcuts.ts:91-98` — currently `n >= 1 && n <= 4`. Change to `<= 9`; keep the
  bounds guard (`leaf.tabs[n-1]` exists).

### #13 — Artifact detail viewer +/- zoom buttons
The artifact detail viewer clips content. Add +/- zoom buttons (and reset) to control content
scale / font-size. Mermaid viewer (`ArtifactMermaidTab.tsx`) already has zoom — match its pattern
and tokens; add zoom to the md/detail artifact viewer that lacks it.
- Design (light): place zoom controls consistently with existing viewer chrome, lucide-react icons
  (`ZoomIn` / `ZoomOut`, plus a reset), design-system R4 tokens, no color emoji.

## Acceptance

- [ ] **[AC-1]** cmd+1 … cmd+9 activate the 1st…9th tab of the active pane; no-op beyond tab count.
- [ ] **[AC-2]** The artifact detail viewer has working +/- zoom (and reset); content no longer
      clips at default zoom for typical artifacts.
- [ ] **[AC-3]** Zoom controls use lucide-react icons + design-system tokens; visually consistent
      with the Mermaid viewer.
- [ ] **[AC-4]** `pnpm tsc --noEmit` passes.

## Plan

1. Widen the digit bound in `useKeyboardShortcuts.ts` to 9 (#9).
2. Lift/extract the Mermaid viewer's zoom control into the md/detail artifact viewer; wire scale
   state + buttons (#13).

## Out of scope

- Pinch-to-zoom / trackpad gestures; persisting zoom level across sessions.
