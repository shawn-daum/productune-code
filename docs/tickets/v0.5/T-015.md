# T-015: Build — A6 cmd+p 헤더 검색 확장

## Request

### EN (master)

Implement **A6 — cmd+p header expansion** per PRD v0.5 item A6 and the design artifacts
`T-005-a6-flow.md` / `T-005-a6-mockup.html`.

**Scope (IN)**

- **Inline search bar in the GUI header**: always visible, center-aligned in the header
  row (between brand mark and tool icons). Collapsed state = compact placeholder pill
  (`검색 — 티켓 · 탭 · 스킬 · MCP · 산출물 · 페르소나` + `⌘P` kbd badge). Clicking the
  bar fires the same `productune:quick-open` custom event as `cmd+p`.
- **QuickOpenPalette extended to 6 categories**: extend `QuickOpenItem` with a `category`
  discriminant field and add 3 new index sources (tabs, MCP, artifacts) alongside the 3
  existing (tickets, skills, personas). Files index stays reachable but is not a
  headline category.
- **Fixed section order** in results: tickets → tabs → skills → MCP → artifacts →
  personas (regardless of score). Ranking decides the default-active row only.
- **Category-scoping prefixes**: `t:` / `tab:` / `s:` / `mcp:` / `a:` / `p:`.
  With a prefix only that section renders; without one all 6 compete.
- **Empty (resting) state**: recent/suggested rows + 6-category legend (prefix chips).
  Never a dead panel.
- **No-match state**: single `"결과 없음"` row + scope hint + `Esc` affordance.
- **Routing intents** on commit (palette closes after each):
  - `ticket` → emit `ticket-open { ticketId }` — calls `openTab` with
    `type: 'ticket-detail'` (A7 seam; T-016 is the rendering owner).
  - `tab` → `tab-focus { tabId }` — call `useWorkspace.getState().setActiveTab` for the
    tab's pane; if the tab was closed, re-open via `openTab`.
  - `skill` → `skill-invoke { skillId }` — call the existing `item.open()` action
    (skill items already carry an `open` callback in `buildQuickOpenItems`).
  - `mcp` → `mcp-open { serverId, entryId }` — call `openTab('mcp-servers', 'mcp-servers',
    { serverId, entryId })`.
  - `artifact` → `artifact-open { path }` — call `openTab` with the same routing logic
    as `ArtifactsPane` (ext → `artifact-md` / `artifact-mermaid` / `browser`, tab id =
    `artifact:<relPath>`). T-014 owns the viewer; A6 only calls `openTab`.
  - `persona` → `persona-open { personaId }` — call `openTab` with `type: 'persona-def'`.

**Scope (OUT)**

- Full-text content search inside artifact files (path/title/metadata match only).
- Any changes to the viewer surfaces (A2 T-014, A7 T-016, persona-def, mcp-servers tab
  content — A6 only emits the intent).
- Skills tab content or MCP tab content changes.

### 3. Palette rendering — `QuickOpenPalette.tsx`

**Replace the flat `filterAndSort` output with a grouped render:**

```ts
type GroupedResults = {
  [K in QuickOpenItem['category']]?: QuickOpenItem[]
}

function groupResults(items: QuickOpenItem[], query: string): GroupedResults {
  const scored = filterAndSort(query, items)  // existing scoring, unchanged
  const groups: GroupedResults = {}
  for (const item of scored) {
    if (!item.category) continue  // skip 'file' source — no headline category
    if (!groups[item.category]) groups[item.category] = []
    groups[item.category]!.push(item)
  }
  return groups
}
```

**Category prefix parsing** — strip the prefix before scoring if detected:

```ts
function parseCategoryPrefix(query: string): {
  filteredCategory: QuickOpenItem['category'] | null
  strippedQuery: string
} {
  const MAP: Record<string, QuickOpenItem['category']> = {
    't:': 'tickets', 'tab:': 'tabs', 's:': 'skills',
    'mcp:': 'mcp', 'a:': 'artifacts', 'p:': 'personas',
  }
  for (const [prefix, cat] of Object.entries(MAP)) {
    if (query.startsWith(prefix)) {
      return { filteredCategory: cat, strippedQuery: query.slice(prefix.length) }
    }
  }
  return { filteredCategory: null, strippedQuery: query }
}
```

**Rendering** — replace the current flat `results.map(…)` with:

```tsx
// Empty/resting state (query === '')
if (!query) {
  return <RestingState items={items} />   // recent rows + legend chips
}

// Grouped results
const { filteredCategory, strippedQuery } = parseCategoryPrefix(query)
const groups = groupResults(
  filteredCategory ? items.filter(i => i.category === filteredCategory) : items,
  strippedQuery,
)
const hasAny = SECTION_ORDER.some(cat => (groups[cat]?.length ?? 0) > 0)
if (!hasAny) {
  return <NoMatchState />   // "결과 없음" + hint
}
return SECTION_ORDER.map(cat => {
  const rows = groups[cat]
  if (!rows || rows.length === 0) return null
  return <SectionGroup key={cat} category={cat} rows={rows} ... />
})
```

**`RestingState`** (new sub-component): renders max 5 recent/suggested items (persisted
in `localStorage` key `productune:quickopen:recent` as `string[]` of item ids, updated
on each commit) + 6 legend chips (`t: 티켓`, `tab: 탭`, `s: 스킬`, `mcp: MCP`,
`a: 산출물`, `p: 페르소나`).

**`NoMatchState`** (new sub-component): search icon + `"결과 없음"` + scope hint text
+ `Esc` kbd badge. Mirrors the mockup `nomatch` block.

**`SectionGroup`** (new sub-component): section header row (`--text-muted`, uppercase,
xs, prefix badge right-aligned) + mapped `ResultRow` for each item.

**`ResultRow`** — extend current row to render `meta` fields:
- `meta.statusPill` → small pill badge (reuse ticket-status color map from T-003).
- `meta.typeBadge` → monospace version pill (`open` / `md` / `html` / `mmd`).
- `meta.connectionDot` → 7px circle, `--health-success` (on) or `--text-disabled` (off).
- `meta.personaDot` → 8px persona color circle using persona hex map.

**Accent token fix**: in `rowStyle`:
```ts
borderLeft: active ? '2px solid #8B5CF6' : '2px solid transparent',
```
(was `#FF6B2B` — stale pre-T-006 value).

**Flat `activeIdx`** — convert to a flat cursor across all rendered rows in section

default-active row on open is the highest-scoring row across all sections (the current
