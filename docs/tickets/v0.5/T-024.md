# T-024: Explorer code-content search (#6)

> Phase 3-B, design-bearing. Assignee starts pdt-designer (UX), then pdt-developer for impl.

## Request

Add VS-Code-style full-text content search to the Explorer tab: search across project files, show a
results list, and open the file at the match on click.

- **Input**: search box in the Explorer panel; supports a plain query (case-insensitivity / regex /
  whole-word options to be decided at design).
- **Results**: grouped by file, each result showing the matching line + line number; click opens the
  file in a tab scrolled/highlighted at the match. Match highlights use the design-system **accent**
  color — no amber anywhere; accent for all highlight and active states.
- **Scope default**: whole project. The scope selector shows at minimum a "whole project" mode;
  fixed ignore rules exclude `node_modules`, `.git`, and `build` output automatically. Include/exclude
  glob fields are **out of scope for v0.5** (future follow-up).
- New IPC for the file-content search (the existing file scan is path-only — content grep is new).

## Acceptance

- [ ] **[AC-1]** A content-search input is present in the Explorer tab.
- [ ] **[AC-2]** Searching returns results grouped by file with line number + matching line text.
- [ ] **[AC-3]** Clicking a result opens the file at the matching line.
- [ ] **[AC-4]** Search excludes ignored dirs (node_modules/.git/build) and stays responsive on the
      productune repo (no UI freeze on a multi-hundred-file search).
- [ ] **[AC-5]** Default scope is whole project; no glob include/exclude fields are present in the UI.
- [ ] **[AC-6]** Match highlight color is the design-system accent; no amber color appears anywhere
      in the search UI (results list, active state, highlight).
- [ ] **[AC-7]** Uses lucide-react icons + design-system tokens; `pnpm tsc --noEmit` passes.

## Plan

**Designer to detail at design time** (input affordance, results list layout, scope selector,
empty/loading/too-many-results states — against `docs/designer/design-system.md`). Baked-in
decisions (no designer input needed): match highlight = accent color, scope default = whole project,
no glob fields in v0.5. Implementation: a new content-search IPC (ripgrep-style streaming or chunked
read; debounced query; ignore-rule honoring) + results UI + open-at-match wiring into the existing
openTab path. Design gates impl.

## Out of scope

- Search-and-replace; cross-project / indexed search; binary-file search.
- Include/exclude glob fields (future follow-up after v0.5).
