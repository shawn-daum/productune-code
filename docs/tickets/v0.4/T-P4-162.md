## §4 Implementation plan

### Step 1 — 신규 hook 스크립트 신설
파일: `packages/core/scripts/hooks/post-bash-strip-cost.sh`

```bash
#!/usr/bin/env bash
# Claude Code hook — PostToolUse, matcher: Bash
# Strips cost/usage fields from claude --agent --output-format json envelope
# before PO surfaces the result to the user.
# Fields removed: total_cost_usd, modelUsage, usage
# Pass-through: non-JSON input, JSON without target fields, jq failure.

set +e

RAW="$(cat 2>/dev/null || true)"
[ -z "$RAW" ] && exit 0

# Quick check — skip non-JSON and JSON without cost fields (fast path)
case "$RAW" in
  *"total_cost_usd"*) ;;
  *) printf '%s\n' "$RAW"; exit 0 ;;
esac

# Attempt jq strip; on failure fall back to original
STRIPPED="$(printf '%s\n' "$RAW" | jq 'del(.total_cost_usd, .modelUsage, .usage)' 2>/dev/null)"
if [ $? -eq 0 ] && [ -n "$STRIPPED" ]; then
  printf '%s\n' "$STRIPPED"
else
  printf '%s\n' "$RAW"
fi

exit 0
```

### Step 2 — `install.sh` `merge_claude_settings_hooks()` 수정

`merge_claude_settings_hooks()` 함수 내:

1. `local strip="$hooks_dir/post-bash-strip-cost.sh"` 변수 추가.
2. `is_pdt()` 에 `or (cmd | endswith("/scripts/hooks/post-bash-strip-cost.sh"))` 추가.
3. `.hooks.PostToolUse` 빌드 구문에 항목 추가:
   ```jq
   {matcher: "Bash", hooks: [{type: "command", command: $strip}]}
   ```
   기존 `$statew` entry 뒤에 삽입.
4. `jq` 호출 인자 목록에 `--arg strip "$strip"` 추가.

> **주의:** `PRODUCTUNE_HOOKS_INSTALLED` 가 이미 `true` 로 세팅된 기존 설치는
> `install.sh` 재실행 시 guard 를 건너뜀. 기존 사용자는 `install.sh` 재실행이 필요.
> 또는 `~/.productune/productune.env` 에서 `PRODUCTUNE_HOOKS_INSTALLED=true` 라인을
> 삭제 후 재실행하면 hook 재등록됨 (install.sh 는 idempotent).

### Step 3 — `uninstall.sh` 정리 (선택, 있을 경우)

`uninstall.sh` 가 settings.json hook 제거 로직을 갖고 있다면
`post-bash-strip-cost.sh` 를 제거 대상 목록에 포함.
