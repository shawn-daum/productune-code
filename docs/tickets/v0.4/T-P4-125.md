- `onboarding:listOllamaModels` → `string[]` of installed `model:tag`.

  Ollama install (없으면) + LLM model pull + nomic-embed-text pull.
- `onboarding:setupGraphiti` → stream progress + `{ ok, error? }`. spawn `bash
  $coreDir/scripts/setup-graphiti.sh`.
- `onboarding:registerGraphitiMCP` → `{ ok, alreadyRegistered, error? }`. 동일
  로직 (claude mcp list / add).

preload `api` 노출 동시 갱신.
