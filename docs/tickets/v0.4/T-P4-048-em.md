## §2 Implementation Spec

### 2(A) Environment — Settings sidebar 3 nav row

`pp-sec-hdr` "환경 변수" + 하단 3 nav row:

```
환경 변수  ← pp-sec-hdr (divider 포함, non-interactive)
  › 프로젝트 .env              (N)    → env-view {layer:'project'}
  › 프로젝트 시크릿            (N)    → env-view {layer:'secrets'}
  › 사용자 전역                (N)    → env-view {layer:'global'}
```

**count badge spec**:
- `env:getCount({ layer, projectDir })` → `number | null`
- count 결과 있음 → `(N)` 표시 (`--text-muted`, 12px). `(0)` 도 표시 (파일 존재 but 빈 상태 구분)
- null (파일 없음 / 읽기 실패) → badge 없음
- mount 시 전체 layer 병렬 fetch; fetch 완료 전 = skeleton dot `(·)` 임시 표시 (§1.5.4 Feedback)

**openTab 호출**:

```ts
openTab('env-view-project', 'env-view', { layer: 'project' }, '프로젝트 .env')
openTab('env-view-secrets', 'env-view', { layer: 'secrets' }, '프로젝트 시크릿')
openTab('env-view-global',  'env-view', { layer: 'global'  }, '사용자 전역')
```

Tab ID가 layer별로 고유 → 3개 탭 동시 열기 가능 (독립 singleton 아님). 재클릭 = focus.

**data source**:

| layer | 파일 경로 |
|:--|:--|
| `project` | `<project>/.env` |
| `secrets` | `<project>/.env.local` |
| `global` | `~/.productune/productune.env` |

`env:getCount()` = `KEY=VALUE` 패턴 라인 수 (comment `#`, 빈 라인 제외).

### 2(B) Environment — EnvViewTab UI shell (stub 상태)

T-P4-030~033 land 전까지 stub skeleton 상태로 동작. 컴포넌트 구조 spec:

```
EnvViewTab
  ├── LayerHeader (layer 라벨 + 파일 경로)
  ├── StubNotice  (--health-info 배너)
  ├── VariableTable
  │     ├── TableHeader (이름 / 값 / 환경 / 상태)
  │     ├── VariableRow × 3  ← skeleton placeholder (gray animated ████)
  │     └── EmptyRow (파일 없음 / 변수 0개 — T-P4-031 land 후 실 데이터)
  ├── AddVariableForm  ← disabled (stub 명시)
  └── (DeleteConfirmModal — T-P4-032 land 후 활성화)
```

**stub 상태 구현**:
- `VariableRow` 3개 = 이름/값 모두 skeleton (`████`, gray animated background)
- `StubNotice` = `--health-info` 배너 텍스트: `"환경 변수 기능은 Round 3에서 완성돼요. 지금은 파일을 직접 열 수 있어요."` + CTA `[파일 열기]` → `openTab('markdown:env-project', 'markdown', { path: '<project>/.env' })`
- `AddVariableForm` = disabled (stub 상태 tooltip 표시)
- stub notice = T-P4-032 complete 시 제거 (별 PR)

**status badge 토큰 매핑** (T-P4-031 visual SoT — stub에서 참조만):

| badge | 조건 | 색 token | lucide 아이콘 |
|:--|:--|:--|:--|
| ✅ 동기됨 | 전체 layer 동기 | `--health-success` | `check-circle-2` 14px |
| ⚠️ 프로덕션 없음 | 로컬 있음, prod 없음 | `--health-warn` | `alert-triangle` 14px |
| 🔴 로컬 없음 | prod 있음, 로컬 없음 | `--health-error` | `x-circle` 14px |
| 🔒 시크릿 | secret (masked) | `--border-muted` (neutral) | `lock` 14px |

**secret masking** (T-P4-031 구현, 본 ticket = 컴포넌트 slot 준비):
- 값 = `••••••••` (8 dots, 실제 길이 노출 X)

- timer 표시 권장: "5초 후 숨겨짐"
- clipboard copy 버튼 → reveal 없이 직접 복사 → toast "복사됐어요"
