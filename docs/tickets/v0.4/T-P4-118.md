## §1 Background

**사용자 verbatim (dogfood 리포트):**
> "caveman skill 이 persona spec 에 적용됐는데 GUI skill matrix 에 노출 안 됨"

- `~/.claude/skills/mattpocock/skills/productivity/caveman/SKILL.md` 는 실제로 설치돼 있지만,

삽입된 것이며, T-P4-098 이 완료된 시점에 제거 예정이었으나 누락됐다.

## §2 Scope

### A. Electron IPC handler `skills:list` — `main.ts`

위치: `packages/gui/electron/main.ts` (기존 IPC 핸들러 블록 말미에 추가).

```
ipcMain.handle('skills:list', async () => { … })
```

구현 세부:
1. `const skillsRoot = path.join(os.homedir(), '.claude', 'skills')` 로 경로 확정.
2. `fs.existsSync(skillsRoot)` 로 존재 여부 확인. 없으면 `[]` 반환 (error 아님 — empty state CTA 는 renderer 처리).
3. `fs.readdirSync` 재귀 또는 `fs.globSync` / 수동 recursive walk 로 `**/*.md` 수집.
   - Node 내장 `fs` 만 사용 (외부 glob 라이브러리 추가 불가).
   - `deprecated/` 디렉터리 포함 여부: **포함** (필터는 renderer 담당).
4. 각 파일에 대해:
   - 파일 내용 `fs.readFileSync(filePath, 'utf8')`.
   - YAML frontmatter 파싱: `---\n…\n---` 블록 (정규식으로 직접 추출 — js-yaml 등 추가 라이브러리 없이).
   - `name` 필드: frontmatter 에 있으면 사용, 없으면 path 의 마지막 디렉터리 이름 (`path.basename(path.dirname(filePath))`).
   - `description` 필드: frontmatter 에 있으면 사용, 없으면 `""`.
   - `personas` 필드: frontmatter `personas:` 있으면 파싱 (array 또는 comma-string 모두 처리). 없으면 §D 경로 추론 heuristic 적용.
   - `id`: `skillsRoot` 기준 상대 경로 (예: `mattpocock/skills/productivity/caveman/SKILL.md`).
5. `SkillEntry[]` 배열 반환.

### C. `SkillMatrixTab.tsx` 갱신

1. **`SKILL_CATALOG` const + `SkillRow` interface 제거** (파일 상단 static catalog 블록 전체).
2. **`SkillEntry` import** from `../../../../lib/types`.
3. **`useEffect` + state 추가**:

```ts
const [skills, setSkills] = useState<SkillEntry[]>([])
const [loading, setLoading] = useState(true)

useEffect(() => {
  let cancelled = false
  setLoading(true)
  window.api.listSkills().then((entries) => {
    if (!cancelled) {
      setSkills(entries)
      setLoading(false)
    }
  })
  return () => { cancelled = true }
}, [])
```

4. **window focus re-fetch** (skills directory 갱신 detect):

```ts
useEffect(() => {
  const refetch = () => {
    window.api.listSkills().then(setSkills)
  }
  window.addEventListener('focus', refetch)
  return () => window.removeEventListener('focus', refetch)
}, [])
```

5. **`filteredSkills` useMemo** — `SKILL_CATALOG` 대신 `skills` state 참조.
   `SkillEntry.personas` 타입이 `PersonaCol[]` 이므로 기존 filter 로직 변경 최소화.

6. **loading state UI**:
   - `loading === true` 일 때: table 영역 대신 `<div style={loadingPane}>Scanning skills…</div>` 표시.
   - 토큰: `color: '#505050'`, `fontSize: 12`, `padding: '24px 16px'`.

7. **empty state** (`loading === false && skills.length === 0`):
   - `EmptyPane` 스타일 텍스트: `~/.claude/skills/ 에 설치된 skill 없음` + secondary: `skill install 후 다시 시도하세요`.
   - T-P4-069 §1.5.1 EmptyPane 패턴 정합 (기존 코드 내 동일 패턴 참조).

8. **`focusRow` scroll** 로직: 기존 `useEffect([focusRow])` 유지. `skills` state 로드 후 scroll 되도록 `deps` 에 `loading` 추가 (`[focusRow, loading]`).

### D. `lib/types.ts` — `SkillEntry` interface 추가

```ts
// ── Skill catalog entry (T-P4-118 — IPC dynamic scan) ─────────────────────────

/** Persona column keys — mirrors SkillMatrixTab PersonaCol. */
export type SkillPersona = 'po' | 'designer' | 'dev' | 'qa'

/**
 * A single skill entry returned by the `skills:list` IPC handler.
 * `id`       — relative path from ~/.claude/skills root (slash-separated).
 * `name`     — frontmatter `name` field, or last-directory fallback.
 * `description` — frontmatter `description` field, or "".
 * `personas` — frontmatter `personas` array, or path-inference result, or [].
 * `filePath` — absolute path (for future deep-link / viewer).
 */
export interface SkillEntry {
  id: string
  name: string
  description: string
  personas: SkillPersona[]
  filePath: string
}
```

`SkillMatrixTab.tsx` 의 `PersonaCol` 타입은 `SkillPersona` 로 교체하거나 local alias 유지 — 어느 쪽이든 무방. `PERSONA_COLS`, `PERSONA_INITIALS`, `PERSONA_COLORS` 는 그대로 유지.

### E. Personas mapping heuristic (main.ts 내 helper)

frontmatter `personas:` 없을 때 path 기반 추론:

| 경로 패턴 | personas 매핑 |
|:----------|:-------------|
| `mattpocock/skills/productivity/**` | `['po', 'designer', 'dev', 'qa']` (all) |
| `mattpocock/skills/engineering/**` | `['dev']` |
| `mattpocock/skills/deprecated/**` | `[]` (no assign — assignedOnly filter 로 숨김) |
| `mattpocock/skills/misc/**` | `['dev']` |
| `mattpocock/skills/personal/**` | `[]` |
| `phuryn/pm-*/skills/**` | `['po', 'designer']` |
| 그 외 | `[]` (default — renderer 에서 assignedOnly=false 시 노출) |

패턴 매칭: `filePath.includes(...)` 단순 순서 우선 체크. 정규식 불필요.

### F. Error / empty state

- `~/.claude/skills/` 디렉터리 자체가 없는 경우: IPC 핸들러 `[]` 반환 (throw 없음).
- renderer: `skills.length === 0 && !loading` 일 때 §C-7 EmptyPane 표시.
- IPC 호출 실패(예: 권한 오류): `catch` 에서 `[]` set + `loading: false`. 에러 toast 는 미포함 (Phase 5 error boundary 에서 처리).

### G. Cache / re-fetch 정책

- 첫 마운트 1회 IPC call (§C-3).
- window `focus` 이벤트마다 re-fetch (§C-4) — skills 디렉터리 변경 detect용.
- Store (zustand/redux) 캐시 레이어는 **미포함** (L2 scope). re-fetch latency ~수ms (fs scan).
- Phase 5 inotify/FSWatcher 연동은 별도 티켓.
