# T-P4-089: Onboarding Step 0 — 언어 카드 설명 문구 제거

> Onboarding wizard Step 0 (Language) 의 English / 한글 카드에서 카드 내부 설명 (`optionEnDesc` / `optionKoDesc`) 과 카드 상단 hint (`step0.hint`) 제거. 카드 = 라벨 + 선택 outline 만.

## §1 Background

사용자 directive (2026-05-11):

> "onboarding할때 언어선택할때 english 한글 밑에 뭐 설명들이 있는데 그거 다 빼줘"

### 현 동작 (T-P4-056 land 산출물)

`packages/gui/src/views/OnboardingWizard.tsx` L242~276 의 Step 0 (Language select):

1. **카드 상단 hint** (L249~251) — `step0.hint` = `"(You can change this later in Settings.)"` / `"(나중에 Settings에서 바꿀 수 있습니다.)"`
2. **카드 내부 설명** — `OptionCard intro` 로 전달되는 `step0.optionEnDesc` (`"Standard interface language."`) + `step0.optionKoDesc` (`"한국어 인터페이스 (페르소나 응답은 별도 설정)"`). `OptionCard` 컴포넌트 (L573~608) 가 `intro` 를 `paddingLeft: 24` 텍스트로 카드 안에 렌더.

### 의도

언어 카드는 단순 선택 — 라벨 (`English` / `한글`) + 선택 시 outline (`#FF6B2B`) 만 보이면 충분. 부가 설명 / hint 제거로 §1.5 Few Things 정합 강화.
