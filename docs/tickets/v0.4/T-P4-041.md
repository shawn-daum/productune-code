## 3. State

Augment `useWorkspace` (existing slice has `messages`, `streaming`, `claudeSessionId`). Extend `Message` type with persona kind:

```ts
// src/lib/types.ts
export type MessageKind = 'po' | 'designer' | 'dev' | 'qa' | 'trace' | 'user'

export interface Message {
  id: string
  role: 'user' | 'assistant' | 'system'
  kind: MessageKind            // NEW — drives bubble style
  text: string
  status?: 'streaming' | 'done' | 'cancelled'
  created_at: string
}
```

Backwards compat: load existing chat.json without `kind` → fallback `role==='user' ? 'user' : 'po'`. No migration script needed (chat.json is per-project ephemeral).

New separate slice `usePoChat` (file `src/store/poChat.ts`) for chat-only state to avoid bloating `useWorkspace`:

- `panelVisible: boolean` (default `true`) — controls collapse / FAB
- `nextDelegate: 'pdt-po' | 'pdt-designer' | 'pdt-developer' | 'pdt-qa'` — selector value
- `inputDraft: string` — textarea controlled value
- `autoScrollLocked: boolean` — true when user scrolls up; false when at bottom
- `sending: boolean` (mirrors workspace.streaming during a turn)

Actions: `setPanelVisible`, `setNextDelegate`, `setDraft`, `setAutoScrollLocked`, `setSending`.

## 4. IPC channels

### existing (already wired)

```
chat:getSession           (projectDir) → Session
chat:appendMessage        (projectDir, message)
chat:setClaudeSessionId   (projectDir, sessionId)
chat:clearSession         (projectDir)
```

### new (this ticket)

```
po:sendMessage            (projectDir, opts) → { ok, error? }
   opts = { text, persona?: 'pdt-po'|..., resume?: string }
events emitted on event.sender:
  po:onToken               (msgId, chunk) — streaming text
  po:onAnnounce            (msgId, payload) — trace/tool events
  po:onDone                (msgId, { sessionId? })
```

`msgId` is generated in main right after spawn, sent first, used by renderer to anchor an in-progress assistant message. This avoids a race where user enter → empty assistant placeholder gets two streams.

### claude CLI spawn strategy

Doctrine (`packages/core/po/po-instructions.md`):

```
NO_COLOR=1 claude --agent pdt-po --model <model> --print --output-format json "$TASK"     # first turn
NO_COLOR=1 claude --resume "$SID" --model <model> --print --output-format json "$TASK"    # resume
```

For chat streaming we want token-level progress, so override `--output-format` with `stream-json` instead of `json` (claude CLI supports both; doctrine uses `json` because PO consumers parse one envelope, but UI wants tokens).

Spawn — when PO env file exists (`~/.productune/productune.env`) and `claude` is on PATH:

```ts
const args = [
  ...(sessionId ? ['--resume', sessionId] : ['--agent', 'pdt-po']),
  '--print',
  '--output-format', 'stream-json',
  '--verbose',  // stream-json requires --verbose
  text,
]
const env = { ...process.env, NO_COLOR: '1' }
const child = spawn('claude', args, { env, cwd: projectDir, stdio: ['ignore', 'pipe', 'pipe'] })
```

stream-json envelope (claude CLI ≥ 1.0):

```jsonl
{"type":"system","subtype":"init","session_id":"abc-…"}
{"type":"assistant","message":{"content":[{"type":"text","text":"hello"}]}}
{"type":"assistant","message":{"content":[{"type":"text","text":" world"}]}}
{"type":"result","subtype":"success","session_id":"abc-…","result":"…"}
```

Parser in main process (line-buffered, JSONL):

- `system.init` → capture `session_id`, persist via `chat:setClaudeSessionId`.
- `assistant` with text content → emit `po:onToken` for each text chunk.
- `assistant` with `tool_use` → emit `po:onAnnounce` (trace bubble: `→ tool: <name>`).
- `result` → emit `po:onDone`.
- stderr lines → emit `po:onAnnounce` with kind `error`.

### dev fallback (no claude installed)

If `which claude` fails OR env file missing, enter **echo mode**: spawn a 200 ms setTimeout that emits a few synthetic `po:onToken` chunks with the text echoed back. Lets the UI / dogfood path work in CI / dev without a paid claude. Logs `[po:sendMessage] echo mode (claude not installed)` to console. Acceptance still verifiable: bubbles render, streaming animates, persistence works.

## 5. Streaming + auto-scroll

Renderer wires three subscribers in `ChatPanel.useEffect` on mount:

```ts
api.poOnToken((msgId, chunk) => appendToMessage(msgId, chunk))
api.poOnAnnounce((msgId, payload) => addTraceMessage(payload))
api.poOnDone((msgId, { sessionId }) => finishMessage(msgId, sessionId))
```

Auto-scroll: a ref on `rp-msgs` div. On every messages change → if `!autoScrollLocked` scroll to bottom. On scroll event → if `(scrollTop + clientHeight) < scrollHeight - 24` set `autoScrollLocked=true`; if back at bottom unset.

## 6. Input behavior

`textarea` controlled by `inputDraft`. `onKeyDown`:

- `Enter` (no shift, no IME composition): preventDefault → submit → clear draft.
- `Shift+Enter`: default behavior (newline).
- IME composition guard: skip Enter if `e.nativeEvent.isComposing` (avoids cutting Korean input).

Submit flow:
1. Build `Message` (`role:'user', kind:'user'`).
2. `useWorkspace.appendMessage(msg)` + `api.chatAppendMessage(projectDir, msg)`.
3. Reserve placeholder assistant message `kind: nextDelegateToKind(nextDelegate)`, status `streaming`.
4. `api.poSendMessage(projectDir, { text, persona: nextDelegate, resume: claudeSessionId })`.
5. Tokens stream → `appendToLastMessage` (existing store action).
6. Done → mark status `done` + `chatAppendMessage` for the final consolidated assistant message; persist sessionId.

Persona selector `<select>` between textarea + send. Options: `@ pdt-po / @ pdt-designer / @ pdt-developer / @ pdt-qa`. Default `pdt-po`. Value persisted in `usePoChat` only (not in chat.json).

## 7. Minimize + FAB

`useWorkspace` already has the grid; we control `panelVisible` from `usePoChat`. Easiest wiring without restructuring grid: `ChatPanel` returns the panel content **plus** the FAB; when `panelVisible=false`, panel root collapses to `width: 0` (and `border: none`), FAB renders as `position: fixed` bottom-right with `zIndex: 9999`. WorkspaceShell grid track 4 stays `340 px` but the panel content is invisible — to truly reclaim the space we need to change grid template.

**Decision**: change `gridTemplateColumns` in WorkspaceShell from static to derived. Pass `panelVisible` via `useWorkspace` context (or import `usePoChat` directly into WorkspaceShell — simplest). When `panelVisible=false` → 4th track is `0px`. FAB always lives in `ChatPanel` (single source).

- **textarea autosize**: fixed min-height 40 px, max-height 120 px, `overflow:auto` — no autoresize lib.
- **z-index FAB collisions**: 9999 chosen; titlebar uses `hiddenInset` (no overlap).
