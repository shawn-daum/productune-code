## §3 Amendment — Version grouping (2026-05-21)

**Change**: Original T-P4-153 spec had a flat `docs/artifacts/<ticket>/` structure.
Amended to `docs/artifacts/<version>/<ticket>/` based on user directive
"아티팩트도 버젼을 나눠줘야해".

**Analogy**: mirrors `docs/tickets/v0.4/` — version/phase is the outer bucket.

**Routing rule** (for new artifact emission going forward):

| Artifact type | Path |
|:--|:--|
| Ticket-level output | `docs/artifacts/<ticket.version>/<ticket_id>/` |
| Global / product doc | `docs/artifacts/<name>` (root, no version prefix) |
| No version field on ticket | `docs/artifacts/global/<ticket_id>/` (fallback) |

**Impact on execution phases**:

| Phase | Change |

| B (git mv) | **Rewritten** — structured multi-step move instead of single rename |

**Migration**: all existing T-P4-* artifacts → `v0.4` bucket
(all phase4 tickets carry `version: v0.4`).

### Phase A — plan.md → §Plan merge (Python script)

*(Unchanged from original — runs on `docs/artifacts/` before rename)*

Create and run `scripts/migrate-plans-to-tickets.py` from project root.

**Full script**:

```python
#!/usr/bin/env python3
"""
scripts/migrate-plans-to-tickets.py
Merge docs/artifacts/v0.4/T-P4-NNN/plan.md into ticket md §Plan sections.
Run from project root. --dry-run for safe preview.
Delete script after successful migration.
"""
import os, sys, re, pathlib, argparse

PROJECT_ROOT = pathlib.Path(os.getcwd())
DESIGN_DIR   = PROJECT_ROOT / 'docs' / 'design'
TICKETS_DIR  = PROJECT_ROOT / 'docs' / 'tickets'

# Strict numeric: T-P4-NNN (no suffix). Non-standard dirs handled separately.
TICKET_PATTERN = re.compile(r'^T-P4-\d+$')

# Non-standard dirs: designer sub-specs, not ticket plans. Rename plan.md → design-spec.md.
RENAME_ONLY = ['T-P4-048-mcp-hooks', 'T-P4-048-env-models']


def shift_headings(content: str) -> str:
    """Shift all markdown headings +1 level outside fenced code blocks."""
    lines = content.split('\n')
    in_code = False
    result = []
    for line in lines:
        stripped = line.lstrip()
        if stripped.startswith('```'):
            in_code = not in_code
        if not in_code and re.match(r'^#{1,5} ', line):
            line = '#' + line
        result.append(line)
    return '\n'.join(result)


def find_ticket(ticket_id: str) -> pathlib.Path | None:
    for phase_dir in TICKETS_DIR.iterdir():
        if not phase_dir.is_dir():
            continue
        cand = phase_dir / f'{ticket_id}.md'
        if cand.exists():
            return cand
    return None


def remove_plan_path_from_frontmatter(content: str) -> str:
    return re.sub(r'^plan_path:[ \t]*.*\n', '', content, flags=re.MULTILINE)


def merge_plan(ticket_id: str, plan_path: pathlib.Path, dry_run: bool) -> str:
    """Returns 'ok' | 'warn' | 'skip'."""
    ticket_md = find_ticket(ticket_id)
    if not ticket_md:
        print(f'  WARN  {ticket_id}: ticket md not found — skipping')
        return 'warn'

    plan_body   = plan_path.read_text('utf-8').strip()
    ticket_body = ticket_md.read_text('utf-8')

    if '## §Plan' in ticket_body:
        print(f'  SKIP  {ticket_id}: §Plan already present')
        return 'skip'

    shifted      = shift_headings(plan_body)
    plan_section = (
        '\n\n---\n\n'
        '## §Plan\n\n'
        f'<!-- migrated from docs/artifacts/{ticket_id}/plan.md -->\n\n'
        f'{shifted}\n'
    )

    if '## §Persona Activity' in ticket_body:
        ticket_body = ticket_body.replace(
            '## §Persona Activity',
            f'{plan_section}\n## §Persona Activity'
        )
    else:
        ticket_body = ticket_body.rstrip() + plan_section

    ticket_body = remove_plan_path_from_frontmatter(ticket_body)

    if dry_run:
        print(f'  DRY   {ticket_id} → {ticket_md.relative_to(PROJECT_ROOT)}')
        return 'ok'

    ticket_md.write_text(ticket_body, 'utf-8')
    plan_path.unlink()

    # Remove dir if now empty (ignoring .DS_Store)
    parent = plan_path.parent
    remaining = [f for f in parent.iterdir() if f.name != '.DS_Store']
    if not remaining:
        for ds in parent.glob('.DS_Store'):
            ds.unlink(missing_ok=True)
        parent.rmdir()
        print(f'  OK    {ticket_id} → §Plan merged + dir removed')
    else:
        print(f'  OK    {ticket_id} → §Plan merged (dir has other artifacts: '
              f'{[f.name for f in remaining]})')
    return 'ok'


def main():
    ap = argparse.ArgumentParser(description='Merge plan.md files into ticket §Plan sections.')
    ap.add_argument('--dry-run', action='store_true', help='Preview without writing')
    args = ap.parse_args()

    # Collect strict-numeric T-P4-NNN dirs with plan.md
    candidates = sorted(
        [(e.name, e / 'plan.md')
         for e in DESIGN_DIR.iterdir()
         if e.is_dir() and TICKET_PATTERN.match(e.name) and (e / 'plan.md').exists()],
        key=lambda x: int(x[0].split('-')[2])
    )
    print(f'Found {len(candidates)} plan.md candidates (strict T-P4-NNN)\n')

    counts = {'ok': 0, 'warn': 0, 'skip': 0}
    for tid, plan_path in candidates:
        result = merge_plan(tid, plan_path, args.dry_run)
        counts[result] += 1

    # Non-standard dirs: rename plan.md → design-spec.md (designer sub-specs)
    print('\nNon-standard dirs (rename plan.md → design-spec.md):')
    for ns in RENAME_ONLY:
        src = DESIGN_DIR / ns / 'plan.md'
        dst = DESIGN_DIR / ns / 'design-spec.md'
        if src.exists():
            if args.dry_run:
                print(f'  DRY   {ns}/plan.md → design-spec.md')
            else:
                src.rename(dst)
                print(f'  OK    {ns}/plan.md → design-spec.md')
        else:
            print(f'  SKIP  {ns}/plan.md not found')

    print(f'\nDone: {counts["ok"]} OK / {counts["warn"]} WARN / {counts["skip"]} SKIP')
    if counts['warn']:
        print('Review WARN entries — ticket md not found for those plan files.')
    if args.dry_run:
        print('\n[dry-run] No filesystem changes. Re-run without --dry-run to execute.')


if __name__ == '__main__':
    main()
```

### Phase B — Structured git mv (version-grouped) *(amended)*

**Replaces** the original single `git mv docs/design docs/artifacts`.
Multi-step: T-P4-* ticket content → version bucket; global docs → artifacts root.

```bash
# B1: Create artifacts root + version bucket (mkdir is safe before git mv)
mkdir -p docs/artifacts/v0.4

# B2: Move T-P4-* ticket DIRS → version bucket
#     Covers: T-P4-NNN/, T-P4-NNN-slug/, T-P4-048-mcp-hooks/, T-P4-048-env-models/, etc.
for dir in docs/artifacts/v0.4/T-P4-*/; do
  [ -d "$dir" ] && git mv "${dir%/}" docs/artifacts/v0.4/
done

# B3: Move T-P4-* flat .md FILES → version bucket
#     Covers: ~27 flat docs (T-P4-020-..., T-P4-021-..., T-P4-065-sub-b-..., etc.)
for f in docs/artifacts/v0.4/T-P4-*.md; do
  [ -f "$f" ] && git mv "$f" docs/artifacts/v0.4/
done

# B4: Move global/non-ticket content → artifacts ROOT
git mv docs/artifacts/productune docs/artifacts/productune
# Remaining flat .md files (design-system.md, design-direction.md, etc.)
for f in docs/artifacts/*.md; do
  [ -f "$f" ] && git mv "$f" docs/artifacts/
done
# Any remaining non-T-P4 dirs (belt-and-suspenders; should be none after productune/ moved)
for dir in docs/artifacts/*/; do
  [ -d "$dir" ] && git mv "${dir%/}" docs/artifacts/
done

# B5: Remove now-empty docs/artifacts/
rmdir docs/design

# Verify
git status | grep 'renamed' | wc -l             # expect ~130+
ls docs/artifacts/                              # global docs + productune/ + v0.4/
ls docs/artifacts/v0.4/ | head -10 # T-P4-* dirs and flat .md files
ls docs/artifacts/T-P4-* 2>&1                  # → No such file or directory
ls docs/design 2>&1                             # → No such file or directory
```

`git mv` preserves per-file history. All tracked paths follow with rename recorded in git.

> **Note on B4 loop ordering**: run `git mv docs/artifacts/productune ...` explicitly before
> the generic `docs/artifacts/*/` loop to avoid double-processing.

**Must be two separate passes in strict order.** T-P4-specific refs get the version-bucket
prefix; remaining `docs/artifacts/` refs (global docs) get the artifacts root only.

```bash

  -not -path './.git/*' \
  -not -path './.productune/worktrees/*' \
  \( -name '*.md' -o -name '*.ts' -o -name '*.tsx' \
     -o -name '*.json' -o -name '*.sh' \) \
  -exec sed -i '' 's|docs/artifacts/v0.4/T-P4-|docs/artifacts/v0.4/T-P4-|g' {} +

# Pass 2 — Remaining docs/artifacts/ refs → artifacts root

     -o -name '*.json' -o -name '*.sh' \) \
