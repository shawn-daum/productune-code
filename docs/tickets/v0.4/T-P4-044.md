## §3 페르소나 detail (persona-def 탭, dispatcher target)

> **본 섹션은 dispatch target 의 contract 만 정의** — 탭 내부 구현은 T-P4-046 의 `persona-def` row.

### 3.1 dispatch payload

```ts
openTab(
  tabId: `persona-def:${persona}`,   // 동일 persona 중복 open 방지
```

- `pd-header` — `p-avatar` 32×32 + name + role + model default (frontmatter `model:`) + tools (frontmatter `tools:` 배열).

- `pd-content` — persona spec md 풍부 렌더 (h1/h2/code/table). source = `~/.claude/agents/<persona>.md`.
- 추가 metadata row (frontmatter):
  - `permissionMode` (예: `bypassPermissions`)
  - `color` (예: purple)
  - `mcpServers` list
  - 마지막 수정 시각 (`fs.statSync(...).mtime`)

> persona spec md 의 `## Skills` section 은 §4 skill matrix tab 과도 cross-reference. persona-def preview 안 skill list 클릭 = `openTab('skill-matrix', { focusRow: skillId })` 로 점프 (선택 사항, Phase 4 nice-to-have).
