# T-P4-090: Settings General sub-tab → Main pane tab open

> Settings 사이드 패널의 General sub-tab 을 inline 표시 (`<GeneralSettings />`) 가 아닌 **링크 row** 로 바꾸고, 클릭 시 `productune:open-tab` 발사 → 메인 패널에 `general-settings` tab open. T-P4-088 listener wire 이후 dispatcher 패턴 (Environment / Models 와 동일) 정합.

## §1 Background

사용자 directive (2026-05-11):

> "언어선택, 사용자 모드 이거 사이드 패널에 바로 노출되는게 아니고 설정-일반 클릭하면 메인 패널에 해당 탭이 나오게 해줘."

### 현 동작 (T-P4-084 land 산출물)

`packages/gui/src/components/workspace/SettingsView.tsx`:

- `activeTab` state 가 `'general' | 'environment' | 'models' | 'mcp' | 'hooks' | 'workflow'`
- General sub-tab 선택 시 (`activeTab === 'general'`) `<GeneralSettings />` (사이드 패널 안 inline) 가 렌더
- `GeneralSettings.tsx` 는 UI Language 2 radio + User mode 3 radio + immediateNote 를 사이드 패널 안에 표시

이는 Environment / Models 와 다른 패턴 (그쪽은 row 클릭 → `productune:open-tab` dispatch → 메인 panel tab). 사용자 의도 = General 도 동일 패턴.

### 의도

- 사이드 패널 Settings = **링크 row 목록** (Environment / Models / MCP / Hooks / Workflow / General 모두 row)
- General row 클릭 → 메인 패널에 `general-settings` tab open
- `GeneralSettings.tsx` 컴포넌트 자체는 그대로 재사용 (라디오 / 카드 / 스타일 보존) — 위치만 메인 pane tab 으로 이동

### T-P4-088 의존

`productune:open-tab` listener 가 T-P4-088 에서 WorkspaceShell 에 wire 됨 — 본 ticket 은 그 listener 의 dispatcher 가 `general-settings` 도 처리하도록 TabType + TabContent + tabId derive 규칙 추가.

## §5 QA scenarios (light)

1. **General row 클릭 → 메인 panel tab open** — Settings 사이드 → 'General' (또는 '일반') row 클릭 → 메인 패널에 `General` tab open. UI Language 2 radio + UserMode 3 radio 표시
2. **stable singleton tabId** — General row 두 번 클릭 → 두 번째는 같은 tab focus only (새 tab 추가 X)
3. **사이드 inline 미노출** — Settings 사이드 패널에 더 이상 UI Language / UserMode radio 가 inline 으로 안 보임
4. **Language 변경** — 메인 panel General tab 의 English / 한글 radio 클릭 → 즉시 i18n 적용 (다른 컴포넌트 / wizard / banner 라벨 갱신)
5. **UserMode 변경** — Developer / Planner / Unset radio 클릭 → useUserMode store 즉시 반영 + PersonaPresenceBar / mode-gated 텍스트 갱신
6. **Environment row 회귀** — Environment 'project' 클릭 → 메인 panel `env-view:project` tab open (T-P4-088 land 동작 유지)
7. **MCP/Hooks/Workflow 회귀** — 3 sub-tab inline 동작 (status badge / toggle / form) 정상
8. **tab close** — General tab 의 X 버튼 → tab 닫힘 + General row 다시 클릭 시 재open
9. **i18n parity** — en/ko 토글 시 General row 라벨 + tab title 모두 정합
