# T-P4-073: TeamPanel WikiRow emoji → lucide 교체 — §7.1 정합

## Background

T-P4-069 audit C-3 critical violation. `TeamPanel.tsx` `WikiRow` 호출부 (lines 292–322) 가 unicode escape 형태 컬러 emoji 5개 (`🧠` `📚` `🗄️` `📌` `⚙️`) 직접 렌더. design-system §7.1 ("컬러 emoji 금지 — accessibility / 폰트 일관성") 위반. OS 폰트별 색/크기/앤티앨리어싱 다름, 스크린리더 발음 불안정.

## Doctrine references

- `docs/designer/design-system.md` §7.1 Iconography (lucide 1.14.0, stroke 2)
- `docs/designer/design-system.md` §2.4 token (`--text-secondary` 등)
- `docs/artifacts/v0.4/T-P4-069-audit.md` §2.C-3
