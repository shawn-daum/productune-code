# T-P4-079: PO 답변 chunk 분리 — stream-json assistant envelope 단위 말풍선 (가독성)

## Background

사용자 dogfood (2026-05-11): PO 가 terminal 의 stream-json 으로 한 turn 안 답을 여러 번 나누어 보냄 (예: "잠깐 기다려" → Bash sub-agent spawn → "결과 합산:" → "Designer A: ..." → "Designer B: ..."). 그러나 ChatPanel 의 사용자 화면에서는 이 모든 chunk 가 단일 거대 말풍선으로 누적 표시됨 — 가독성 ↓, 단계 구분 불가, terminal 자연스러운 흐름이 chat 에서 단절.

## Doctrine references

- `docs/designer/design-system.md` §1.5.4 Feedback — action 의 단계별 progress visibility
- T-P4-068 BackgroundTaskSegment / T-P4-077 IPC trigger — sub-agent dispatch trace 정합
- `packages/gui/electron/po-runner.ts:108` 의 turn-scope msgId 발급 (현 동작)
- `packages/gui/src/components/workspace/ChatPanel.tsx:76~88` 의 `onMsgId` placeholder 패턴 (현 동작)

## 현 동작 (변경 대상)

- po-runner `runPoTurn` 진입 시 `newMsgId()` 1회 호출 → `cb.onMsgId(msgId)` 1회 emit
- 한 turn 안 모든 stream-json `assistant.text` chunk 가 같은 `msgId` 로 `cb.onToken(msgId, chunk)` 흘림
- ChatPanel 이 같은 bubble (placeholder) 에 text append → **거대 단일 말풍선**

## Acceptance

  - 같은 envelope 안 multiple text part (드물지만 가능) 는 같은 msgId 유지
  - tool_use only envelope (text 없음) 은 새 msgId 발급 X — 기존 동작 그대로 onAnnounce trace 처리

### B) ChatPanel — 이전 msgId 자동 done flip

## QA scenarios (light)

1. **multi-envelope turn** — PO 답이 stream-json 으로 3 envelope (text/tool/text/text) → chat bubble 3 + trace 1
2. **single envelope turn** — PO 답이 1 envelope → 1 bubble (회귀 없음)
3. **tool_use + text mixed envelope** — 한 envelope 안 text + tool_use + text → 1 bubble (text 합쳐짐) + trace 1
4. **turn 종료** — onDone 마지막 msgId 의 status done flip / 이전 msgId 들도 모두 done (streaming stuck X)
5. **session restart** — 진행 중 streaming bubble 정상 종료, store reset
6. **persistence** — chat.json 에 분리된 multiple message 모두 저장 (앱 재시작 후 복원 정합)
7. **token streaming** — 한 envelope 안 token 단위 chunk 가 와도 같은 bubble 에 누적 (chunk 단위로 새 bubble X)
