## §1 Request

**Origin**: T-P4-124 OQ-K gap candidate G10 — T-P4-125 established the `register_graphiti_mcp()` pattern in `install.sh` and the `onboarding:complete` IPC handler in `electron/main.ts`. Playwright MCP (`@playwright/mcp`) is not registered automatically; new users must run `claude mcp add` manually after install.

**Directive verbatim (T-P4-124 OQ-K)**:
> "G10 신규 (claude mcp add playwright 자동화 — graphiti pattern 확장)"

**Pattern to extend**: `register_graphiti_mcp()` in `packages/core/scripts/install.sh` + companion call in `packages/gui/electron/main.ts` `onboarding:complete` handler. Both paths must register Playwright to cover CLI install and GUI onboarding flows.

## §2 Acceptance

### A1. `install.sh` — `register_playwright_mcp()` added
`packages/core/scripts/install.sh`:
- New function adjacent to `register_graphiti_mcp()`:
  ```bash
  register_playwright_mcp() {
    if claude mcp list 2>/dev/null | grep -q "playwright"; then
      echo "  playwright MCP already registered (skip)"
      return 0
    fi
    echo "  Registering Playwright MCP..."
    claude mcp add playwright npx -- -y @playwright/mcp@latest --isolated
    echo "  Playwright MCP registered."
  }
  ```
- Called from main install flow after `register_graphiti_mcp()`.
- Idempotent: re-run skips if already registered.
- Graceful: failure (e.g. npx unavailable) prints warning, does not abort install (`|| echo "WARN: playwright MCP registration failed — run manually"` guard).

### A2. `electron/main.ts` — `onboarding:complete` handler extended
`packages/gui/electron/main.ts`:
- Existing `onboarding:complete` IPC handler already registers Graphiti MCP via shell exec.
- Add parallel exec for Playwright MCP using same pattern:
  ```ts
  exec('claude mcp add playwright npx -- -y @playwright/mcp@latest --isolated', ...)
  ```
- Idempotent guard: check `claude mcp list` output before adding (same as Graphiti pattern).
- Error logged to console/log file; does not surface error dialog to user (non-blocking).

### A3. Verification
Post-install (or post-onboarding-complete): `claude mcp list` output includes a `playwright` entry with status `Connected`.

### A4. No new dependencies
`@playwright/mcp@latest` is fetched via `npx -y` at registration time — no `package.json` change required.
