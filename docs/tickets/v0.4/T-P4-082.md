### B) tooltip — row 로 stack + 위치 PresenceBar 위쪽 중앙

- [ ] `PersonaPresenceBar.tsx` 의 `tooltipStyle` 변경:
  - `whiteSpace: nowrap` → `whiteSpace: pre-line` (\n 을 newline 으로 render)
  - `maxWidth: 200` → `maxWidth: 360` (정도)
  - `textOverflow: ellipsis` / `overflow: hidden` 제거 (row 단위 표시라 truncate 불필요)
  - 또는 component 안에서 artifact.split('\n').map → `<div>` row 로 render — `pre-line` 보다 명시적
- [ ] **위치 변경**: chip 별 위 (현 `bottom: calc(100% + 4px); left: 50%; translateX(-50%)`) → **PresenceBar root 의 위쪽 중앙** 으로 통일:
  - tooltip 을 chip 자식이 아닌 PresenceBar root (bar 컨테이너) 의 자식으로 absolute positioning
  - `position: absolute; bottom: calc(100% + 6px); left: 50%; transform: translateX(-50%)`
  - PresenceBar root 가 `position: relative` 인지 확인 후 보강
  - 어떤 chip 을 hover 해도 tooltip 은 PresenceBar 줄의 위쪽 중앙에 떠 있어서 viewport 좌측 clip 회피
- [ ] tooltip text 정렬: `text-align: left` (row 간 정합)
- [ ] tooltip 의 `z-index` 충분히 높임 (chat header 위에 떠야)
