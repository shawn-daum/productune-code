# T-P4-003: packages/gui — Electron + React/TS + Vite boilerplate (main/preload/renderer + secure IPC)

**Round**: phase4-r0  **Stage**: impl  **Status**: todo  **Assignee**: pdt-developer
**PRD anchor**: [docs/prd/productune.md#phase-4--개발-비숙련-기획자-모드-planner-mode-future](../../prd/productune.md#phase-4--개발-비숙련-기획자-모드-planner-mode-future)
**Estimated complexity**: L4  **Risk flags**: none

> Round 0 의 GUI 기반 마련. T-P4-001 에서 생성된 `packages/gui/` 위에 Electron + Vite + React + TypeScript boilerplate 를 초기화. main process / preload / renderer 3-layer 보안 분리 구조를 확립하고, renderer 에서 `@productune/core` 를 직접 참조하지 않는 IPC 패턴을 정의. 이 티켓의 결과물은 "빈 Electron 창" — 실제 기능 구현은 Round 1+ 에서.

---

## Request

### 1. Electron + Vite 설정

`electron-vite` (`@electron-toolbox/vite-plugin` 계열) 또는 `vite-plugin-electron` 을 선택하여 `packages/gui/` 에 설정. renderer 는 Vite dev server 기반, main/preload 는 별도 빌드.

권장 구조:

```
packages/gui/
├── electron/
│   ├── main.ts          ← BrowserWindow 생성, preload 지정, app lifecycle
│   └── preload.ts       ← contextBridge.exposeInMainWorld (IPC 브릿지)
├── src/
│   ├── App.tsx          ← renderer root (빈 화면 OK)
│   └── main.tsx         ← ReactDOM.createRoot
├── vite.config.ts       ← renderer 빌드 설정
├── tsconfig.json        ← TypeScript 설정 (strict)
└── package.json         ← @productune/gui
```

### 2. 보안 설정 (필수)

Electron `BrowserWindow` 생성 시:
```ts
webPreferences: {
  contextIsolation: true,   // 반드시 true
  nodeIntegration: false,   // 반드시 false
  preload: path.join(__dirname, 'preload.js'),
}
```

### 3. IPC 패턴 정의

- **renderer → main**: `contextBridge.exposeInMainWorld('api', { ... })` 로 renderer 에서 사용 가능한 API 표면 정의. `ipcRenderer.invoke` 래핑.
- **main → core**: main process 가 `@productune/core` (workspace 의존) 를 `require`/`import` 하여 호출. renderer 에서 직접 `require('child_process')` / `require('fs')` 금지.
- 이 티켓에서는 `ping → pong` 수준의 IPC 예시 1개만 구현 (실제 core 호출은 Round 1+ 에서).

### 4. 의존성

`packages/gui/package.json` 에 추가:
- `electron` (devDependency)
- `vite`, `@vitejs/plugin-react` (devDependency)
- `react`, `react-dom` (dependency)
- `typescript` (devDependency)
- `electron-vite` 또는 `vite-plugin-electron` (devDependency)
