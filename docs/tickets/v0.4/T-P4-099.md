**handleTabClick 변경 (대상)**:

```ts
// 변경 후
const handleTabClick = (id: SettingsSubTab) => {
  setActiveTab(id)
  if (id === 'general') {
    openTab('general-settings', 'general-settings', undefined,
      t('settings.tabGeneral', { defaultValue: '일반 설정' }))
  } else if (id === 'workflow') {
    openTab('workflow-settings', 'workflow-settings', undefined,
      t('settings.tabWorkflowRules'))
```

```ts
const handleTabClick = (id: SettingsSubTab) => {
```

### §6 §1.5 self-check (design-system UX principles)

| Sub-rule | 검증 | 결과 |
|---|---|---|
| **§1.5.1 Few Things** | Version row 토큰 4→2. Team sidebar: Personas inline (4 row, 항상 visible) + 2 nav row — WikiRow 4 행 sidebar 에서 제거. Settings sidebar = sub-tab list only. 각 sidebar 의 표면 surface 30%~50% 감소. | ✓ pass |
| **§1.5.2 Familiar** | Team panel — Skills + Wiki·Memory nav = Settings 와 동일 패턴. Personas 는 기존 inline 그대로 (팀 상태 항상 읽는 곳, 변경 X — 사용자 학습 부담 0). Main pane tab = 기존 singleton `openTab` API. | ✓ pass |
| **§1.5.3 Predictability** | Skills + Wiki·Memory nav row click = main pane tab open (모호성 0). 재클릭 = focus (동일). Version row click 동작은 T-P4-097 그대로. Personas section = click-free, always visible. | ✓ pass |
| **§1.5.4 Feedback** | nav row hover bg `#1A1A1A` 즉시 변경 + click → main tab open (시각 변화). Version row hover popover 제거 — "왜 이게 보이지" anti-pattern 해소. Close badge = 항상 인라인 visible (hover 의존 X). | ✓ pass |
| **§1.5.5 Escape** | Main pane tab 모두 X 닫기 가능 (기존 mechanism). Sidebar collapse = Activity Bar 재클릭. Personas section 은 click-free (escape 해당 없음). row click 비-destructive. | ✓ pass |

**Anti-pattern 점검**:
- ❌ "hover 해야 정보가 보임" → 제거 (PhaseStrip popover 삭제, close badge 인라인).
- ❌ "두 sub-tab 동작이 다름" → 통일 (일반/작업흐름 둘 다 openTab).
- ❌ "sidebar 가 빽빽한 list 들로 채워짐" → WikiRow 제거 (Team) + 2 nav row + Personas inline 유지 / 2 sub-tab nav only (Settings).
- ❌ "row 마다 phase 라벨이 또 보임" → sidebar 상단 PhaseStrip 1 곳으로 단일화.
