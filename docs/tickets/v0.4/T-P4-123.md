## §2 Acceptance

### A1. Description default-hide

SkillMatrixTab 의 skill row 가 기본 상태에서 description 미노출. `<td
style={tdSkill}>` 안의 inline `<span style={skillDesc}>{skill.description}</span>`
제거. name 만 표시.

### A2. Description trigger 노출

Hover 또는 click trigger (plan.md §A 결정 후 확정) → description 노출.
- Trigger 후보: (i) tooltip on hover / (ii) popover on click / (iii) inline accordion.
- 단일 row mutex (한 번에 하나만 open).
- Outside-click + Esc → close.

### A3. i18n — 사용자 UI 언어 매칭

`i18n.language === 'ko'` → ko description / `'en'` → en description.
- Strategy 후보: (a) 정적 사전 (`locales/ko.json`) / (b) lazy + cache / (c) en-only retained (plan.md §B 결정 후 확정).
- 추천 = (a) static dictionary + (a.2) LLM batch 1회 generation (impl 시 dev 실행).

### A4. Fallback — graceful

i18n key 매칭 실패 시 영문 원본 (frontmatter description) 표시. `t('skills.descriptions.<key>', { defaultValue: skill.description })` 패턴.
- 새 skill 설치 후 ko 누락 시 표 자체 동작 + 영문 표시.

### A5. Keyboard 접근성

- Trigger 는 native `<button>` (`tabindex` 자동, Enter/Space 동작 OS-level).
- `aria-expanded={open}` + `aria-label` (신규 i18n key `workspace.team.skillMatrix.viewDescription`).
- Popover 본문 `role="tooltip"` 또는 `role="dialog"`.
- Focus return — close 시 trigger 버튼으로 복귀.

### A6. Build pass

`pnpm -F gui build` (또는 `tsc --noEmit`) 0 errors. vite renderer/electron/preload
모두 clean.
