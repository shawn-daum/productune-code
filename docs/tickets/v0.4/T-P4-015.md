# T-P4-015: First-run Onboarding Wizard

**Round**: phase4-r1  **Stage**: impl  **Status**: done  **Assignee**: pdt-developer

> 앱 최초 실행 시 (`~/.productune/productune.env` 없을 때) 사용자를 인터랙티브하게 세팅해주는 wizard. install.sh 에서 하던 설정을 GUI로 옮김. 완료 후 Settings 탭에서 언제든 변경 가능.

## Trigger

`app.whenReady()` 이후 `~/.productune/productune.env` 존재 여부 확인 →
없으면 HomeView 대신 OnboardingWizard 렌더.

## Steps

### Step 1 — Engine 선택
- `○ Claude Code` (기본 추천)
- `○ Codex`
- `○ 둘 다` (primary: Claude Code, secondary: Codex)
- 각 옵션에 한 줄 설명

### Step 2 — Wiki 백엔드
- `○ Filesystem` (심플, 의존성 없음) — 기본 추천
- `○ Graphiti` (그래프 DB, Docker 필요)
- IPC로 하드웨어 tier 자동 감지 (RAM, Apple Silicon, Docker) → 추천 표시
- Graphiti 선택 시 "Docker가 필요합니다" 안내

### Step 3 — API Key 입력
- 선택한 engine에 따라 필드 표시
  - Claude Code: `ANTHROPIC_API_KEY`
  - Codex: `OPENAI_API_KEY`
  - 둘 다: 두 필드
- [건너뛰기 — 나중에 Settings에서 설정] 버튼 제공
- 입력값은 `~/.productune/productune.env`에 저장 (mode 0600)

### Step 4 — 완료
- `~/.productune/productune.env` 생성 (engine, wiki_backend, created_at)
- `agents/` → `~/.claude/agents/` 심링크 (IPC로 실행)
- `po-instructions.md` → `~/.productune/` 복사
- `po-memory.md.template` → `~/.productune/po-memory.md` (없으면)
- "설정 완료 ✓" 화면 → [시작하기] → HomeView

## IPC 채널

- `onboarding:checkEnv` — `~/.productune/productune.env` 존재 여부 반환
- `onboarding:detectHardware` — `{ tier: 'S'|'A'|'B', ram_gb, apple_silicon, docker }` 반환
- `onboarding:complete(opts)` — env 파일 생성 + 심링크 + 파일 복사

## Settings 연동

완료 후 Settings 패널에서 동일 항목 변경 가능하도록 `onboarding:complete`와 동일한 IPC 재사용.
