### Step 컴포넌트 props 패턴

모든 state 는 OnboardingWizard.tsx 소유. Step 컴포넌트는 필요한 값 + 콜백만 props 로 수신.

```ts
// Step0_Language.tsx 예시
interface Step0Props {
  uiLang: UiLang
  resetFeedback: boolean
  onSelectLang: (lng: UiLang) => void
  onReset: () => void
  onNext: () => void
}
export default function Step0_Language({ uiLang, resetFeedback, onSelectLang, onReset, onNext }: Step0Props) {
  const { t } = useTranslation()
  return (
    <>
      <div style={body}>...</div>
      <div style={footer}>...</div>
    </>
  )
}
```

Step 컴포넌트 내부:
- `useTranslation()` 직접 호출 가능 (i18n hook은 child에서도 OK)
- 자체 state 선언 없음 — 모든 state는 orchestrator 소유 props 경유
- 예외: `logEndRef`, `llmLogEndRef` → 각각 Step3_WikiBackend, Step3_5_LocalLLM 내부 `useRef` (해당 step 내에서만 사용)
