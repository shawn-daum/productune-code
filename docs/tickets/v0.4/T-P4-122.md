## §1 Request

SkillMatrixTab 에서 mattpocock 스킬이 중복 출현:
- `improve-codebase-architecture`: 4 rows
- `prototype`: 3 rows
- `setup-matt-pocock-skills`: 5 rows
- `triage`: 3 rows (SKILL + AGENT-BRIEF + OUT-OF-SCOPE)
- `.out-of-scope/` hidden 디렉토리 안 md 3개가 각각 entry 화

**Root cause**: `collectMdFiles` 가 모든 `.md` 재귀 픽업 → 각 파일이 별 `SkillEntry`.
Matt Pocock 컨벤션 = `SKILL.md` + 보조 docs (no frontmatter). 현 핸들러는
frontmatter 없는 supplementary docs 를 name fallback (`path.basename(path.dirname(...))`)
으로 entry 화 → 부모 디렉토리 이름 중복 노출.

## §2 Acceptance

### A1. SKILL.md 만 entry 화

`skills:list` 핸들러 내 frontmatter 파싱 직후 **early-continue** 추가:
```typescript
const fmName = (fm.name as string | undefined)?.trim()
const fmDescription = (fm.description as string | undefined)?.trim()
if (!fmName || !fmDescription) continue
```
- `name` fallback (`path.basename(path.dirname(filePath))`) 제거.
- `description` fallback (`''`) 제거.
- 이후 `name = fmName`, `description = fmDescription` 로 직접 사용.

### A2. 숨김 디렉토리 traversal skip

`collectMdFiles` 내 디렉토리 재귀 분기 조건 변경:
```typescript
// Before
if (entry.isDirectory()) {
// After
if (entry.isDirectory() && !entry.name.startsWith('.')) {
```
- `~/.claude/skills/mattpocock/.out-of-scope/` 및 향후 hidden dir 자동 제외.
- `.git/`, `.DS_Store/` 등도 동시 처리.
