## §2 Scope

### Sub-area A — Onboarding Local Storage cleanup (IPC + reset CTA)

#### A.1 IPC handler — `onboarding:clearLocalStorage`

**`packages/gui/electron/main.ts`** 에 신규 handler 추가:

```ts
ipcMain.handle('onboarding:clearLocalStorage', async () => {
  const home = os.homedir()
  const platform = process.platform

  // OS-aware path resolution
  let appDataBase: string
  if (platform === 'darwin') {
    appDataBase = path.join(home, 'Library', 'Application Support')
  } else if (platform === 'win32') {
    appDataBase = path.join(home, 'AppData', 'Roaming')
  } else {
    // Linux and other POSIX
    appDataBase = path.join(home, '.config')
  }

  const targets = [
    path.join(appDataBase, '@productune', 'Local Storage'),
    path.join(appDataBase, '@productune', 'gui', 'Local Storage'),
  ]

  const removed: string[] = []
  const errors: string[] = []

  for (const t of targets) {
    try {
      fs.rmSync(t, { recursive: true, force: true })
      removed.push(t)
    } catch (e: any) {
      errors.push(`${t}: ${e?.message}`)
    }
  }

  return { ok: errors.length === 0, removed, errors }
})
```

**OS path 표 (reference)**:

| OS | `@productune` path | `@productune/gui` path |
|---|---|---|
| macOS | `~/Library/Application Support/@productune/Local Storage` | `~/Library/Application Support/@productune/gui/Local Storage` |
| Linux | `~/.config/@productune/Local Storage` | `~/.config/@productune/gui/Local Storage` |
| Windows | `%APPDATA%/@productune/Local Storage` | `%APPDATA%/@productune/gui/Local Storage` |

> `fs.rmSync` with `{ force: true }` — 경로 없으면 no-op. 오류 없이 성공 반환.
