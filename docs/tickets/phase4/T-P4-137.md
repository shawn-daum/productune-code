**User directives verbatim (2026-05-19):**
> "스킬 사이드 탭에 총 11개 이렇게 표시 되어있는데 실제 값과 안맞는거같아."
> "스킬은 공통된게 많은 순으로 sort해주고, 현재 po와 designer가 겹치는 스킬이 너무 많은데 중복 자체는 문제없는데 다 정말 중복되어있는 상태가 맞는건지 확인해줘."

Two cohesive changes to the SkillMatrix surface:

**A — Dynamic count**: `TeamPanel.tsx:42` has `const SKILLS_TOTAL = 11` hardcoded. Actual skill count shifts as skills are added/archived. Replace with live IPC call (`window.api.listSkills()`).

**B — Sort by overlap**: `SkillMatrixTab.filteredSkills` has no sort. Sort by `personas.length` descending (most cross-persona skills at top) with alphabetical tiebreak.

**Audit note (no code change here)**: `inferPersonasFromPath` gives ALL `phuryn/pm-*` skills `['po', 'designer']`. Plan §4 surfaces per-pack assessment — `pm-data-analytics`, most of `pm-market-research`, and `pm-execution` are flagged as designer-inappropriate. Fix deferred to a follow-up ticket (OQ gate). See `docs/design/T-P4-137/plan.md §4`.

## §2 Acceptance

### A1. `TeamPanel.tsx` — dynamic count
- `const SKILLS_TOTAL = 11` removed.
- `useState<number | null>(null)` added for `skillsTotal`.
- `useEffect` calls `window.api.listSkills()` on mount → `.then(entries => setSkillsTotal(entries.length))`.
- Skills badge: renders `t('workspace.team.section.skillsCount', { count: skillsTotal })` when resolved; renders `?` in muted grey (`#3A3A3A`) while loading.
- No localStorage cache.

### A2. Badge value matches SkillMatrixTab row count
After mount, the badge number equals the total unfiltered row count in SkillMatrixTab (same IPC source). Verified visually.

### B1. `SkillMatrixTab.tsx` — sort added to filteredSkills useMemo
`.sort((a, b) => b.personas.length - a.personas.length || a.name.localeCompare(b.name))` chained after `.filter(...)`.

### B2. Sort order visible in UI
- 4-persona skills (mattpocock `productivity/` — caveman, grill-me, write-a-skill, handoff) appear at top of the table.
- 2-persona skills (phuryn `pm-*` — po+designer) appear in mid section.
- 1-persona skills (mattpocock `engineering/`, `misc/` — dev only) appear at bottom.
- Within same overlap count: alphabetical order.

### B3. Sort preserved after search/filter
Applying search term or persona chip filter maintains the sort order within filtered results.
