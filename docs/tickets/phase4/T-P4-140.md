## §2 Acceptance

### A1. TeamPanel: MCP inline section removed

- `<Section storageKey="mcp">` and all children removed.
- `Section` function component + `SectionProps` interface removed.
- `secHdrBtn` + `secChevron` style consts removed.
- Imports removed: `McpServerEntry`, `McpServerModal`.
- State removed: `mcpServers`, `mcpLoading`, `selectedMcp`, `loadMcpServers`.
- Style consts removed: `mcpRowBtn`, `mcpName`, `mcpMuted`.

### A2. TeamPanel: MCP nav-row added

- Single `navRowBtn` renders between Skills and 위키 메모리 sections.
- Label: `t('workspace.team.section.mcpServers')` (existing key, no change).
- Click → `openTab('mcp-servers', 'mcp-servers', {})`.
- No count badge (count visible inside McpServersTab).

### A3. main.ts: 3-tier mcp:getServers

- `readClaudeJson()` helper reads `~/.claude.json` (graceful empty on error).
- `writeClaudeJson(data)` helper: atomic tmp+rename write (same pattern as `writeClaudeSettings`). Code comment: "CAUTION: ~/.claude.json is Claude Code's own state file. Never truncate."
- `mcp:getServers` merges 3 tiers in order (later wins):
  1. `productune`: `~/.claude/settings.json .mcpServers{}`
  2. `local`: `~/.claude.json .projects[projectDir].mcpServers{}`
  3. `project`: `<projectDir>/.mcp.json .mcpServers{}`
- `McpServerEntry.source` type in main.ts: `'productune' | 'local' | 'project'`.
- productune's graphiti + playwright appear with `source: 'local'`.

### A4. main.ts: mcp:save writes to local tier

- Handler signature adds `projectDir?: string` (3rd arg).
- When `projectDir` present: read-modify-write `~/.claude.json` `projects[dir].mcpServers[name] = config`. Guards: create `projects`, `projects[dir]`, `mcpServers` if missing.
- When `projectDir` absent: fallback to productune tier (`~/.claude/settings.json`) — legacy compat.
- Saved entry appears as `source: 'local'` on next `mcp:getServers` read.

### A5. preload.ts updated

- `mcpSave` signature: `(serverName, config, projectDir?)`.
- `ipcRenderer.invoke('mcp:save', serverName, config, projectDir)`.
- `mcpGetServers` return type: `source: 'productune' | 'local' | 'project'`.

### A6. McpServerModal + McpServersTab: projectDir threading

- `McpServerModal` `Props` adds `projectDir?: string`.
- `handleSave`: `api.mcpSave?.(server.name, buildConfig(), projectDir)`.
- `McpServersTab` passes `projectDir={project?.projectDir}` to `<McpServerModal>`.
- `McpServerEntry.source` type in `McpServersTab.tsx`: `'productune' | 'local' | 'project'` (remove `'merged'`).

### A7. McpServersTab: source tier pill

- Each server row renders `<span style={tierPill}>[{server.source}]</span>` between server name and `StatusBadge`.
- `tierPill` style: `fontSize: 9, fontFamily: monospace, color: '#404040', border: '1px solid #2A2A2A', borderRadius: 2, padding: '0 3px'`.
- Visual example: `graphiti  [local]  ◌ checking`

### A8. TeamPanel: Wiki Memory persona-style section

- Single wiki nav-row replaced with:
  - Plain `plainSecHdr` title: "위키 메모리" (`t('workspace.team.section.wikiMemory')`)
  - 4 rows rendered from `WIKI_PERSONAS` const using `personaRowStyle` + `avatarStyle` + `PERSONA_COLORS`
  - PO row: promo badge when `promoCount > 0`
- `WIKI_PERSONAS: WikiPersonaDef[]` const added after `PERSONAS`.
- `handleWikiPersonaClick(persona)` → `openTab('team-wiki:' + persona, 'team-wiki', { persona })`.
- `handleWikiClick` removed.

### A9. TeamWikiTab: persona-scoped rows

- Accepts `props.persona` (`'po' | 'designer' | 'dev' | 'qa' | undefined`).
- When persona set → persona header + scoped rows:
  - `po`: User Memory + Project State + Promotions (3 rows)
  - `designer`: Design Decisions + Feature History + Promotions (3 rows)
  - `dev`: Project State + Promotions (2 rows)
  - `qa`: Fail Patterns + Project State (2 rows)
- When persona unset → legacy 4-row view (unchanged).
- `personaHeader` + `personaHeaderText` style consts added.

### A10. i18n keys (9 new)

`workspace.team.section.wikiMemory`, `workspace.team.section.mcpLink`, `workspace.team.wiki.role.po/designer/dev/qa`, `workspace.team.wiki.designerDecisions`, `workspace.team.wiki.featureHistory`, `workspace.team.wiki.failPatterns` — both `ko.json` + `en.json`.
