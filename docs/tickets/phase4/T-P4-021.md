# T-P4-021: [자동저장] = ticket worktree 안 자동 commit

**Round**: phase4-r2  **Stage**: impl  **Status**: todo  **Assignee**: pdt-developer
**PRD anchor**: [docs/prd/productune.md#phase-4--terminal-무의존-gui-풀-사이클-future](../../prd/productune.md#phase-4--terminal-무의존-gui-풀-사이클-future) (§10 [자동저장])
**Estimated complexity**: L3  **Risk flags**: hook, persona-output
**Doctrine**: [`~/.productune/sections/git-workflow.md`](../../../../.productune/sections/git-workflow.md) §"자동저장 트리거"

## Request

페르소나 turn 종료 + 상태 변화 (developer turn end / QA pass / designer review pass) 트리거로 현재 ticket worktree 안에서 자동 commit. PO 직접 commit 금지. `post-delegate-autosave` hook 신설 — `post-delegate-state-write` 와 별개. commit 메시지 = `T-NNN [<persona>/turn N] <persona output 1줄 summary>`. 본문 (1줄 summary) = 페르소나 turn output 의 자기 발화. PO 는 ticket-id / persona / turn idx prepend 만. base worktree (프로덕션 / toggle 시 검증용 중간 환경) 위 트리거 시 noop + 친절 모달 (T-P4-020 모듈 재사용).

## Acceptance

- [ ] `post-delegate-autosave` hook 신설 — persona turn 종료 + 상태 변화 시 트리거
- [ ] commit 메시지 형식 = `T-NNN [<persona>/turn N] <summary>`. summary = 페르소나 turn output 1줄 (페르소나 자기 발화). PO 가 작성하지 않음.
- [ ] `git -C <worktree_path> add -A && git commit -m "..."` 으로 wrap
- [ ] base worktree (프로덕션 / toggle 시 검증용 중간 환경) 위 트리거 → noop + status bar "보호된 환경 — 작업공간에서 시작해주세요" + [새 작업 시작] CTA (T-P4-020 모달 재사용)
- [ ] ticket worktree 안 trivial 변경 (typo / import) 도 commit 됨 — empty diff 만 skip
- [ ] commit 직후 status bar "방금 자동저장됨 (HH:MM:SS)" 갱신
- [ ] `post-delegate-state-write` 와 hook 실행 순서 = (1) state-write → (2) autosave (state 가 ticket-id 반영 후 commit 메시지 prepend 가능)
- [ ] `pnpm -r build` 통과

## Out of scope

- push / PR / merge (T-P4-022 [배포 준비] / [배포하기])
- commit 메시지 사용자 편집 UI (Phase 5)
- staging 환경 자동저장 (default off)
- 다중 worktree 동시 자동저장 race condition (Phase 5; current = current_task 한 개만 활성 가정)
- cherry-pick / amend / 기타 git porcelain (Phase 5+)

## Notes

- 모듈 위치: `packages/core/src/git-workflow/autosave.ts` (메시지 합성 + commit) + `packages/core/src/po/hooks/post-delegate-autosave.sh` (hook entry).
- 메시지 1줄 summary 추출 = 페르소나 JSON output 의 `summary` 필드 (designer/developer/qa 모두 보유). 누락 시 fallback `"<persona> turn N output"`.
- "상태 변화" 정의 = ticket `status` 전이 (todo→in-progress, in-progress→review/done) 또는 designer review pass / QA pass. 단순 turn end 만으로는 trigger X.
- base worktree 검사 = T-P4-020 의 protected-branches API 호출. 중복 구현 금지.
- 자동저장 trigger 기록은 `po-state.json.recent_turns` 에 1줄 추가 (lifecycle.md 영향 없음 — 보조 기록).
