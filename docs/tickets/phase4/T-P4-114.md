# T-P4-114 · Main panel auto-open + chat hyperlink + browser tab

---

## §1 Context

**사용자 verbatim**:

> "Main panel 자동 오픈 로직 필요. - 산출물 자동 open. - 현재 진행중인 티켓 focus - po가 ticket을 발행하거나 작업 위임했을 경우 ticket detail page open. - po가 특정 산출물, 파일, 티켓을 언급했을때 해당 언급에 하이퍼링크 달아줘야하고 클릭시 오픈. - po가 url 언급했을 경우에 하이퍼 링크 달고 클릭시 main panel에서 브라우저 오픈 (po와 persona가 브라우저 인풋 아웃풋 읽을 수 있음 for debug)"

**현재 상태 (drift)**:

현재 PO chat 메시지는 `react-markdown` + `remark-gfm` 으로 렌더링되지만 **auto-link 없음**.

| 시나리오 | 현재 사용자 행동 | 문제 |
|:--|:--|:--|
| `docs/design/T-P4-114/plan.md` 언급 | Quick Open 또는 FileTree 수동 클릭 | 컨텍스트 전환 마찰 |
| `T-P4-113` 언급 | TicketDashboard 수동 탐색 | ticket 확인까지 최소 2-step |
| `https://vercel.com` 언급 | 외부 브라우저 열림 | Electron GUI 밖 — persona debug 불가 |
| PO ticket emit / dev dispatch | 알림 없음, tab 자동 open 없음 | §1.5.4 Feedback 위반 |

§1.5 위반 2건: **Predictability** (PO 언급 → 자동 열리지 않음), **Feedback** (ticket 발행 직후 main pane 시각 반응 없음).

## §2 Goal & Non-goals

**Goals:**
- **A. 산출물 자동 open** — dev/persona 작업 완료 후 `changed_files[]` envelope 기반 .md / spec 탭 자동 open (최대 3개 cap).
- **B. ticket focus 자동 open** — PO ticket emit 또는 dispatch 직후 `ticket-review` 탭 자동 open + main pane focus.
- **C. chat message hyperlink** — PO/persona 메시지 내 ticket ID / 파일 경로 / bare URL 자동 감지 → 클릭 시 내부 탭 라우팅.
- **D. `BrowserTab` 구현** — `<webview>` + nav bar (← → ↺ URL입력 ⧉). Playwright MCP IPC 브릿지 예약.
- **E. `MessageBubble` renderer 갱신** — `linkifyText` 전처리 + `Markdown.a` component override 적용.

**Non-goals (§8 Out of scope 참고):**
- Playwright MCP → browser snapshot / console 통합 UI (T-P4-115).
- BrowserTab DevPane (console / network log).
- UserBubble linkify (보안/XSS 방어 — 미적용).
- tab 자동 open preference toggle UI.
- streaming debounce 최적화.

## §3 Approach

### A. 산출물 자동 open

**trigger**: dev/persona 작업 완료 후 envelope `changed_files: string[]` 포함.  
Main process 파싱 → `po:artifact-open` IPC → renderer `WorkspaceShell` 구독 → `openTab` 호출.

**필터 규칙**:

| 조건 | open 탭 type |
|:--|:--|
| `docs/design/**/*.md` 또는 `docs/tickets/**/*.md` | `markdown` |
| `docs/qa/**/*.md` | `markdown` |
| `**/*.spec.ts` / `**/*.test.ts` | `qa-result` (PlaceholderTab — 추후 확장) |
| `src/**`, `scripts/**`, lock 파일 | **skip** |

**cap**: 한 event 에서 최대 3개 탭만 open. 초과 시 info toast:  
`"N개 파일이 변경됨 — Quick Open(Cmd+P) 으로 추가 확인"`

**dedupe**: 기존 `openTab` dedupe 로직 활용 — 이미 열린 tab ID 는 focus 이동만.

> T-P4-112 `changed_files` envelope 포맷 미확정 시 `path[]` 배열 단순 가정. T-P4-112 land 시 포맷 정합.

### B. ticket focus — dispatch 직후 ticket detail tab 자동 open

**trigger**: `po:ticket-focus { ticketId, reason: 'emit' | 'dispatch' }`

**action**: `openTab('ticket-review:' + ticketId, 'ticket-review', { ticketId }, ticketId)`

**IPC channel**: `po:ticket-focus` — `{ ticketId: string; reason: 'emit' | 'dispatch' }`

Main process 파싱: PO envelope JSON 에서 `tickets[]` key → reason `'emit'` / `delegation.ticket_id` key → reason `'dispatch'`.

**UX 보장**:
- 이미 해당 tab 열려 있으면 focus 이동만 (중복 추가 금지).
- dispatch 이후 사용자가 tab 닫아도 다음 dispatch 전까지 강제 재open 없음 (once-per-event).

### C. chat message 내 hyperlink 자동 감지 + 내부 라우팅

**`linkifyText(text: string): string` 유틸리티 — 패턴 우선순위**:

| 우선순위 | 패턴 | 변환 형식 | 색상 힌트 |
|:--|:--|:--|:--|
| 1 | 이미 마크다운 `[text](href)` | 그대로 유지 | 기존 mdLink (#38BDF8) |
| 2 | 티켓 ID: `T-P4-\d+` bare | `[T-P4-NNN](ptn:ticket/T-P4-NNN)` | `--persona-designer` (#A78BFA) |
| 3 | 파일 경로: `(docs\|packages)/[\w/.\-]+\.(md\|tsx\|ts\|sh\|json)` | `[basename](ptn:file/<path>)` | `--persona-dev` (#38BDF8) |
| 4 | bare URL: `https?://[^\s<>"]+` | `[hostname](https://...)` | `--text-secondary` (#C8C8CC) |

**skip 조건**: 백틱 `` `code` `` 블록 내, ` ```fence``` ` 코드 블록 내, 기존 `[…](…)` link 의 href 부분.

**구현 방식 — preprocessor 채택** (Option 2):  
`linkifyText` 가 render 전 `message.text` 처리 → `[…](ptn:…)` md link 치환 → 기존 `react-markdown` `a` 컴포넌트가 처리.  
추가 npm 패키지 없음, 의존성 0, bundle 증가 0.

**click handler — `Markdown.a` component override**:

```
href 접두사 → action
─────────────────────────────────────────────────────────
ptn:ticket/<id>   → openTab('ticket-review:'+id, 'ticket-review', { ticketId: id }, id)
ptn:file/<path>   → openTab('markdown:'+path, 'markdown', { path }, basename(path))
https?://…        → openTab('browser:'+encodedUrl, 'browser', { url }, hostname)
(기타)            → e.preventDefault() + noop (보안 방어)
```

- `e.preventDefault()` 필수 (Electron 외부 nav 방지).
- `useWorkspace.getState().openTab(...)` store 직접 호출.

### D. BrowserTab component (`packages/gui/src/components/workspace/main/panes/BrowserTab.tsx`)

**renderer 결정**: `<iframe>` 은 X-Frame-Options 차단 다수 → `<webview>` 채택.

```html
<webview
  src={url}
  style={{ flex: 1, border: 'none', background: '#0F0F0F' }}
  allowpopups
  partition="persist:browser-tab"
/>
```

**Nav bar (상단 32px row)**:

```
[ ← ] [ → ] [ ↺ ]  [  URL input (flex-1)  ]  [ ExternalLink icon ]
```

- `←` / `→`: `webviewRef.current.goBack()` / `goForward()` — Electron webview API.
- `↺`: `webviewRef.current.reload()` (lucide `RefreshCw`).
- URL input: 사용자 수정 + Enter → `webviewRef.current.loadURL(newUrl)`.
- `ExternalLink`: `shell.openExternal` IPC.

**Playwright MCP IPC 브릿지 예약 (noop)**:

```ts
// packages/main/src/ipc/browser.ts  (신규)
import { ipcMain } from 'electron'

// T-P4-115: playwrightMcp.navigate(url) + snapshot 으로 교체 예정
ipcMain.on('browser:opened', (_e, { url, tabId }: { url: string; tabId: string }) => {
  // noop — channel reserved for T-P4-115
  void url; void tabId
})
```

BrowserTab mount 시 `window.api.browserOpened({ url, tabId })` emit.

### F. Dispatch 후 canonical UX flow

```
[PO 발행 / dispatch]
        │
        ▼
  (1) po:ticket-focus IPC
      → ticket detail tab 자동 open + main pane focus 이동   [§B]
        │
        ▼
  (2) dev 작업 완료
      → po:artifact-open IPC (changed_files[])
      → .md / spec 최대 3개 tab 자동 open                     [§A / T-P4-112]
        │
        ▼
  (3) QA dispatch (T-P4-112 dev-qa loop)
      → qa-result tab open (T-P4-112 scope)
        │
        ▼
  (4) PO chat 메시지 stream
      → linkifyText: T-P4-XXX / file path / URL → hyperlink   [§C / §E]
        │
        ▼
  (5) 사용자 click hyperlink
      → ticket-review tab | markdown tab | browser tab open   [§D]
```

## §5 Acceptance Criteria

**§A — 산출물 자동 open**
- [ ] dev/persona 작업 완료 envelope `changed_files[]` 에 `docs/**/*.md` 포함 시 → main pane 에 markdown 탭 자동 open.
- [ ] 한 event 에서 탭 open 은 최대 3개. 4번째부터 info toast 노출.
- [ ] `src/**` / lock 파일 → 자동 open skip.
- [ ] 이미 열린 탭 → focus 이동만 (중복 탭 없음).

**§B — ticket focus**
- [ ] PO envelope 에 `tickets[]` key → `ticket-review:<id>` 탭 자동 open + main pane focus.
- [ ] PO envelope 에 `delegation.ticket_id` key → 동일 동작, reason `'dispatch'`.
- [ ] 이미 해당 탭 열려 있으면 focus 이동만.
- [ ] 사용자가 탭 닫은 후 → 다음 dispatch event 전까지 강제 재open 없음.

**§C / §E — chat hyperlink**
- [ ] PO/persona 메시지 내 `T-P4-NNN` bare text → 보라(#A78BFA) 밑줄 링크 렌더링.
- [ ] `docs/…/*.md` 파일 경로 bare text → 파랑(#38BDF8) 밑줄 링크 렌더링.
- [ ] `https://…` bare URL → 회색(#C8C8CC) 밑줄 링크 렌더링.
- [ ] 백틱/fence 코드 블록 내 패턴 → 링크 변환 없음.
- [ ] 이미 `[text](href)` 마크다운 링크인 경우 → double-wrap 없음.
- [ ] `UserBubble` → linkify 미적용.

**§C click routing**
- [ ] ticket 링크 click → `ticket-review:<id>` 탭 open / focus.
- [ ] file 링크 click → `markdown:<path>` 탭 open / focus.
- [ ] URL 링크 click → `browser:<encodedUrl>` 탭 open + webview 로드.
- [ ] 알 수 없는 ptn: 접두사 → `e.preventDefault()` + noop.

**§D — BrowserTab**
- [ ] `browser` 탭 활성 시 nav bar (← → ↺ URL입력 ⧉) 상단 32px row 표시.
- [ ] webview 가 전달된 URL 로드.
- [ ] ← / → / ↺ 버튼 동작 (goBack / goForward / reload).
- [ ] URL input 수정 + Enter → 해당 URL 로드.
- [ ] ExternalLink(⧉) 클릭 → 외부 브라우저에서 URL 열림.
- [ ] mount 시 `window.api.browserOpened({ url, tabId })` IPC emit.
- [ ] `packages/main/src/ipc/browser.ts` noop handler 등록 (채널 예약).
- [ ] webview `did-fail-load` 이벤트 → "이 페이지는 로드할 수 없습니다" 오류 UI 표시.

**회귀 방지**
- [ ] `MessageBubble.tsx` — bold / italic / code / list / 기존 마크다운 `[text](https://...)` 링크 동작 유지.
- [ ] `WorkspaceShell.tsx` — 기존 IPC 구독 (deploy modal, baseDirty, session health, worktree) 영향 없음.
- [ ] `TabContent.tsx` — 기존 탭 type 12종 (markdown, version-detail, ticket-review 등) 동작 유지.
