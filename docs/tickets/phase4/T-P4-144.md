## §1 Request

두 개의 독립적인 UI 버그 수정.

**Bug 3 — MCP "확인 중" 배지 무기한 표시**  
`McpServersTab` 에서 서버 목록 로드 시 `status: 'checking'` 으로 초기화하지만,
`mcp:testConnection` IPC 는 Phase 5 structural stub 이라 실제 호출되지 않음.
결과: 모든 MCP 서버 행에 `◌ 확인 중` 영구 표시 → 사용자 혼란.
**Fix**: `StatusBadge` 컴포넌트 전체 제거. 서버 이름 + source tier pill 만 표시.

**Bug 4 — Kanban card 너비가 컬럼 초과 + 내부 가로 스크롤 발생**  
`TicketDashboardView` 의 `columnBody` 에 `overflowX` 미설정, `card` 에 `minWidth: 0`
부재, `cardTitle` 에 word-wrap 없음 → 긴 제목이 카드를 컬럼 밖으로 밀어냄.
**Fix**: 3개 style 상수에 overflow/word-wrap 속성 추가.

## §2 Acceptance

### A1. McpServersTab — StatusBadge 제거

- `McpStatus` 타입 삭제.
- `McpServerEntry` 인터페이스에서 `status: McpStatus` 필드 제거.
- `loadServers()` 에서 `status: 'checking'` spread 제거 (`raw` 를 직접 사용).
- `<StatusBadge ... />` JSX 호출 제거.
- `StatusBadge` 함수 컴포넌트 삭제.
- `badgeBase` 스타일 상수 삭제.
- 서버 행: `serverNameStyle` + `tierPill` 만 렌더.

### A2. McpServerModal 타입 호환

`McpServerModal` props 에서 `server.status` 를 읽지 않는다면 빌드 에러 없음.
읽고 있다면 해당 참조도 제거 (옵셔널 처리 또는 삭제).

### A3. TicketDashboardView — 3개 스타일 수정

```typescript
// 1. columnBody — overflowX 추가
overflowX: 'hidden'

// 2. card — minWidth + overflow 추가
minWidth: 0,
overflow: 'hidden',

// 3. cardTitle — overflowWrap 추가
overflowWrap: 'break-word',
```

### A4. 빌드 통과

```bash
pnpm -F gui build
# 0 TypeScript errors
```

### A5. 시각적 확인 (dev mode)

- MCP 탭: 서버 행에 "◌ 확인 중" 없음. `[local]` / `[project]` / `[productune]` tier pill 만.
- Kanban: 긴 제목 카드가 컬럼 경계 안에 머묾. 컬럼 내부 가로 스크롤 없음.
