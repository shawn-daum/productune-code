# T-P4-048: Settings 탭 — Environment + Models + MCP Servers + Hooks (T-P4-024 git rule 통합)

**Round**: phase4-r4  **Stage**: impl  **Status**: todo  **Assignee**: pdt-developer
**Design**: [docs/design/service-flow-and-screens.md §4.1 Settings 탭](../../design/service-flow-and-screens.md)
**Bundle**: 본 티켓은 `T-P4-R4-workspace-shell` 번들의 일부로 함께 출고.

> Activity Bar 의 Settings 아이콘 (lucide `Settings`) 클릭 시 Side panel 에 Settings 탭 전체 노출. Environment + Models + MCP Servers + Hooks + Workflow rules (T-P4-024 에서 정의한 git rule 토글) 5 섹션. T-P4-024 의 작업 흐름 규칙 패널을 본 탭으로 통합.

## Acceptance

### 헤더
- [ ] `sp-hdr` "Settings" (사용자 화면 한글 tooltip "설정")
- [ ] Activity Bar 아이콘 = lucide `Settings` (20px, stroke 1.75)

### Environment 섹션
- [ ] `pp-sec-hdr` "환경 변수"
- [ ] Project .env (N vars) → `openTab(tabId, 'env-view', { layer: 'project' })`
- [ ] Project secrets (N vars) → `openTab(tabId, 'env-view', { layer: 'secrets' })`
- [ ] User global (N vars) → `openTab(tabId, 'env-view', { layer: 'global' })`
- [ ] 각 항목 우측 var count 표시

### Models 섹션
- [ ] `pp-sec-hdr` "모델"
- [ ] Catalog → 모델 카탈로그 viewer (opus / sonnet / haiku effort matrix) — `openTab(tabId, 'markdown', { path: '~/.productune/models.md' })`

### MCP Servers 섹션
- [ ] `pp-sec-hdr` "MCP 서버"
- [ ] `set-row` × N: graphiti / figma / linear + `s-badge` (ok 초록 "connected" / err 빨강 "unauth")
- [ ] 클릭 → MCP 설정 modal (auth endpoint 입력)
- [ ] 상태는 IPC `mcp:getStatus()` 로 실시간 조회

### Hooks 섹션
- [ ] `pp-sec-hdr` "훅"
- [ ] PreToolUse — `s-badge ok` (N active) → hook list viewer
- [ ] PostToolUse — `s-badge ok` (N active) → hook list viewer
- [ ] 클릭 → hook 목록 + toggle (enable/disable per hook)

### Language 섹션 (T-P4-056 통합)
- [ ] `pp-sec-hdr` "Language / 언어" — bilingual label
- [ ] 라디오 옵션 2 개: English / 한글
- [ ] 변경 즉시 반영 (`setUiLanguage` IPC → `i18next.changeLanguage` → re-render). 앱 재시작 불필요.
- [ ] `~/.productune/settings.json` 에 영구 저장
- [ ] **구현 위치**: `packages/gui/src/components/workspace/LanguageSettings.tsx` (T-P4-056 에서 구현됨). 본 티켓 land 시 Settings 탭 sub-tab 라우터에 연결할 것.

### Workflow rules 섹션 (T-P4-024 통합)
- [ ] `pp-sec-hdr` "작업 흐름 규칙"
- [ ] `useDevBranch` 토글 (boolean, default false) — "검증용 중간 환경 사용"
- [ ] `useStagingEnv` 토글 (boolean, default false) — "외부 점검 환경 사용"
- [ ] `featureBranchPrefix` 텍스트 input (default "feature")
- [ ] `fixBranchPrefix` 텍스트 input (default "fix")
- [ ] `protectedBranches` 표시 전용 (auto-derived)
- [ ] 변경 = `<project>/.productune/git-rules.json` 즉시 저장, 다음 ticket 부터 반영
- [ ] 사용자 화면에 "branch" / "merge" / "worktree" 어휘 노출 X — 자연어 매핑 그대로

## Data source

- `<project>/.productune/git-rules.json` (project-tracked)
- `~/.productune/git-rules.default.json` (global default)
- IPC `mcp:getStatus()` / `hooks:list()` / `hooks:toggle(hookId)`

## Out of scope

- hook 신규 작성 UI (기존 hook 목록 표시 + toggle만)
- MCP server 직접 설치 (설정 + auth만)
- T-P4-030–035 의 env panel 상세 구현 (Round 3 담당, 이 티켓은 설정 진입점만)

## Notes

T-P4-024 (Settings 작업 흐름 규칙 패널) 의 구현 내용을 본 티켓으로 흡수. T-P4-024 는 별도 구현 X — 본 티켓이 대체. Slice 순서: T-P4-046 (Main tab dispatcher) 완료 후 env-view 탭 연결. Workflow rules 섹션은 T-P4-020 (worktree) 과 연동되므로 Round 2 완료 후 검증 권고.
