## §1 Request

**Incident (T-P4-129/T-P4-130 batch):** `pdt-developer` subagent appended `## Persona Activity`
rows to ticket `.md` files on its own. PO also appended per mechanical duty → duplicates. PO
deduped post-hoc.

**Audit:** No developer or QA variant file mentions or prohibits writing Persona Activity rows.
Gap (absence of prohibition) → LLM agent infers self-update from reading the ticket template.

**Decision:** PO 단독. Developer and QA return turn summary in JSON `notes` field. PO does 1-row
mechanical append. Designer: no change (authors initial rows at ticket creation — legitimate).
