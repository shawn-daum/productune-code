# T-P4-150 — JSON-only persona output doctrine

## §1 Request

Enforce JSON-only stdout from all three persona sub-agents (developer / designer / qa)
across all three backend variants (graphiti / keeper / fs). Eliminate the current mixed
JSON + prose body pattern. Add two new fields (`summary` ≤200 char, `user_surface` ≤500 char)
to carry human-readable content that PO paraphrases for the user.

Expected ROI: ~80% output-token reduction per dispatch.
