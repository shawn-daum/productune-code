## §1 Request

**User directives verbatim (2026-05-19):**
> "Phase gate 이거 불편하네.. 그냥 PO랑 대화하면서 Phase 넘어가도록 하자."
> "프로젝트탭 사이드 패널의 PHASE부분 없애자."

**Root cause**: Phase transition previously used a top-pinned modal banner (`PhaseTransitionGate`) with Approve/Modify buttons. User prefers natural chat flow — PO determines phase transition from conversation, no GUI interrupt needed. Separately, the PHASE section in LeftSidebar Project panel is redundant (phase context already visible in ChatPanel chip).

**Changes (3 areas, 5 files):**
1. `MainPanel.tsx` — remove PhaseTransitionGate mount + all gate-related state/handlers
2. `PhaseTransitionGate.tsx` — JSDoc deprecation annotation only (file kept)
3. `LeftSidebar.tsx` — remove PhaseStrip strip variant + unused import + secHdr style
4. `~/.productune/sections/_details/po-loop-extras.md` — doctrine: chat-driven gate (PO-applies)
5. `~/.productune/sections/po-loop.md` + `po-state-schema.md` — 1-line updates (PO-applies)
