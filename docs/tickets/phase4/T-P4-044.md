## Data source

- 정적 skill 목록: `~/.claude/agents/<persona>.md` parse
- 활동 trace: `po-state.json` `current_task.persona_session_meta.<persona>` (turns / last_seen / model_history)
- 현재 turn skill: ticket `## Persona Activity` 또는 별도 trace 로그
- Promotion candidates: `po-state.json` 의 pending promotion queue
