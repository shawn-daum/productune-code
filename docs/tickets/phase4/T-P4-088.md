# T-P4-088: `productune:open-tab` listener wire (T-P4-048 dispatcher spec gap)

> Settings → Environment / Models row click 이 silent (아무것도 안 일어남). `window.dispatchEvent('productune:open-tab')` 를 받는 listener 가 어디에도 등록 안 됨. WorkspaceShell 에 useEffect 로 wire.

## §1 Background

사용자 dogfood (2026-05-11):

> Settings 탭 → "환경 변수" sub-tab → "프로젝트 .env / 프로젝트 시크릿 / 사용자 전역" row 클릭 → 아무것도 안 일어남.

### Root cause

`packages/gui/src/components/workspace/SettingsView.tsx` 의 `EnvironmentSection` (L58~83) 과 `ModelsSection` (L87~104) 모두:

```ts
window.dispatchEvent(new CustomEvent('productune:open-tab', {
  detail: { tabType: 'env-view', params: { layer } },
}))
```

발사. 그러나 `grep -rn "productune:open-tab" packages/gui/src` = **2 hit (dispatch 만)**, listener 0 — `window.addEventListener('productune:open-tab', ...)` 가 어디에도 없음.

`WorkspaceShell.tsx` 는 `productune:quick-open` listener 는 등록 (L95~100) 하지만 `open-tab` listener 누락. T-P4-046 dispatcher impl + T-P4-048 SettingsView impl 사이 **spec gap forward fix**.

### 컨텍스트 — T-P4-048 dev note

T-P4-048 SettingsView 가 "T-P4-046 dispatcher 와 wire 누락 (TODO)" 으로 명시한 spec gap. 본 ticket 이 그것을 완결.

## §4 Acceptance

### A) Listener 등록 (WorkspaceShell)

- [ ] `packages/gui/src/views/WorkspaceShell.tsx` 에 useEffect 추가:
  - [ ] `window.addEventListener('productune:open-tab', handler)` 등록
  - [ ] handler 가 `event.detail` 에서 `tabType` / `params` / 옵션 `tabId` 추출
  - [ ] tabId derive 규칙:
    - `tabType === 'env-view'` → `env-view:${params.layer ?? 'default'}`
    - `tabType === 'markdown'` → `markdown:${params.path}` (stable per file)
    - 일반: `${tabType}` (params 없으면) / explicit `tabId` 제공 시 그대로
  - [ ] `openTab(tabId, tabType, params ?? {})` 호출
