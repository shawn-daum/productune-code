## Request

`productune init` (CLI + GUI `project:installAt`) 와 GUI `dialog:openFolder` 의 hygiene 강화. 단일 ticket 으로 4 sub-area 묶음:

1. **settings.local.json 다른 user 잔재 차단** — `.claude/settings.local.json` 의 `permissions.allow` 에 다른 user absolute path glob (`/Users/<other>/...`) 이 있으면 backup + default 교체. 신규 폴더는 default template 박음.
2. **`.gitignore` 자동 보강** — `.claude/settings.local.json` 항목 자동 추가 (없으면). 다른 user 잔재가 git/zip transfer 로 따라오는 것 자체 차단.
3. **GUI legacy `.productune/` layout self 감지** — config.json 없이 `briefs/`, `po-state.json`, `po.lock` 만 있는 폴더도 self 인식 + 사용자 confirm 후 idempotent migration.
4. **install 모달 시각** — 어두운 배경 위 어두운 모달 + 회색 본문 (~`#A0A0A0` 추정) → WCAG AA 미달 가능. design system 토큰 정렬 + 본문 `--text-primary` (`#E8E8EA`, AAA) + 모달 elevation (border + shadow) 강화.

## Acceptance

### A. settings.local.json hygiene (init 시점)

- [ ] `packages/core/src/init.ts` 에 `bootstrapClaudeSettings(projectDir)` 함수 추가 — `initProject` 의 마지막 step (`config.json` write 후, `bootstrapPersonaMemory` 와 동급) 으로 호출.
- [ ] `.claude/settings.local.json` 존재 시:
  - [ ] `permissions.allow` 의 string entry 를 regex `/^[A-Za-z]+\(\/{1,2}Users\/([^/)]+)\//` 로 검사.
  - [ ] capture 된 user 이름 ≠ `os.userInfo().username` 인 entry 가 1개 이상이면 = "foreign-user 잔재" 판정.
  - [ ] 판정 시 `settings.local.json` 을 `settings.local.json.legacy-<ISO timestamp>.json` 로 backup (timestamp = `new Date().toISOString().replace(/[:.]/g,'-')`) → default template 으로 교체.
  - [ ] 판정 X 면 사용자 customization 보존 (no-op).
- [ ] `.claude/settings.local.json` 부재 시 default template 박음.
- [ ] Default template 내용 (design doc §3.1):
  - `Read(<projectDir>/**)`, `Write(<projectDir>/**)`, `Edit(<projectDir>/**)`
  - `Bash(npm *)`, `Bash(pnpm *)`, `Bash(git *)`, `Bash(node *)`, `Bash(python3 *)`, `Bash(jq *)`, `Bash(claude *)`, `Bash(codex *)`
  - `<projectDir>` 는 `opts.projectDir` 로 substitute (absolute path).
- [ ] **Relative-glob self-check (impl 단계 결정)**: dev 가 새 폴더에 `{"permissions":{"allow":["Write(./**)"]}}` 만 박고 claude code Write 시도 → deny → absolute 채택 (현 default), pass → relative 로 단순화 + 본 acceptance 수정. **결과를 design doc §6 OQ 에 기록**.
- [ ] `bootstrapClaudeSettings` 도 idempotent — 두 번째 호출 시 default 박혀 있으면 skip.

### B. .gitignore 자동 보강

- [ ] `bootstrapClaudeSettings` 안에서 `<projectDir>/.gitignore` 검사:
  - [ ] 파일 없으면 신규 생성 + `.claude/settings.local.json\n` 한 줄 작성.
  - [ ] 있고 해당 줄 X 면 append (`\n.claude/settings.local.json\n`).
  - [ ] 이미 있으면 no-op.

### C. GUI legacy layout 감지 + migration

- [ ] `packages/gui/electron/main.ts` 에 `detectProductuneLayout(dir)` 함수 신규 — design doc §3.3 spec.
- [ ] return shape: `{ kind: 'self-current' | 'self-legacy' | 'none', config?, hints? }`.
  - `self-current`: `.productune/config.json` 존재 + parsable.
  - `self-legacy`: `.productune/` 존재 + (`po-state.json` || `briefs/` || `po.lock` || `turns/`) 1개 이상, config.json X.
  - `none`: 위 둘 다 X.
- [ ] `dialog:openFolder` handler:
  - `self-current` → 기존 `kind:'self'` 동작 (호환 유지).
  - `self-legacy` → 신규 return `{ kind:'self-legacy', dir, hints }`.
  - 그 외 → 기존 descendant / none 분기.
- [ ] `scanDescendantsForProductune` 도 legacy 인식 — `readProductuneConfig` 만으로 판정하던 부분을 `detectProductuneLayout` 호출로 교체. legacy descendant 도 list 에 포함.
- [ ] 신규 IPC `project:migrateLegacy` handler — 입력 `{ projectDir, slug? }`:
  - slug 미지정 시 `path.basename(projectDir)` lowercase + sanitize.
  - `initProject({ slug, projectDir })` 호출 — 기존 `briefs/` / `po-state.json` / `po.lock` / `turns/` 보존 + `config.json` 추가 + `bootstrapPersonaMemory` (없는 docs/* 만 채움) + `bootstrapClaudeSettings`.
  - return `{ projectDir, config, migrated: true }`.
- [ ] Renderer 측 `OpenFolderResult` (또는 등가 컴포넌트) 에 `self-legacy` 분기 UI 추가:
  - 모달 메시지: "이 폴더는 옛 productune 프로젝트로 보입니다. 감지된 항목: <hints join('/')>. 최신 layout 으로 업데이트하면 기존 작업 내역은 그대로 보존됩니다. 진행할까요?"
  - 버튼: [업데이트] (primary, → `project:migrateLegacy` 호출) / [취소] (secondary).
  - 업데이트 성공 시 self-current 와 동일 진입 flow 로 합류.
