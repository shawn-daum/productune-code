# T-P4-087: Team Side Panel — Skills section 축약 (list → summary card)

> 사이드 패널의 Skills 섹션을 개별 skill row list 에서 **요약 카드 1개** (`N skills · M active`) 로 축약. 클릭 시 메인 패널 skill-matrix 탭 open. 개별 skill 목록은 메인 패널에서만 노출.

## §1 Background

사용자 directive (2026-05-11):

> "skill 표시 어차피 사이드 패널에 목록 다 안넣어줘도돼 오른쪽에 메인 패널에 나오잖아 클릭하면. 사이드 패널엔 스킬 몇개 다운로드되어있고 몇개 활성화중이다. 클릭하면 전체 나온다 이정도 정보면 충분해."

### 현 동작 (T-P4-044 land 산출물)

`packages/gui/src/components/workspace/TeamPanel.tsx` 의 Skills section:

- `SKILL_CATALOG` 11개 entry 를 `SKILL_LIMIT = 8` 으로 slice → `SkillRow` 8 row 표시 + `"+N more"` link
- 우상단 `secHdrRight` 에 `matrixBtn` (`workspace.team.section.skillsMatrix` → `↗`) — 메인 panel `skill-matrix` 탭 open
- 개별 row 클릭 시 `openTab('skill-matrix', 'skill-matrix', { focusRow: skillId })` 으로 메인 panel 에 focusRow params 와 함께 open

### 의도

사이드 패널 = **인디케이터**. 전체 인벤토리 = 메인 패널. 사이드에서 사용자가 알아야 할 정보 = "skill 몇 개 있고 몇 개 활성화 중인가" 단일 numeric 카드.

§1.5 Few Things 원칙 정합 — 사이드 패널 dense 정보 절감.

## §2 결정 사항 (designer 판단, work-without-stopping)

| OQ | 결정 |
|---|---|
| "active" 정의 | **persona 에 배정된 (= `skill.personas.length > 0`) skill 개수**. 전체 catalog 가 활성 candidate 이므로 현재는 모든 entry 가 active 이지만, 향후 `enabled: false` flag 도입 시 자동 정합 (designer note in code) |
| 카드 클릭 vs hover | **카드 전체 click → skill-matrix tab open**. hover = subtle background highlight (기존 `SkillRow` 패턴 답습) |
| 우상단 matrix link | **유지** (alt path). 카드 click 과 동일 동작 — duplicate path 허용 (Predictability §1.5.3) |
| ko 라벨 | "N개 스킬 · M개 활성화" (조사 자연스러움) |
| 11 vs 12+ skills 시 카드 너비 | 단일 row, 숫자 자릿수 영향 X (3자리까지 여유) |
