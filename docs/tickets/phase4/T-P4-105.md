# T-P4-105 — 프로젝트 열기 시 current_version 탭 자동 오픈 (board 오픈 제거)

## §1 Background

### 1.1 발단 — dogfood 피드백

v0.4-meta-dogfood 진행 중 사용자 관측:

> "처음에 프로젝트 열면 ticket tab이 여전히 살아있거든? 대신 현재 진행 버젼 탭을 열어줘야돼."

`WorkspaceShell.tsx` mount `useEffect`(line ~230–233)가 `poState`와 무관하게 항상 `ticket-review:board` 탭을 연다. T-P4-102로 `SidePanelCurrentVersion` mount 시 `ticket-review:{versionId}` 탭이 열리는 경로는 확보됐지만, `WorkspaceShell` mount effect가 그보다 먼저(또는 동시에) `board` 탭을 열어버려 두 탭이 공존하거나 `board`가 기본 포커스를 가져간다.

### 1.2 추가 진입점 — Activity bar 'tickets' click

`onSelectActivity` (line ~222–227) 역시 항상 `ticket-review:board`를 연다. `current_version`이 있는 프로젝트에서 아이콘을 클릭하면 board 전체 탭이 포커스되어 버전 컨텍스트에서 이탈한다.

### 1.3 결론

두 진입점 모두 `poState.current_version`을 참조하도록 수정한다.

- **mount auto-open**: `current_version` 있으면 → `ticket-review:{cv}` (versionFilter). 없으면 → 아무것도 열지 않음(empty pane greeting, DS §1.5 준수).
- **Activity icon click**: `current_version` 있으면 → `ticket-review:{cv}`. 없으면 → `ticket-review:board` (기존 fallback 유지, 버전 없는 상태에서 유일한 진입점).

`SidePanelCurrentVersion` mount effect(T-P4-102 landed)는 동일 tab id(`ticket-review:{cv}`)를 호출하므로 `openTab` 내부 dedup으로 이중 오픈 없음 — 변경 불필요.

## §2 Scope

### (a) WorkspaceShell mount useEffect — 조건부 오픈으로 교체

**변경 위치**: `packages/gui/src/views/WorkspaceShell.tsx` lines ~229–233.

```ts
// BEFORE
useEffect(() => {
  openTab('ticket-review:board', 'ticket-review', undefined, 'Tickets')
  // eslint-disable-next-line react-hooks/exhaustive-deps
}, [])

// AFTER
useEffect(() => {
  const cv = useWorkspace.getState().poState?.current_version
  if (cv) {
    openTab(`ticket-review:${cv}`, 'ticket-review', { versionFilter: cv }, cv)
  }
  // no auto-open when no current_version (empty pane greeting)
  // eslint-disable-next-line react-hooks/exhaustive-deps
}, [])
```

- `useWorkspace.getState()` — mount effect는 reactive selector 불필요. store 직접 읽기(WorkspaceShell 내 다른 mount effect에서 이미 사용 중인 패턴, line ~242, ~289).
- `poState?.current_version` — null / undefined 양쪽 safe.
- 조건 미충족 시 → effect 종료, 탭 미생성. empty pane은 기존 EmptyPane 컴포넌트가 렌더 (기존 동작).

### (b) onSelectActivity 'tickets' 클릭 — current_version 우선 라우팅

**변경 위치**: `packages/gui/src/views/WorkspaceShell.tsx` lines ~222–227.

```ts
// BEFORE
const onSelectActivity = (icon: ActivityIcon) => {
  setActiveIcon(icon)
  if (icon === 'tickets') {
    openTab('ticket-review:board', 'ticket-review', undefined, 'Tickets')
  }
}

// AFTER
const onSelectActivity = (icon: ActivityIcon) => {
  setActiveIcon(icon)
  if (icon === 'tickets') {
    const cv = useWorkspace.getState().poState?.current_version
    if (cv) {
      openTab(`ticket-review:${cv}`, 'ticket-review', { versionFilter: cv }, cv)
    } else {
      openTab('ticket-review:board', 'ticket-review', undefined, 'Tickets')
    }
  }
}
```

- current_version 존재 → 현재 버전 ticket board (scopde). 이미 열려 있으면 dedup → focus.
- current_version 없음 → 기존 board (ALL tickets). 버전 없는 프로젝트 초기 진입 경로 보존.

### (c) SidePanelCurrentVersion mount effect — 변경 없음

T-P4-102에서 landed. tab id = `ticket-review:${cv}`, props = `{versionFilter: cv}` — (a)와 동일 id 생성 → `openTab` dedup 처리. WorkspaceShell mount와 SidePanelCurrentVersion mount 중 누가 먼저 실행되더라도 한 탭만 생성됨. **코드 변경 없음**.

### (d) 전수 진입점 dispatch table (변경 후)

| 진입처 | 조건 | tab id | props | 변경 여부 |
|---|---|---|---|---|
| WorkspaceShell mount useEffect | `current_version` 있음 | `ticket-review:{cv}` | `{ versionFilter: cv }` | **변경** |
| WorkspaceShell mount useEffect | `current_version` 없음 | — (오픈 안 함) | — | **변경** |
| `onSelectActivity` `'tickets'` | `current_version` 있음 | `ticket-review:{cv}` | `{ versionFilter: cv }` | **변경** |
| `onSelectActivity` `'tickets'` | `current_version` 없음 | `ticket-review:board` | `undefined` | 기존 그대로 |
| SidePanelCurrentVersion mount | always (cv 있을 때만 렌더) | `ticket-review:{cv}` | `{ versionFilter: cv }` | 변경 없음 |
| LeftSidebar `handleVersionClick` current | — | `ticket-review:{cv}` | `{ versionFilter: cv }` | 변경 없음 (T-P4-102) |
| quick-open palette | — | `ticket-review:{ticketId}` | `{ ticketId, … }` | 변경 없음 |

## §3 Acceptance Criteria

1. **Fresh project open (no current_version)** → `ticket-review` 계열 탭 자동 오픈 없음. 빈 pane(EmptyPane) 노출.
2. **current_version='v1' 프로젝트 open** → `ticket-review:v1` 탭 단 1개 자동 오픈. `ticket-review:board` 탭 미생성.
3. **Activity bar tickets icon 클릭 (current_version='v1')** → `ticket-review:v1` 탭 오픈/포커스. board 탭 미생성.
4. **Activity bar tickets icon 클릭 (no current_version)** → `ticket-review:board` 탭 오픈. 기존 동작 유지.
5. **SidePanelCurrentVersion mount + WorkspaceShell mount 동시** → 중복 탭 없음. `ticket-review:v1` 단일 탭 (openTab dedup).
6. **이미 `ticket-review:v1` 탭 열린 상태에서 icon 재클릭** → 중복 탭 없음. 기존 탭 focus.

## §6 §1.5 Self-Check (Design System UX Principles)

| Sub-rule | 검증 | 결과 |
|---|---|---|
| **§1.5.1 Few Things** | board 탭이 열리지 않음으로써 surface 감소. 사용자가 배울 새 패턴 없음 — 이미 아는 ticket board가 current version scope로 열릴 뿐. | ✓ pass |
| **§1.5.2 Familiar** | 프로젝트 열기 = 현재 작업 바로 보임. 기존 ticket board UI 그대로 — 낯선 신규 view 없음. | ✓ pass |
| **§1.5.3 Predictability** | `current_version` 있는 프로젝트 → 항상 해당 버전 탭. `current_version` 없음 → 빈 pane(명확한 "아직 버전 없음" 신호). 동작 일관성. | ✓ pass |
| **§1.5.4 Feedback** | mount 즉시 탭 오픈(시각 변화). icon 클릭 → 탭 포커스 즉각. empty pane = 의도적 상태(no version). | ✓ pass |
| **§1.5.5 Escape** | 탭 X 닫기 동작 그대로. auto-open은 비파괴적 — 닫으면 그만. | ✓ pass |

**Anti-pattern 점검**:
- ~~"board 탭 + version 탭 중복 생성"~~ → 제거됨. mount effect는 cv 있을 때 한 탭만. ✓
- ~~"action with no visual feedback"~~ → mount 시 탭 즉시 생성(시각). empty pane도 명확한 상태. ✓
- ~~"no current_version인데 version tab 오픈"~~ → 조건부 guard로 방지. ✓
