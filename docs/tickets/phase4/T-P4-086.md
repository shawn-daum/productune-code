# T-P4-086: Ticket → Version frontmatter migration (T-P4-065 sub-f spec gap forward fix)

> doctrine SoT (`poState.versions[]`) ↔ ticket md mapping 회복. frontmatter `version:` field 일괄 stamp + PO 발행 logic 보강 + scan IPC fallback 폐기 + GUI "Unassigned" 가시화.

## §1 Background

사용자 dogfood (2026-05-11): `ProjectVersionsSection` (T-P4-085 land 이후) 의 version expand 시 모든 row 가 "티켓 0" 표시. 실제 docs/tickets/phase4/T-P4-*.md 에 56개 ticket 존재.

### Root cause

`packages/gui/electron/main.ts:613~668` `tickets:scan` IPC handler 가 `version: fm.version ?? versionDir` fallback 사용. 그러나:

- ticket md frontmatter 에 `version:` field 전수 누락 (`grep -rln "^version:" docs/tickets/` = 0)
- fallback `versionDir = "phase4"` 로 ticket.version 박힘
- `poState.versions[].id` = `"v0.4-meta-dogfood"` 같은 semantic slug — mapping X

### 컨텍스트 — T-P4-065 sub-f spec gap

`packages/core/po/sections/tickets.md` L76, L78 에 `version` 은 **이미** "Required frontmatter" 명시. sub-f (po-state slim, ticket md = SoT) 시점에 추가됐어야 할 field. spec land + 기존 ticket 일괄 stamp 누락 + PO 발행 logic 미반영 = **forward fix**.

자세한 design plan: `docs/design/T-P4-086-ticket-version-frontmatter-migration.md`.
