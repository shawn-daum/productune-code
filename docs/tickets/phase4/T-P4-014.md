# T-P4-014: GitHub OAuth → private repo 자동 생성 + git remote 설정

**Round**: phase4-r1  **Stage**: impl  **Status**: todo  **Assignee**: pdt-developer

> planner mode 신규 프로젝트 생성 시 GitHub private repo를 자동으로 만들고 remote 연결. 실패/건너뛰기 시 로컬 전용으로 계속.

## Request

### 1. OAuth flow (Device Flow 사용 — Electron에 적합)
- GitHub OAuth App (Device Flow): `POST /login/device/code` → 사용자에게 코드 표시 → polling `POST /login/oauth/access_token`
- token을 `~/.productune/credentials.json`에 저장 (모드 0600)

### 2. repo 생성
- `POST /user/repos` — `{ name: slug, private: true, auto_init: true }`
- `git remote add origin <clone_url>` + 초기 push

### 3. GUI
- OAuth 진행 중: 코드 + GitHub 링크 표시 (Electron `shell.openExternal`)
- 성공: "✓ my-saas.git 연결됨" 배너
- 실패/건너뛰기: "로컬 전용으로 계속" → workspace 진입

## Acceptance
- [ ] Device Flow OAuth 정상 동작
- [ ] private repo 생성 + remote 연결
- [ ] credentials.json 권한 0600
- [ ] 건너뛰기 → 로컬 전용 workspace 진입
- [ ] 이미 token 있으면 OAuth 생략 (재사용)
