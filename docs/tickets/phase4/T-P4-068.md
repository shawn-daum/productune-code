# T-P4-068: BackgroundTaskMonitor — PresenceBar count badge + StatusBar BackgroundTaskSegment + height 28→36px

## Background

사용자 dogfood 발견: PO 가 designer/dev/qa sub-agent 동시 background 호출 시 GUI visibility 부족. 어떤 작업 진행 중인지 사용자가 모름. 사용자 directive (2026-05-08): **C 채택 — PersonaPresenceBar 보강 + StatusBar 신 segment 둘 다**. height 28→36px (잘 보이게).

- [ ] `WorkspaceShell` (T-P4-046) `gridTemplateRows: '44px 1fr 28px'` → `'44px 1fr 36px'`

- [ ] T-P4-059 SessionHealthSegment 36px 안 vertical center 회귀 X

### B) BackgroundTaskSegment (StatusBar 신 segment)

- [ ] `BackgroundTaskSegment` 신규 컴포넌트, StatusBar 안 SessionHealthSegment 우측 배치
- [ ] compact 4 case:
  - 0 → "Idle" placeholder (`--text-muted`, dim) — §1.5.3 권장 (항상 visible)
  - 1 → `<persona dot> designer working…`
  - 2~3 → `designer × 2 + dev × 1` (count + persona 압축)
  - 4+ → `4 tasks running` (총 count)
- [ ] running 시 dot 1.5s loop blink (0.6 → 1.0 opacity, reduced-motion 시 stop)
- [ ] divider 좌우 1px `--border-subtle` (StatusBar segment 관례)

### C) Hover popup (portal)

- [ ] portal positioning: StatusBar segment 우측 정렬, 위로 펼침
- [ ] T-P4-058 modal/popover surface tokens (`--surface-modal` `#1C1C20`, `--border-strong`, border-radius 8, shadow)
- [ ] max-width 360 / max-height 320 / overflow scroll
- [ ] Header: "Background tasks ({count})" + 우상단 ×
- [ ] Running list: row = persona 6px dot + description (1줄, ellipsis) + duration · status
- [ ] Recent (last 10) 섹션 — done/error
- [ ] Empty: "No background tasks." (i18n)
- [ ] Esc / 외부 click / × 모두 닫기 (§1.5.5)

### D) Auto-fade (focus-aware countdown — 사용자 OQ-3 결정)

- [ ] task `status: 'done'` 전이 시 5s countdown 시작
- [ ] `document.visibilityState === 'visible' && document.hasFocus()` 일 때만 카운트
- [ ] background / minimize / 다른 앱 spotlight 시 일시 정지, 돌아오면 resume
- [ ] 5s 경과 → fade-out 200ms → "Recent" 섹션 이동 (compact 표시에서 즉시 제거)
- [ ] dismiss 정책: running 불가 (× 비활성 + tooltip "still running"), done/error 만 가능

### E) PersonaPresenceBar count badge

- [ ] working 상태 task 수 ≥ 2 인 페르소나 chip 우상단 14×14 circle 배지
- [ ] 0 / 1 → 배지 X
- [ ] 2+ → 숫자 (`2`, `3`, `9+`)
- [ ] 배지 bg = chip 의 persona token hex (`--persona-designer` 등) 채도 유지
- [ ] 배지 text `--text-emphasis` (#F0F0F0), 10px / weight 600
- [ ] 배지 border 2px `--surface-body` outline (chip 위에 떠 있는 느낌)
- [ ] chip click → BackgroundTaskSegment popup 강제 open + 해당 persona filter (popup 상단에 "designer (2)" 헤더 + close affordance)

### F) Store + po-runner integration

- [ ] `src/store/useBackgroundTasks.ts` (zustand) 신규 slice
- [ ] type `BackgroundTask`: id (tool_use_id) / persona / description / started_at / completed_at? / status ('running' | 'done' | 'error')

- [ ] selector: `running()` / `recent()` (last 10) / `countByPersona()`
- [ ] po-runner stream-json parser hook:

## QA scenarios (light)

1. **idle** — task 0 → segment "Idle" placeholder 노출
2. **single running** — sub-agent 1 호출 → `<persona dot> persona working…` + dot blink
3. **multi running compact** — designer × 2 동시 → `designer × 2` + count badge
4. **popup hover** — segment hover → popup open / running list + Recent 섹션
5. **focus-aware fade** — task done → 5s countdown / GUI background 시 일시 정지 / focus 복원 시 resume
6. **error** — sub-agent error → row status 라벨 "error" + `--health-error` 색
7. **dismiss policy** — running × 비활성 (tooltip), done/error × 활성
8. **chip click** — PresenceBar chip click → popup 강제 open + persona filter
9. **reduced-motion** — OS 설정 시 dot blink / fade 비활성
