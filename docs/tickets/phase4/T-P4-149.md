# T-P4-149 — Session lifecycle policy: per-ticket fresh / per-turn resume

## §Request

ticket close (status = done / blocked / abandoned) 시점에 해당 persona session_id 를 즉시 폐기.
다음 ticket dispatch = 항상 fresh (no `--resume`).
동일 ticket 내 multi-turn 은 resume 유지.

**목표 절감**: 5-ticket batch $8.6 → $2.5 (↓70%). crossover ≈ 3 tickets.
