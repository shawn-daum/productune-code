# T-P4-146 — MCP 서버 추가 + name rename 활성화

## Request

Phase 5 deferral에서 v0.4로 앞당긴 항목 1/3.  
`McpServersTab`의 `[+ 서버 추가]` 버튼 활성화 + `McpServerModal` name 필드 editable 전환.  
신규 `mcp:add` / `mcp:delete` IPC 추가, i18n 정리 포함.

## Design doc

`docs/design/T-P4-146/plan.md` — 전체 spec (IPC 명세, 컴포넌트 spec, 유효성 규칙, i18n key, 스타일).

## §Scope

**In scope**

1. `McpServersTab` — `[+ 서버 추가]` 버튼 활성화, `phaseLockLabel` 제거, "new" 모드로 modal 열기.
2. `McpServerModal` — `mode: 'new' | 'edit'` prop 추가, name 필드 editable, 유효성 검증 (빈 이름 / 중복 / 특수문자 / max 64자), rename 시 delete+add flow.
3. `main.ts` — `mcp:add` IPC (중복 가드), `mcp:delete` IPC (idempotent) 추가.
4. `preload.ts` — `mcpAdd`, `mcpDelete` 노출.
5. `ko.json` / `en.json` — `addBtnTooltip` 제거, `emptyDesc` 변경, 신규 key (`modal.newTitle`, `modal.namePlaceholder`, `modal.nameError.*`) 추가.

**Out of scope**

- Source tier 선택 UI (local 고정 hidden).
- Connection test 실제 구현 (기존 stub 유지).
- `productune` tier 서버 GUI 편집.
- 서버 삭제 버튼 (rename-only 삭제 경로 제외).
- a11y / aria-label 개선.

## §Risk

- **Rename 원자성**: `mcp:delete` 성공 + `mcp:add` 실패 시 서버가 사라질 수 있음. 단일 사용자 Electron 앱에서 확률 낮으나, frontend에서 실패 시 toast + 재시도 안내로 완화. 완전 원자적 롤백은 scope 외.
- `~/.claude.json` write 실패 (권한 이슈) → 기존 `mcp:save`와 동일 error path (toast).
