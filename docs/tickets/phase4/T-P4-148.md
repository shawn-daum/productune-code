## §2 Acceptance

### A1. Core — `packages/core/src/agents/persona-def.ts` (신규)

새 파일 생성. 타입 + 유틸:

```ts
export type PersonaModel  = 'sonnet' | 'opus' | 'haiku'
export type PersonaEffort = 'low' | 'medium' | 'high' | 'xhigh' | 'max'
export interface PersonaFrontmatter {
  name?: string; description?: string; model?: PersonaModel
  default_effort?: PersonaEffort; permissionMode?: string
  tools?: string; color?: string; [key: string]: unknown
}
export interface ParsedPersonaDef { frontmatter: PersonaFrontmatter; body: string }
```

함수:
- `parsePersonaDef(content: string): ParsedPersonaDef` — `---` 블록 regex 파싱
- `serializePersonaDef(parsed: ParsedPersonaDef): string` — `---\n{yaml}\n---\n{body}` 재조립
- `resolveAgentFilePath(personaId: string): string` — `fs.realpathSync(~/.claude/agents/{personaId}.md)`, 실패 시 원본 경로 fallback
- `savePersonaDef(personaId, patch: Partial<PersonaFrontmatter>): void`
  - `resolveAgentFilePath` → read → parse → **허용 키만 merge** (`model`, `default_effort`, `description`) → serialize → `tmp + rename` atomic write
  - `~/.claude/agents/` 심링크 파손 방지: 반드시 realpathSync 후 write

`packages/core/src/index.ts` 에 export 추가.

### A2. IPC — `settings:loadPersonaDef` / `settings:savePersonaDef`

`packages/gui/electron/main.ts` — `// ── Settings IPC` 블록 하단 (T-P4-148 섹션):

```ts
ipcMain.handle('settings:loadPersonaDef', (_event, personaId: string) => {
  try {
    const content = fs.readFileSync(resolveAgentFilePath(personaId), 'utf-8')
    const { frontmatter } = parsePersonaDef(content)
    return { ok: true, frontmatter }
  } catch (e: any) { return { ok: false, error: e?.message } }
})

ipcMain.handle('settings:savePersonaDef', (_event, personaId: string, patch) => {
  try { savePersonaDef(personaId, patch); return { ok: true } }
  catch (e: any) { return { ok: false, error: e?.message } }
})
```

import 상단에 core util export 추가.

### A5. UI — `PersonaDefTab.tsx` 개편

1. **상단 주석** `Phase 4 preview-only` 제거.
2. **state 추가** (plan.md §A5 참조): `def`, `draft`, `editing`, `saving`, `saveStatus`, `saveError`, `skills`.
3. **useEffect**: mount 시 `loadPersonaDef(meta.id)` + `listSkills()` 호출.
4. **Header `modelBadge`**: `def` 로드 후 dynamic (`{def.model} / {def.default_effort ?? '—'}`).
5. **SPEC 섹션** (기존 Metadata 섹션 확장 or 별도):
   - `description` (role) / `model` / `default_effort` 행
   - 비편집 시: 정적 텍스트 (metaRow 스타일 유지)
   - 편집 시: `<textarea>` / `<select>` (plan.md §A5 스타일 상수)
   - `permissionMode` / `source` 행 read-only 그대로 유지
6. **편집 버튼 바**: Edit → `editing=true` ; Save → `savePersonaDef` call + 1.5s green banner ; Cancel → `draft` 초기화.
7. **ASSIGNED SKILLS 섹션** (`sectionSubHdr` 스타일):
   - `skills.filter(s => s.personas.includes(meta.key))` → 행 목록
   - 각 행 ×: `setPersonaAssignment(id, meta.key, false)` 즉시 호출; `conflictType==='path-inferred'` → 경고 아이콘 + tooltip
   - 하단 + 버튼 → 미할당 skill 드롭다운 (단순 list, Esc 닫힘)
   - 로딩 중 행 opacity 0.5
8. **스타일 상수**: `editBar`, `btnPrimary`, `btnSecondary`, `inputField`, `selectField`, `successBanner`, `errorBanner` 추가 (plan.md §A5 상수).
