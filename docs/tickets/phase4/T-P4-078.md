  const filesBlock = attachedFiles.length > 0
    ? `## Attached files\n${attachedFiles.map((p) => `- ${p}`).join('\n')}\n\n`

## QA scenarios (light)

1. **hover open** — segment hover → popup open
2. **hover close (grace)** — segment 떠나면 200ms 후 close, 그 사이 popup 위로 이동하면 유지
3. **persona filter hover** — PresenceBar chip click → popup open with persona filter → segment hover 외부에서도 유지 (filter mode 정합)
4. **Esc 닫기** — popup open → Esc → close
5. **외부 click 닫기** — popup open → 바깥 click → close
6. **단일 file attach** — 1개 파일 첨부 → send → `**Attached files**` + `\`package.json\`` (basename + inline code)
7. **복수 file attach** — 2개 파일 → bullet list 2 row + 본문 끝 HTML comment 에 path 보존
8. **PO read 정합** — PO 가 첨부된 파일 read 요청 시 hidden comment 의 path 추출해서 정상 read
