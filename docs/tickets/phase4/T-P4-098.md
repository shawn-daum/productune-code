# T-P4-098: Team panel Skills section — SkillRow list 제거, 단일 매트릭스 row + count badge

> Team side panel 의 Skills section 에서 개별 SkillRow 리스트를 완전히 제거. Section 전체를 단일 clickable row 로 교체: "스킬 매트릭스 →" 라벨 + 총 N개 count badge. 클릭 시 main panel 에 `skill-matrix` 탭 열림. Personas / Wiki·Memory section 변경 없음.

## §1 Background

사용자 2026-05-12 directive:

> "Team side panel / Persona skills side panel에 리스트 표시 x. 스킬 항목만 있고 클릭시 main panel에 matrix 표시"

**현재 상태** (`TeamPanel.tsx`):

- Skills `<Section>` 내부에 `visibleSkills.map(<SkillRow>)` (최대 8행) + `hiddenCount more link` 렌더.
- Section 우측 헤더에 `matrixBtn` ("Matrix ↗") 별도 존재.
- Section 헤더 클릭 = collapse/expand.

**목표 상태**:

- (A) `visibleSkills.map` + `hiddenCount more link` 전체 삭제.
- (B) Section 헤더 클릭 → `openTab('skill-matrix', 'skill-matrix', {})` (collapse 대신).
- (C) Section body = 단일 clickable row: "스킬 매트릭스 →" 라벨 + count badge "총 N개".

L1 trivial — 기존 `handleMatrixClick()` 함수 재사용, 신규 로직 없음.

## §2 Scope

### A. SkillRow 관련 코드 삭제

`TeamPanel.tsx` 에서 다음을 **삭제**:

- `SkillRow` 컴포넌트 (133–163 line).
- `handleSkillClick` 함수 (223–225 line).
- `visibleSkills` / `hiddenCount` 변수 (242–243 line).
- `matrixBtn` JSX 변수 (246–253 line).
- Skills `<Section>` 내부 `{visibleSkills.map(...)}` + `{hiddenCount > 0 && ...}` (275–287 line).
- Style object `skillRowStyle`, `skillBullet`, `skillName`, `skillPersonaDots`, `personaDotSmall`, `moreLink`, `matrixLinkBtn` — **모두 삭제** (더 이상 참조 없음).

> `SKILL_CATALOG` + `SKILL_LIMIT` 상수 및 관련 interface `SkillEntry` 도 삭제 (SkillMatrixTab 자체 데이터를 갖고 있어 TeamPanel 에서 불필요).

### B. Skills section → 단일 clickable nav row

`<Section title={...} storageKey="skills" right={matrixBtn}>` 블록을 다음 패턴으로 교체:

```tsx
{/* ── Skills nav row ── */}
<div style={sectionWrap}>
  <button
    style={skillsNavBtn}
    onClick={handleMatrixClick}
    onMouseEnter={(e) => { (e.currentTarget as HTMLButtonElement).style.background = '#1A1A1A' }}
    onMouseLeave={(e) => { (e.currentTarget as HTMLButtonElement).style.background = 'transparent' }}
    title={t('workspace.team.section.skillsLink')}
  >
    <span style={secHdrText}>{t('workspace.team.section.skills')}</span>
    <span style={skillsNavLabel}>{t('workspace.team.section.skillsLink')}</span>
    <span style={skillsNavBadge}>
      {t('workspace.team.section.skillsCount', { count: SKILLS_TOTAL })}
    </span>
  </button>
</div>
```

`SKILLS_TOTAL` = 상수로 선언 (현재 `SKILL_CATALOG.length` = 11 이었으나 catalog 삭제 후 대신 SkillMatrixTab 이 SoT). SkillMatrixTab 이 자체 데이터를 관리하므로 **count badge = static 상수** 로도 족함 — developer 가 `SKILLS_TOTAL = 11` 또는 `SKILL_CATALOG` 상수를 minimal 형태 (id 배열만) 로 남겨 `length` 참조하는 방식 중 선택. 구현 단순성 우선.

**신규 style objects**:

```ts
const skillsNavBtn: React.CSSProperties = {
  display: 'flex',
  alignItems: 'center',
  width: '100%',
  padding: '5px 8px 3px',
  background: 'transparent',
  border: 'none',
  cursor: 'pointer',
  gap: 4,
  textAlign: 'left',
  transition: 'background 0.1s',
}

const skillsNavLabel: React.CSSProperties = {
  fontSize: 10,
  fontFamily: 'monospace',
  color: '#60A5FA',
  flexShrink: 0,
}

const skillsNavBadge: React.CSSProperties = {
  fontSize: 9,
  fontFamily: 'monospace',
  color: '#505050',
  marginLeft: 4,
  flexShrink: 0,
}
```

`secHdrText` 는 기존 Personas / Wiki 섹션과 공유 — 그대로 재사용.

### C. i18n keys (2개 신규)

`packages/gui/src/locales/en.json` + `ko.json` 의 `workspace.team.section` 객체에 추가:

| key | en | ko |
|---|---|---|
| `workspace.team.section.skillsLink` | `"Skill Matrix →"` | `"스킬 매트릭스 →"` |
| `workspace.team.section.skillsCount` | `"{{count}} skills"` | `"총 {{count}}개"` |

기존 키 `skillsMatrix` / `skillsMore` 는 참조 코드 삭제와 함께 **dead key** 로 남음 — T-P4-057 locale linter 는 value 가 보호어 위반일 때만 fail, dead key 는 무해. 별도 cleanup 은 out of scope.

## §6 Design system §1.5 self-check

| Sub-rule | 검증 | 결과 |
|---|---|---|
| 2-1 Few Things | 1 row = 라벨 + badge = 2 토큰. 단일 action. | ✓ |
| 2-2 Familiar | WikiRow 패턴과 동일 (아이콘 대신 라벨). 사이드바 nav row 관용 패턴. | ✓ |
| 3-1 Predictability | 클릭 = 항상 skill-matrix 탭 open. 모호성 없음. | ✓ |

| 3-3 Escape | tab X = 닫기. row click 비파괴. | ✓ |

- ❌ 클릭 후 무반응 → 없음 (`handleMatrixClick` 기존 검증됨).
- ❌ 리스트 노출로 matrix 탭 중복 역할 → 제거로 해결.
