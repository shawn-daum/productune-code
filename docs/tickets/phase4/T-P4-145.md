### A1. Bug 1b — 지정 없음 confirm

### A2. Bug 2 — ActiveVersionCard visual

- `ChevronRight` (lucide, 12px) 가 version id 오른쪽에 표시됨.
- 카드 hover 시 border color `#FF6B2B33` → `#FF6B2B` 변화 (`onMouseEnter/Leave`).
- `cardActive.padding` = `'12px 14px'` (기존 `'10px 12px'`).
- 클릭 → `version-detail` tab 열림 (기존 동작 유지).

### A3. Bug 5 — Persona row routing

**TeamPanel.tsx**:
```tsx
// handlePersonaClick:
openTab(`persona-def:${def.key}`, 'persona-def', { personaKey: def.key }, t(def.nameKey))
```
- 4 persona 행 클릭 → tab type `persona-def`, tabId `persona-def:po` / `persona-def:designer` / `persona-def:dev` / `persona-def:qa`.
- Tab label = persona name (i18n).

**PersonaDefTab.tsx**:
- `KEY_TO_ID` 맵 추가 (`'po' → 'pdt-po'` 등).
- `personaId = props?.persona || KEY_TO_ID[props?.personaKey]` fallback chain.
- **LONG-TERM MEMORY 섹션**: persona 별 파일 row 표시 → 클릭 → `markdown` tab.
  - po: `~/.productune/po-memory.md`
  - designer: `docs/designer/decisions.md`
  - dev: `docs/designer/feature-history.md`
  - qa: `docs/qa/fail-patterns.md`
- **PROJECT MEMORY 섹션**: `useWorkspace(poState)` 에서 파생 — current version, active task (assignee match), promo pending count, last seen.
- `previewNote` `<div>` 제거.

### A4. Bug 6 — Wiki sub-row distinct tabs

```tsx
openTab('team-wiki:fs',          'team-wiki', { backend: 'fs' },          t('…wikiMenu.fs'))
openTab('team-wiki:userMemory',   'team-wiki', { backend: 'userMemory' },  t('…wikiMenu.userMemory'))
openTab('team-wiki:projectState', 'team-wiki', { backend: 'projectState' },t('…wikiMenu.projectState'))
openTab('team-wiki:promo',        'team-wiki', { backend: 'promo' },       t('…wikiMenu.promo'))
```
4 sub-row 클릭 시 tab bar 에 라벨 다른 4개 independent tab 생성.
`TeamWikiTab.tsx` 변경 없음.
