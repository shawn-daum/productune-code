# T-P4-045: Explorer 탭 — 파일 트리 + 검색 (regex/case/word) + ⌘⇧E 토글

**Round**: phase4-r4  **Stage**: impl  **Status**: todo  **Assignee**: pdt-developer
**Design**: [docs/design/service-flow-and-screens.md §4.1 Explorer 탭](../../design/service-flow-and-screens.md)
**Bundle**: 본 티켓은 `T-P4-R4-workspace-shell` 번들의 일부로 함께 출고.

> Activity Bar 의 Explorer 아이콘 (lucide `FolderTree`) 클릭 시 Side panel 에 파일 트리 + 검색 박스 뷰 노출. 단축키 `⌘⇧E` 로 토글 (collapse/expand). 검색 모드 진입 시 결과 행 노출.

## Acceptance

### 헤더
- [ ] `sp-hdr` 라벨 = "Explorer" (사용자 화면 한글 tooltip "탐색") + `+` 버튼 (`newProject()` 호출)
- [ ] Activity Bar 아이콘 = lucide `FolderTree` (20px, stroke 1.75, active 시 좌측 2px PO-orange bar)

### 검색 박스 (`ex-search-wrap`)
- [ ] 검색 input + clear `×` 버튼
- [ ] 옵션 토글 3종: 정규식 (`.*`) / 대소문자 (`Aa`) / 전체 단어 (`W`) — active 시 background 강조
- [ ] 입력 시 파일 트리 → 검색 결과 모드 전환

### 파일 트리 (`sp-body#explorer-body`)
- [ ] `ft-item` 행 = 아이콘 + 라벨, 재귀 디렉터리 indent
- [ ] hover bg `#1a1a1a`, active bg `#1f3a5f`
- [ ] 파일 클릭 → `openTab(tabId, 'markdown', { path })` (markdown 탭)

### 검색 결과 모드
- [ ] `sr-file` 헤더 (파일명) + `sr-line` 하위 행 (줄번호 + match highlight `#daa520`)
- [ ] 결과 행 클릭 → 해당 파일 + 해당 줄 포커스로 markdown 탭 open

### 단축키
- [ ] `⌘⇧E` → Explorer 탭 토글 (collapse/expand). Electron `globalShortcut` 등록
- [ ] `⌘⇧F` → 검색 input focus (VS Code 호환, 추론)

## Out of scope

- 파일 생성 / 삭제 / 이름 변경 (이 슬라이스 X)
- git blame / diff 표시
- symlink / hidden 파일 처리 (기본 숨김)

## Notes

파일 트리 backend: Electron main process 의 fs.readdir 재귀 (IPC `explorer:listDir`). 검색 backend: ripgrep 또는 Node.js 순수 구현 — Round 4 plan 단계 결정. 첫 오픈 시 `.productune/` 루트로 기본 확장. Slice 순서: T-P4-046 (Main split-pane) 이전 또는 병렬 구현 가능.
