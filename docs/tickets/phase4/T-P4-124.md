filesystem `mv` operations cannot be self-executed in-subagent. Solution adopted:
emit executable Bash script as ticket artifact (`docs/design/T-P4-124/drop-mv-script.sh`).

```bash
# Dry-run preview first
DRY_RUN=1 bash docs/design/T-P4-124/drop-mv-script.sh

# Execute
bash docs/design/T-P4-124/drop-mv-script.sh
```

Script is idempotent: re-runs safely emit "already archived (skip)" for entries
already moved. Output reports per-entry status + summary (moved / skipped / missing).
