## Request

> "스킬, 위키에 저 셰브론 없애는거해주고, 위키 메인 패널에 이모지 쓰고있는데 우리 디자인시스템에 이모지 안쓰게되어있잖아. 이거 리액트 아이콘으로 수정해주고." — user (2026-05-19)

**관찰된 증거:**

1. Team 사이드 패널의 스킬 nav row + Wiki·Memory nav row 양쪽에 `<ChevronRight>` 아이콘이 표시됨. 두 row 모두 클릭 시 탭을 여는 단순 네비게이션 버튼 (collapsible 아님) — chevron 은 의미 없는 장식으로 제거 요청.
2. Wiki nav row label 이 `workspace.team.tab.wiki` i18n 키를 참조하는데, ko.json / en.json 양쪽에 해당 키가 없어 literal key 문자열이 화면에 노출됨.
3. Wiki 메인 탭(`TeamWikiTab`) 4개 row 에 emoji 사용 중:
   - Row 1 (wiki backend): `\u{1F5C4}` (🗄 fs) / `\u{1F9E0}` (🧠 graphiti) / `\u{1F4DA}` (📚 keeper)
   - Row 2 (user memory): `\u{1F9E0}` (🧠)
   - Row 3 (project state): `⚙️`
   - Row 4 (promotion candidates): `\u{1F4CC}` (📌)
4. `\u{1F9E0}` / `\u{1F4CC}` 가 화면에 literal escape 텍스트로 노출 (emoji render 실패).

**Doctrine**: `feedback_icon_set.md` — "컬러 emoji 금지. lucide-react default."

## Acceptance

### A1 — Chevron 제거 (TeamPanel.tsx)

- [ ] Skills nav row (`handleMatrixClick` 버튼) 에서 `<ChevronRight>` 제거.
- [ ] Wiki·Memory nav row (`handleWikiClick` 버튼) 에서 `<ChevronRight>` 제거.
- [ ] `import { ChevronRight } from 'lucide-react'` import 삭제 (다른 lucide 사용 없음).
- [ ] 클릭 동작 (openTab) 은 변경 없음.

### A2 — i18n key 추가

ko.json `workspace.team` 객체 안에:
```json
"tab": {
  "wiki": "위키"
}
```

en.json `workspace.team` 객체 안에:
```json
"tab": {
  "wiki": "Wiki"
}
```

- [ ] Wiki nav row 라벨이 ko 모드 = "위키", en 모드 = "Wiki" 로 표시됨.
- [ ] literal key string 화면 노출 없음.

### A3 — Wiki tab emoji → lucide-react (TeamWikiTab.tsx)

`WikiRowProps.icon` 타입을 `string` → `React.ReactElement` 로 변경.

아이콘 매핑 (plan §3 확정 표):

| Row | 기존 emoji | 교체 lucide 아이콘 |
|:----|:-----------|:------------------|
| Wiki backend: fs | `\u{1F5C4}` 🗄 | `<FileText size={14} />` |
| Wiki backend: graphiti | `\u{1F9E0}` 🧠 | `<BrainCircuit size={14} />` |
| Wiki backend: keeper | `\u{1F4DA}` 📚 | `<BookOpen size={14} />` |
| User memory | `\u{1F9E0}` 🧠 | `<Brain size={14} />` |
| Project state | `⚙️` | `<Settings2 size={14} />` |
| Promotion candidates | `\u{1F4CC}` 📌 | `<Pin size={14} />` |

`wikiIcon` span 스타일: `fontSize: 14` → `display: 'flex', alignItems: 'center'` (SVG 기반이므로 fontSize 무의미). 아이콘 color: `#808080` (lucide `color` prop — `--txt2` 근사).

- [ ] 4개 row 전체 emoji 없음, lucide 아이콘으로 렌더.
- [ ] `\u{1F9E0}` / `\u{1F4CC}` literal escape 텍스트 화면 노출 없음.
- [ ] 아이콘 크기 14px, 색상 `#808080`.

### A4 — Import 추가

- [ ] TeamWikiTab.tsx에 lucide import 추가:
  ```tsx
  import { FileText, BrainCircuit, BookOpen, Brain, Settings2, Pin } from 'lucide-react'
  ```
- [ ] build 에러 없음 (tsc + vite).
