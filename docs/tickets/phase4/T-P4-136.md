## §1 Request

**User directive verbatim (2026-05-19):**
> "planned문제는 왜생긴거야? 재발방지가능해?" → "B만."

**Root cause**: `status: planned` written into T-P4-131~135 by LLM training prior bias + cascade self-mimic. No hook blocked it at write time.

**Fix**: `PreToolUse` hook that validates `status:` + `qa_status:` frontmatter values whenever a `docs/tickets/*/T-*.md` file is written or edited. Exit 2 (block) on canonical enum violation.

**Canonical enums**:
- `status:` → `todo | in-progress | review | user-verify | done | blocked | abandoned`
- `qa_status:` → `pending | pass | fail`

Full spec: `docs/design/T-P4-136/plan.md`.

## §2 Acceptance

### A1. Hook script authored
`packages/core/scripts/hooks/pre-frontmatter-lint.sh` — new file, executable.

Behaviour:
- PreToolUse trigger on Write or Edit.
- Path filter: only `docs/tickets/*/T-*.md`. All other paths `exit 0`.
- Write: parse `tool_input.content` frontmatter → validate `status:` and (if present) `qa_status:`.
- Edit: parse `tool_input.new_string` → validate `status:` / `qa_status:` if touched.
- Violation: `stderr` message + `exit 2` (blocks tool call).
- Pass: `exit 0`.
- Idempotent: no side effects, no file writes.

### A2. settings.json registered
`~/.claude/settings.json` `PreToolUse` array gains a third entry:
```json
{ "matcher": "Write|Edit",
  "hooks": [{ "type": "command",
               "command": "<abs-path>/pre-frontmatter-lint.sh" }] }
```
Both home and (if applicable) project-level settings updated.

### A3. delegation.md cross-ref
`~/.productune/sections/delegation.md` lifecycle metadata bullet — 1 line appended:
> `status:` enum enforced by `pre-frontmatter-lint.sh` PreToolUse hook (T-P4-136).
