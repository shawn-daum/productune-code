## §1 Request

**User directive verbatim (2026-05-19):**
> "버젼 히스토리에 ABANDONED만 하단에 배치되어 다른 티켓들의 세로 길이를 줄이고 있어 이거 개선해줘. 최우측 컬럼에 넣어줘. 티켓 상태들도 i18n 필요함 (todo 등) blocked는 todo 왼쪽에 배치해줘."

**Root cause**: `gridTemplateColumns: repeat(6, minmax(180px, 1fr))` with 7 statuses → `abandoned` wraps to a second row, compressing all row-1 column heights.

**Changes (4 files):**
1. `TicketDashboardView.tsx` — STATUS_ORDER reorder + 6→7 column grid + Column label i18n
2. `ko.json` + `en.json` — add `workspace.tickets.status` block (7 keys each)
3. `VersionHistoryView.tsx` — unify to same i18n key (removes hardcoded Korean map, fixes missing `user-verify`)

## §2 Acceptance

### A1. STATUS_ORDER reorder
```ts
// Before:
['todo', 'in-progress', 'review', 'user-verify', 'done', 'blocked', 'abandoned']
// After:
['blocked', 'todo', 'in-progress', 'review', 'user-verify', 'done', 'abandoned']
```
`blocked` = col 1 (leftmost), `abandoned` = col 7 (rightmost).

### A2. Grid 7 columns on one row
```ts
// Before:
gridTemplateColumns: 'repeat(6, minmax(180px, 1fr))'
// After:
gridTemplateColumns: 'repeat(7, minmax(160px, 1fr))'
```
All 7 statuses render in a single row. Narrow viewports scroll horizontally (`overflowX: auto` already present).

### A3. Column labels localised
`Column` component adds `const { t } = useTranslation()`.
`<span style={columnLabel}>{status}</span>` → `{t('workspace.tickets.status.' + status, { defaultValue: status })}`.

### A4. i18n keys added (both locales)
`workspace.tickets.status` sub-object in `ko.json` + `en.json`:

| key | ko | en |
|:--|:--|:--|
| `todo` | 대기 | To Do |
| `in-progress` | 진행 중 | In Progress |
| `review` | 검토 중 | Review |
| `user-verify` | 검증 대기 | Awaiting Verify |
| `done` | 완료 | Done |
| `blocked` | 차단 | Blocked |
| `abandoned` | 취소 | Abandoned |

### A5. VersionHistoryView statusLabel unified
- `statusLabel(status)` call site (L207) replaced with `t('workspace.tickets.status.' + status, { defaultValue: status })`.
- `statusLabel` function (L647–657) removed — now unused.
- `statusPill` function unchanged (color palette independent).
- `user-verify` now correctly renders "검증 대기" / "Awaiting Verify" (was missing from hardcoded map → showed raw string).

### A6. KNOWN_STATUS_SET unaffected
`KNOWN_STATUS_SET` is derived from `STATUS_ORDER` (set, not ordered) — reorder has no effect on ticket grouping logic.
