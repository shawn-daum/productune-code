# T-P4-047: Project 탭 — Stage strip + Rounds + sub-items + Preview + Recent Activity

**Round**: phase4-r4  **Stage**: impl  **Status**: todo  **Assignee**: pdt-developer
**Design**: [docs/design/service-flow-and-screens.md §4.1 Project 탭](../../design/service-flow-and-screens.md)
**Bundle**: 본 티켓은 `T-P4-R4-workspace-shell` 번들의 일부로 함께 출고.

> Activity Bar 의 Project 아이콘 (lucide `LayoutDashboard`) 클릭 시 Side panel 에 Project 탭 전체 노출. Stage strip + Rounds + Preview + Recent Activity 4 섹션. T-P4-040 (Stage strip) / T-P4-043 (Tickets sub-items) 의 상위 컨테이너 역할.

## Acceptance

### 헤더
- [ ] `sp-hdr` "Project" + 우측 프로젝트 slug 작은 텍스트
- [ ] Activity Bar 아이콘 = lucide `LayoutDashboard` (20px, stroke 1.75)

### Stage strip 섹션
- [ ] `pp-sec-hdr` "단계" (한글) + `stage-strip` 컴포넌트 (T-P4-040 구현체 사용)
- [ ] 6 `sdot-item` — done/cur/pending 상태, stage 색 변수
- [ ] 240px 폭에서 4개 노출 + 수평 scroll

### Rounds 섹션
- [ ] `pp-sec-hdr` "라운드 (Rounds)" + 펼치기/닫기
- [ ] round-N `pp-row` + 상태 badge (done success `#193d24` / active warn `#3a2200`)
- [ ] 펼치기 시 sub-items (indent 34px):
  - 📄 **PRD** + status badge → `openTab(tabId, 'markdown', { path: 'docs/prd/...' })`
  - 🎨 **Design Gate** + status badge (review warn / approved success / pending) → `openTab(tabId, 'design-gate', { round })`
  - 📋 **Tickets (N)** + 펼치기 → 각 ticket `pp-row` (indent 46px) + status sbadge → `openTab(tabId, 'ticket-review', { ticketId })`
  - ✓ **QA Verdict** + status badge → `openTab(tabId, 'qa-result', { round })`

### Preview 섹션
- [ ] `pp-sec-hdr` "미리보기"
- [ ] 🌐 Local (:3000) → `openTab(tabId, 'preview', { env: 'local', url: 'http://localhost:3000' })`
- [ ] ☁ Vercel preview → `openTab(tabId, 'preview', { env: 'vercel', url: vercelUrl })`
- [ ] 각 항목 우측 상태 dot (running = green / stopped = gray / error = red)

### Recent Activity 섹션
- [ ] `pp-sec-hdr` "최근 활동"
- [ ] mono-font 1행 — 페르소나 chip (Dev/Des/PO/QA 색) + ticket-id + model/effort + turn N
- [ ] 최근 5–10개 노출, display only (클릭 비활성)
- [ ] 데이터: `po-state.json` `persona_session_meta` turn 기록

## Data source

- `po-state.json` `current_task.stage`, `rounds`, `past_tickets`
- `docs/tickets/phase4/` 파일 시스템 scan (round + status)
- vercel API or `.productune/vercel-state.json` (preview URL)

- ticket 직접 편집 (ticket-review 탭에서 승인/반려만)
