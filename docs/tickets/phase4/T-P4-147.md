# T-P4-147 — autosaveTriggers UI 활성화

## §1 Request

Phase 5 deferral 2/3 unlock (v0.4).
`WorkflowRulesPanel.tsx` L133-137 의 `autosaveTriggers` row 가
`phase5Lock` chip + `lockedRow` (opacity 0.45) 로 비활성화 상태.

이 row 를 편집 가능한 트리거 chip 목록으로 교체.
저장소: `~/.productune/settings.json` → `workflow.autosaveTriggers: string[]`.

## §2 Acceptance

### A1. UI — lockedRow 제거

`WorkflowRulesPanel.tsx` L133-137 (`lockedRow` / `phase5Chip`):
- 해당 `<div style={lockedRow}>` 블록 제거.
- 대신 `fieldRow` 레이아웃: trigger chip 목록 + Add input.
- chip style `triggerChip`: green `#6EE7A0` / `#1A2A1A`, ×버튼 포함.
- Add input + "추가" 버튼: Enter 또는 클릭으로 추가.
- 빈 문자열 / 중복 → 무시 (chip 불변).
- `lockedRow` + `phase5Chip` style 상수 삭제 (미사용 TS 경고 방지).

### A2. 기본 트리거 (첫 실행)

`settings.json` 에 `workflow.autosaveTriggers` 없을 때 default 3개:

```
ticket-close | phase-transition | user-idle-5min
```

### A3. 저장 동작

- 삭제 / 추가 시 즉시 `api.saveAutosaveTriggers(next)` 호출.
- 기존 `saveStatus` state (success banner 1.5s / error banner + retry) 재사용.
- 앱 재시작 후 마지막 저장 목록 복원.

### A4. Core — `packages/core/src/settings/ui-settings.ts`

추가할 코드 (plan.md §A1 참고):

```ts
const DEFAULT_AUTOSAVE_TRIGGERS: string[] = [
  'ticket-close', 'phase-transition', 'user-idle-5min',
]

function readRawSettings(): Record<string, any> {
  try { return JSON.parse(fs.readFileSync(SETTINGS_PATH, 'utf-8')) }
  catch { return {} }
}

export function getAutosaveTriggers(): string[]
export function setAutosaveTriggers(triggers: string[]): void
```

`setAutosaveTriggers`: raw read → `raw.workflow.autosaveTriggers = triggers` →
tmp+rename atomic write. 기존 `ui.language` / `integrations.vercel` 필드 보존.

### A5. `packages/core/src/index.ts`

`getAutosaveTriggers, setAutosaveTriggers` export 추가.

### A6. IPC — `packages/gui/electron/main.ts`

`// ── Settings IPC` 블록 하단에 추가:

```ts
ipcMain.handle('settings:getAutosaveTriggers', (): string[] =>
  getAutosaveTriggers()
)

ipcMain.handle(
  'settings:saveAutosaveTriggers',
  (_event, triggers: string[]): { ok: boolean; error?: string } => {
    try {
      setAutosaveTriggers(triggers)
      return { ok: true }
    } catch (e: any) {
      return { ok: false, error: e?.message ?? 'unknown error' }
    }
  },
)
```

상단 import 에 `getAutosaveTriggers, setAutosaveTriggers` 추가.

### A7. Preload — `packages/gui/electron/preload.ts`

settings block 끝 (기존 `saveRules` 이후) 에 추가:

```ts
getAutosaveTriggers: (): Promise<string[]> =>
  ipcRenderer.invoke('settings:getAutosaveTriggers'),

saveAutosaveTriggers: (triggers: string[]): Promise<{ ok: boolean; error?: string }> =>
  ipcRenderer.invoke('settings:saveAutosaveTriggers', triggers),
```

### A8. i18n — `ko.json` + `en.json`

`settings.workflowRules` 에 6개 key 추가:

| key | ko | en |
|:--|:--|:--|
| `autosaveTriggerAddPlaceholder` | `트리거 추가…` | `Add trigger…` |
| `autosaveTriggerAdd` | `추가` | `Add` |
| `autosaveTriggerRemove` | `제거` | `Remove` |
| `autosaveTriggerLabel_ticket-close` | `티켓 완료 시` | `On ticket close` |
| `autosaveTriggerLabel_phase-transition` | `Phase 전환 시` | `On phase transition` |
| `autosaveTriggerLabel_user-idle-5min` | `5분 대기 후` | `After 5 min idle` |

> `phase5Lock` 키는 i18n 에서 **삭제하지 않음** (dead key cleanup = 별도).
