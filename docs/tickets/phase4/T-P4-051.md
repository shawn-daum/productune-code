# T-P4-051: Mermaid.js 렌더링 컴포넌트 — Design stage inline diagram viewer

**Round**: phase4-r5  **Stage**: impl  **Status**: done  **Assignee**: pdt-developer
**PRD anchor**: [docs/prd/productune.md#phase-4--개발-비숙련-기획자-모드-planner-mode-future](../../prd/productune.md#phase-4--개발-비숙련-기획자-모드-planner-mode-future)
**Estimated complexity**: L4  **Risk flags**: rendering, dependency

> Design stage 에서 Claude design skill 이 생성한 Mermaid code fence 를 Productune GUI 안에서 바로 볼 수 있게 한다. 정상 viewing 은 Electron/React renderer 에 번들된 Mermaid.js 또는 React Mermaid component 로 처리하며, 외부 CLI 에 의존하지 않는다.

---

## Request

1. markdown artifact 안의 Mermaid code block 을 감지해 Design stage viewer 에 inline 렌더링한다.
2. UX flow / 사용자 여정 / 화면 전환 / 상태도 / sequence diagram 을 지원한다.
3. viewer 에 zoom/pan, source toggle, source copy 를 제공한다.
4. 렌더 실패 시 diagram 영역에 오류 메시지 + 원문 Mermaid source 를 보여주고, 나머지 문서 검토는 계속 가능해야 한다.
5. GitHub / VS Code Markdown preview 는 현재 수동 확인 경로로 문서화하되, Phase 4 GUI 정상 viewing 은 앱 내부 렌더링을 기준으로 한다.
6. `@mermaid-js/mermaid-cli` 는 SVG/PNG export 또는 자동 이미지 생성이 필요할 때만 선택적으로 사용한다. 설치가 필요하면 외부 도구/라이브러리 동의 흐름을 따른다.
