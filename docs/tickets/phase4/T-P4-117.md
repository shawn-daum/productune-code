## §1 Background

**T-P4-100 codex context.**
Codex 가 `.productune/worktrees/T-P4-100/` worktree 에서 두 가지를 구현했다:
1. `ColumnResizeHandle.tsx` — 4px 드래그 핸들 component. **이미 main 에 absorbed** (`packages/gui/src/components/workspace/ColumnResizeHandle.tsx`).
2. `WorkspaceShell.tsx` — `sidebarWidth` / `poChatWidth` width state, drag handlers, localStorage persist, ColumnResizeHandle 사용처 전부 포함. 이쪽은 **아직 main 에 없다**.

**왜 단순 merge 가 안 되는가.**
Codex 가 작업하던 시점의 base(T-P4-100 분기 당시)와 지금 main HEAD 사이에 다음 티켓 변경이 누적됐다:
- T-P4-022 3rd PR: `DeployConfirmModal` + IPC subscription
- T-P4-092: `BaseDirtyModal` + worktree IPC subscription
- T-P4-099: 자동 버전 탭 열기 로직 변경 (`current_version` 기반)
- T-P4-105: `useTranslation` / i18n 훅 추가, `appendMessage` 연결
- T-P4-114: artifact auto-open IPC + overflow toast (§A), ticket focus IPC (§B)
- T-P4-112: artifact toast style

결과로 worktree `WorkspaceShell.tsx`(658 lines) ↔ main HEAD(637 lines)는 구조적으로 많이 벌어져 있다. **직접 merge 시 conflict 다수 + 기능 퇴행 위험**.

본 티켓 = resize 관련 코드만 선별 이식(transplant). ColumnResizeHandle 은 이미 있으므로 `WorkspaceShell.tsx` 한 파일만 편집.
