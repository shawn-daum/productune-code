# T-P4-046: Main split-pane + tab dispatcher (10 type) + drag-drop

**Round**: phase4-r4  **Stage**: impl  **Status**: todo  **Assignee**: pdt-developer
**Design**: [docs/design/service-flow-and-screens.md §4.2 Main panel](../../design/service-flow-and-screens.md)
**Bundle**: 본 티켓은 `T-P4-R4-workspace-shell` 번들의 일부로 함께 출고.

> Workspace shell 의 Main panel — `hbox`/`vbox` 재귀 split tree. 각 leaf pane = tab bar + 컨텐츠. `openTab(tabId, type, props)` API 가 active pane 에 탭 추가. tab type 10 종 dispatcher 라우팅. tab drag-drop 으로 pane 간 이동 / 새 pane split 트리거.

## Acceptance

### Pane tree 구조
- [ ] pane tree 상태: `{ type: 'hbox'|'vbox'|'leaf', children?, paneId?, tabs?, activeTab? }`
- [ ] `splitRight(paneId)` → `hbox` split (기존 pane + 새 빈 pane)
- [ ] `splitDown(paneId)` → `vbox` split
- [ ] `closePane(paneId)` → tab merge into adjacent pane + tree 재구성; 마지막 pane 은 init pane reset
- [ ] `setActivePane(paneId)` → active border + `active-pane` class
- [ ] pane resize handle 4px (drag to resize col/row)
- [ ] 최소 pane 크기: 150×100px

### Tab 관리
- [ ] `openTab(tabId, type, props)` → active pane 에 탭 추가; 이미 존재 시 activate
- [ ] tab bar: 탭 이름 + 닫기 `×` 버튼; 탭 재정렬 (같은 pane 내 drag)
- [ ] tab drag cross-pane: `drop-before` / `drop-after` / `bar-end-drop` / `pane-drop-zone` glow 시각 피드백
- [ ] `⌘W` → 현재 탭 close; `⌘\` → 현재 pane split right; `⌘K ⌘\` → split down

### Tab type dispatcher — 10 종
- [ ] `markdown` — md-toolbar (crumb + edit/preview 토글) + md-view (h1/h2/code/table 렌더) + md-edit (mono editor)
- [ ] `design-gate` — dg-tabs (System / Flow / Wireframe / Mockup) + dg-body + dg-footer (승인/수정/다시 작업/나중에)
- [ ] `ticket-review` — tr-body (frontmatter + body + Persona Activity 표) + tr-actions footer
- [ ] `preview` — prev-chrome (URL bar + Local/Vercel toggle) + prev-body (iframe placeholder)
- [ ] `qa-result` — qa-body + qa-verdict (pass/fail) + qa-suite (테스트 케이스 펼침)
- [ ] `persona-def` — pd-header (avatar/name/role/model) + edit-toggle + pd-content (md edit/preview)
- [ ] `env-view` — layer 선택 + env-table (key/value/mask)
- [ ] `skill-matrix` — sm-toolbar + sm-table (skill × persona 체크박스 그리드) + sm-add
- [ ] `terminal` — term-content (mono, blink cursor) — node-pty 연결
- [ ] `browser` — browser-chrome (URL bar) + browser-body (webview/iframe)

### Empty pane (`empty-state`)
- [ ] 가운데 logo (28px, opacity 0.25)
- [ ] `esc-title` "파일을 열거나 명령을 실행하세요"
- [ ] 단축키 hint: `⌘P` Quick Open / `⌘\` Split Right / `⌘W` Close Tab
