# T-P4-069: Design system §1.5 UX principles audit — 기존 컴포넌트 정합 검증

## Background

`docs/design/design-system.md` §1.5 UX principles (대원칙 2 + 3, 5 sub-rules: Few Things / Familiar / Predictability / Feedback / Escape) 가 doctrine 으로 land 됐지만 (commit 직전), **이미 land 된 GUI 컴포넌트들이 정합인지 미검증**. design-system §11 Migration plan 의 6단계 audit 자리.

직전 사용자 dogfood 발견: ChatPanel restart button 클릭 후 visual feedback 없음 → §1.5.4 Feedback 위반. 이런 anti-pattern 들 cross-component 가 더 있을 가능성.

## Doctrine reference

- `docs/design/design-system.md` §1.5 UX principles (5 sub-rules + 체크리스트)
- §8 Components recipe (Button / Banner / Modal / PresenceBar / StageStrip / PhaseGate / Empty pane)

## Acceptance

### A) Audit scope (designer)
- [ ] 모든 GUI 컴포넌트 (`packages/gui/src/components/**/*.tsx`) 가 §1.5 5 sub-rules 정합인지 1회 검토
- [ ] component × sub-rule matrix 작성 (`docs/design/T-P4-069-audit-matrix.md` 또는 design plan 안)
  - row = 컴포넌트 (ChatPanel / Modal / FAB / Banner / Empty pane / PendingPromotionDrain / VersionDetailView / TicketDashboardView / WorkflowRulesPanel / OnboardingWizard / 기타)
  - col = 5 sub-rules
  - cell = ✅ pass / ⚠ minor / ❌ violation + 1줄 사유

### B) Violation 우선순위
- [ ] Critical (사용자 가시 직접 영향) — 즉시 fix ticket 발행
- [ ] Minor (보강 가치) — Phase 5 또는 별 R4 patch
- [ ] OK — 변경 X

### C) 알려진 violation (직전 발견)
- [ ] **ChatPanel restart button**: 클릭 후 modal 떠도 "Restart now" 클릭 후 actual feedback 없음 (chat history 보존되지만 visual 변화 X). §1.5.4 Feedback 위반 — Critical
  - fix 후보: toast `[PO] 세션이 재시작됐어요` / inline indicator / claude session id reset 시 trace 메시지 inline

### D) Audit 산출물
- [ ] `docs/design/T-P4-069-audit.md` — matrix + 우선순위 분류 + critical violation list (각 fix ticket 후보 명시)

### E) 후속 ticket 발행 trigger
- [ ] critical violation 별 fix ticket — designer 가 audit 완료 시 발행
- [ ] minor violation 통합 ticket (Phase 5)
