## Sub-areas

### A. i18n catalog mode suffix (S)

- `en.json` + `ko.json` 의 mode 차이 key 들에 `.dev` / `.planner` suffix 추가.
- base key (suffix X) = planner-friendly default.
- 대상 key — design plan §7.1 + §7.2 (총 11 항목 + Settings 섹션 제목 6 항목).
- 신규 key 추가 시: base key (planner) → 필요 시 `.dev` override.

### B. i18next mode-aware resolver (M)

- `packages/gui/src/i18n/useUserModeT.ts` 신규 — `useT()` hook (또는 wrapper).
- 동작: 호출 시 `useUserMode()` store 읽어 mode 추출 → `${key}.${mode}` 가 있으면 사용, 없으면 `${key}` fallback.
- mode = null (미설정) → base key (planner-friendly) 사용.
- 기존 `i18n.t(...)` 호출은 점진 마이그레이션 — 본 ticket 에서는 design plan §7 surface area 만 마이그레이션.

### C. UserModeProvider + store + IPC (M)

- `packages/gui/src/store/useUserMode.ts` 신규 — zustand slice (`mode: 'developer' | 'planner' | null`, `setMode(m)`).
- Electron IPC: `settings:getUserMode` (read `~/.productune/settings.json`), `settings:setUserMode(mode)` (atomic write + broadcast).
- preload export.
- 앱 시작 시 1회 hydrate. Settings/Wizard 에서 setMode → store update + IPC write + 전 renderer reactive.

### D. Onboarding Step 0.5 (M)

- `packages/gui/src/components/onboarding/Step0_5UserMode.tsx` 신규.
- 2 카드 (`developer` / `planner`) + 카드 선택 outline accent + "건너뛰기" + "선택" CTA.
- lucide icon: `Code2` (developer) / `UserCog` (planner).
- 선택 → `setMode(...)` → wizard next step.
- "건너뛰기" → `setMode(null)` 유지 → next step + StatusBar reminder banner queue.
- Wizard 진행 순서: Step 0 (언어) → Step 0.5 (mode) → Step 1+ (기존).
- design-system §8 selectable card 패턴 준수.

### E. Settings General sub-tab (M)

- `SettingsView.tsx` 의 sub-tab list 에 **General** 추가 (Environment / Models / MCP / Hooks 앞).
- 기존 Language sub-tab → General 안 흡수 (sub-tab list 에서 제거).
- General sub-tab 컴포넌트 신규 — UI 언어 radio (en/ko) + 사용자 mode radio (developer/planner/미설정) + 설명문.
- 변경 즉시 반영 (앱 재시작 X) — store dispatch → IPC write → 전 renderer reactive.
- T-P4-048 의 sub-tab list 갱신 비고 (ROADMAP) 동기.

### F. Wizard skip + reminder banner (S)

- 사용자 mode = null 상태에서 앱 진입 시 StatusBar 또는 top banner 1회 reminder.
- "사용자 mode 가 설정되지 않았습니다. Settings → General 에서 선택해 주세요." (planner-friendly default copy).
- dismiss 후 재진입 X (session 단위).

### G. QA — manual mode switch 검증 (S)

- 신규 사용자 wizard → Step 0 → Step 0.5 (developer 선택) → Step 1+ 동작 확인.
- 같은 wizard 다시 → Step 0.5 (planner 선택) → 자연어 tone 적용 확인.
- Settings General 에서 mode 토글 → §7.1 surface area 5 항목 + §7.2 6 항목 즉시 반영 확인.
- T-P4-057 linter pass — 보호어 (PO/Designer/Dev/QA/Phase/stage 등) 가 두 mode 모두 영문 보존.
- 외부 어휘 (git/branch/worktree) 가 두 mode 모두 노출 X 확인.
