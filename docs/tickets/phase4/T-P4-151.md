# T-P4-151 — po-state.json hygiene doctrine

## §1 Request

Define and enforce three turn-start hygiene rules (H1/H2/H3) for `po-state.json` to prevent
unbounded bloat. Productune is currently at 9.4 KB with 2318 chars of stale `past_tickets[]`
(T-P4-065 abolished this field but no purge mechanism exists) and 1526 chars of uncapped
`recent_turns[]` (schema says "rolling 10", actual use window is last 5). A 13-day-old stale
`pending_gate` has no staleness policy.

Fix: doctrine + mechanical rules, not one-time scrub. Rules live in `po-loop.md` Step 1.1 and
are referenced in `po-state-schema.md` per-field bullets and a new `## Size budget` table.

---

## §2 Acceptance

Full text inserts specified in `docs/design/T-P4-151/plan.md`.

### A1 — `po-state-schema.md` (local `packages/core/po/sections/_formats/` + global `~/.productune/sections/_formats/` mirror)
- `past_tickets[]` bullet: H1 turn-start purge rule + "MUST NOT be written in v2"
- `recent_turns[]` bullet: "rolling 10" → "rolling 5" + H2 trim rule + Version close reset note
- `pending_gate?` bullet: H3 stale rule appended (auto-clear if phase advanced; surface if 7d stale + same phase)
- `## Legacy + access patterns`: remove compat language for past_tickets (compat period ended)
- `## Size budget` section added at end (table: cap / hygiene rule / notes per field)

### A2 — `po-loop.md` (local `packages/core/po/sections/` + global `~/.productune/sections/` mirror)
- Step 1.1 block inserted after Step 1 Memory, before Step 1b pending_promotions drain
- Block contains: H1 jq one-liner, H2 jq one-liner, H3 LLM-driven check with auto-clear and surface branches

### A3 — `lifecycle.md` (local `packages/core/po/sections/` + global `~/.productune/sections/` mirror)
- `## Compaction + cleanup` section: append `recent_turns[]` Version-close reset note

### A4 — One-time backfill (productune `.productune/po-state.json`)
```bash
STATE=".productune/po-state.json"
jq '.past_tickets = []' "$STATE" > /tmp/ps.tmp && mv /tmp/ps.tmp "$STATE"
jq '.recent_turns |= .[-5:]' "$STATE" > /tmp/ps.tmp && mv /tmp/ps.tmp "$STATE"
```
Expected: `past_tickets = []`, `recent_turns` trimmed to 5 entries.

`pending_gate` (13d stale, `from_phase == current_phase == 3`): **do not touch** — PO surfaces
to user per H3 on the first turn after this ticket ships.

`pnpm -F core build` exits 0.
