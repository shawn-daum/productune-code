## Request

> "설정에 있는 mcp서버를 팀에 스킬 아래에 배치해주자." — user (2026-05-19)

**현 위치:** `SettingsView.tsx` → tab `mcp` → `openTab('mcp-servers', 'mcp-servers', ...)` → `McpServersTab` (main pane 전체 화면 탭).

**이동 목적:** Settings 패널은 탐색 depth가 깊어 자주 열지 않게 됨. MCP 서버는 AI 팀원(페르소나)들이 런타임에 사용하는 외부 도구이므로 팀 컨텍스트(TeamPanel) 안에 배치하는 것이 자연스러움 — 페르소나·스킬 바로 아래에서 "팀이 쓰는 도구"로 그룹화.

**Designer plan:** `docs/design/T-P4-130/plan.md`

## Acceptance

- [ ] **A1 — TeamPanel MCP 섹션**: `TeamPanel.tsx` 에 스킬 nav row 아래, 위키/메모리 섹션 위에 "MCP 서버" 섹션 추가. 기존 `<Section>` 패턴 (collapse 버튼 + `localStorage` 상태 유지) 동일하게 적용.
- [ ] **A2 — 서버 목록 렌더링**: 섹션 내부에 `mcpGetServers` IPC로 로드한 서버 목록 표시. 행 레이아웃 = `serverName` (left) + `StatusBadge` (right). TeamPanel row 높이(28px) + 폰트 스타일(`personaRowStyle` 참고) 준수.
- [ ] **A3 — 클릭 시 modal**: 서버 행 클릭 → `McpServerModal` (기존 컴포넌트 재사용, props 동일). 모달 동작(Esc / backdrop click / 저장 토스트) 변경 없음.
- [ ] **A4 — 로딩 / 빈 상태**: loading 중 → 기존 `◌ 확인 중` muted 텍스트. 서버 0개 → "MCP 서버 없음" 1줄 muted. (main pane 탭의 emptyWrap 대형 UI는 team panel 사이드바에 부적합 — 단순 텍스트로 대체.)
- [ ] **A5 — Settings MCP tab 유지**: `SettingsView.tsx` 의 `mcp` sub-tab 제거하지 않음 (plan §3 "유지" 결정). 두 경로 병행 동작.
- [ ] **A6 — i18n 신규 키**: 팀 패널 섹션 헤더 + 빈 상태 텍스트 신규 i18n 키를 ko.json / en.json 양쪽에 추가.
  - `workspace.team.section.mcpServers` (ko: `"MCP 서버"`, en: `"MCP Servers"`)
  - `workspace.team.mcp.empty` (ko: `"연결된 MCP 서버 없음"`, en: `"No MCP servers configured"`)
- [ ] **A7 — collapse 상태 `localStorage`**: storageKey = `"mcp"` → `workspace.team.collapsed.mcp` 로 저장 (기존 `Section` 컴포넌트 storageKey 패턴 그대로).
- [ ] **A8 — McpServersTab 내부 변경 없음**: 기존 main pane 탭 경로(`mcp-servers` tab type) 는 그대로 유지. `McpServersTab.tsx` 파일 자체 수정 없음 — TeamPanel 에서는 로직만 인라인 재사용(IPC call + modal mount).
