# T-P4-077: BackgroundTaskMonitor sub-agent spawn 감지 fix — Bash + claude --agent 패턴

## Background

T-P4-068 (BackgroundTaskMonitor) 가 land 됐지만 사용자 dogfood (2026-05-08) 결과 BackgroundTaskMonitor 가 영영 동작 X — StatusBar segment 회색 idle / PresenceBar dot 회색 (T-P4-076 land 후에도 동일). PO 에 sub-agent 동시 dispatch 시켜도 segment / dot 변화 없음. 단 PO 답변에는 sub-agent 결과 정상 합산 → sub-agent dispatch 자체는 동작.

**Root cause** — T-P4-068 acceptance §F 가 잘못된 가정 위에 설계됨:

- 기존 가정: PO 가 stream-json envelope 으로 `assistant.tool_use` (`name === 'Task'`, `input.subagent_type` 추출) 를 흘린다
- 실제 PO doctrine (`~/.productune/po-instructions.md:8 + 29 + 93`): **"Never built-in `Agent` tool"** — PO 는 Task/Agent tool 절대 안 쓰고, **Bash 으로 `claude --agent pdt-<persona>` 자식 프로세스 spawn**
- 따라서 PO envelope 에 `tool_use.name === 'Task'` 가 영영 안 옴 — `name === 'Bash'` + `input.command` 안에 `claude --agent pdt-XXX` 문자열만 흐름
- 현 `po-runner.ts:414` 의 `if (part.name === 'Task' && ...)` 분기 영영 false → `cb.onBackgroundTaskStart` fire 0회 → store 빈 채

**T-P4-076 (PresenceBar derive) 와의 관계** — T-P4-076 자체는 정상 land. store 가 채워지기만 하면 working/done transition 정확히 동작. 본 ticket fix 후 즉시 효력 발휘. T-P4-076 reopen 불필요.

**T-P4-068 reopen 여부** — 다른 acceptance (§A height / §B segment / §C popup / §D fade / §E badge / §G i18n / §H 회귀 / §I 검증) 모두 정상 land. §F (parser hook) 만 가정 오류. 깔끔하게 forward fix — T-P4-068 frontmatter 는 done 유지.
