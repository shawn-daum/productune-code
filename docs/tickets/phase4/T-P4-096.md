# T-P4-096: UserMode default → planner + i18n parity (Settings General tab)

> UserMode store / onboarding 초기값을 null → planner 로 변경. Settings General 탭에서 i18n key 누락으로 UserMode 섹션이 raw key 노출 중 — en/ko 양쪽에 `settings.general.userMode.*` + `settings.tabGeneral` 추가.

## §1 Background

사용자 dogfood (2026-05-12):

1. **Settings → General 탭에 i18n code(raw key)만 보임** — `GeneralSettings.tsx` 는 `settings.general.userMode.*` 키를 참조하지만 `en.json` / `ko.json` 에 해당 트리가 없어 `t('settings.general.userMode.title')` 등이 key string 그대로 노출.
2. **UserMode 기본값이 없음(null)** — 신규 설치 시 onboarding Step0_5 에서 아무 카드도 선택되지 않은 상태로 시작. UX 원칙 §1.5.2 Familiar 위반 — 사용자가 아무 것도 하지 않으면 계속 버튼이 비활성 상태이고, planner 가 default 임이 암시되지 않음.

**별도 skip:** Settings > MCP / Hooks / Environment / Models 서브섹션은 T-P4-048 / T-P4-084 spec 에만 정의된 상태로 본 ticket 범위 밖 — 별도 follow-up ticket.

## §2 Scope

### Sub-area A — UserMode store initial state

**파일**: `packages/gui/src/store/useUserMode.ts`, line 14

```ts
// Before
mode: null,

// After
mode: 'planner',
```

`loadFromSettings()` 는 IPC 에서 읽은 값으로 덮어쓰기 때문에 기존 사용자 설정은 영향 없음. IPC 미연결(browser dev mode) 시에만 store default 가 표시됨 — catch 블록은 `// IPC unavailable — keep null` 주석 → `// IPC unavailable — keep default` 로 갱신.

### Sub-area B — Onboarding Step0_5 초기 선택

**파일**: `packages/gui/src/components/onboarding/Step0_5UserMode.tsx`, line 15

```tsx
// Before
const [selected, setSelected] = useState<UserMode>(null)

// After
const [selected, setSelected] = useState<UserMode>('planner')
```

- Planner 카드가 pre-selected 상태(주황 border + 배경)로 화면에 진입.
- "Continue" 버튼이 즉시 활성화(사용자가 아무 것도 안 해도 진행 가능).
- Skip 버튼은 유지 — 누르면 `setMode(null)` 호출. 사용자가 원하면 Developer 카드로 변경 후 Continue 가능.

## §3 Acceptance

- **A1 (store default)**: GUI 첫 렌더(IPC 연결 전) 시 `useUserMode.getState().mode === 'planner'`. 기존 사용자(`api.getUserMode()` 반환값 있음) 의 경우 `loadFromSettings` 호출 후 기존 값 유지.
- **A2 (onboarding pre-select)**: `Step0_5UserMode` 마운트 시 Planner 카드에 orange border + `#1E1108` background + radio filled. "Continue" 버튼 `opacity: 1`, `pointer-events: auto`.
- **A3 (i18n render)**: Settings → General 탭에서 `settings.general.userMode.title` 위치에 "User Mode" (EN) / "사용자 모드" (KO) 렌더. raw key string 노출 X.
- **A4 (tabGeneral)**: Settings sidebar 탭 라벨이 "General" (EN) / "일반" (KO). 현재 `{ defaultValue: '일반' }` fallback 은 i18n key land 후에도 동작 유지.
- **A5 (protected token)**: `pnpm run check-locale-protected` (T-P4-057 linter) pass. ko.json 에 `Developer`, `Planner`, `Unset` 가 한글로 번역되지 않음.
- **A6 (build)**: `pnpm -r build` + TypeScript check pass. 기존 테스트 회귀 없음.

## §6 DS / UX 점검 (§1.5)

- **Few Things**: 변경 범위 최소 — 2 TS 라인 + 2 JSON 트리. 사용자에게 노출되는 차이: onboarding Planner pre-select + Settings General 탭 텍스트 정상화.
- **Familiar**: Planner pre-select 는 "권장(recommended)" 패턴 (onboarding Step1/Step3 의 기본 선택과 동일 관례). 사용자는 이미 pre-select = 추천이라는 mental model 보유.
- **Predictability**: 동일 환경으로 onboarding 진입 → 항상 Planner pre-selected. 비결정적 초기 상태(null) 제거.
- **Feedback**: raw i18n key 노출(현행) → 사람이 읽을 수 있는 텍스트(개선). §1.5.4 violation 해소.
- **Escape**: Planner pre-select 는 강제가 아님 — Skip(null) / Developer 선택 모두 열려 있음.
