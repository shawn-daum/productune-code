## Acceptance

### A) tooltip max-height + scroll

- [ ] `PersonaPresenceBar.tsx` 의 `barTooltipStyle` 에 추가:
  - `maxHeight: 160` (4~5 row 한계 후 scroll)
  - `overflowY: 'auto'`
  - 기존 `maxWidth: 360`, `whiteSpace: 'pre-line'`, `zIndex: 200`, root anchor (PresenceBar 위쪽 중앙) 유지
- [ ] tooltip 의 padding 적정 — row 가 깔끔히 보이게

### B) done transition 의 batch-scope artifact

- [ ] `PersonaPresenceBar.tsx` 의 `usePersonaPresenceDerive` 의 done 분기 의 doneTasks 추출 logic 변경:
  - 기존: `tasks.filter(t => t.persona === p && (status===done || error) && !processedDoneIds.has(t.id))` — store 누적 task 중 unprocessed 전체
  - 변경: **이번 working → done transition batch 의 task 만** 추적. 즉 working 중 running 상태였던 task id 집합을 ref 로 track → done transition 시 그 batch 의 task description 만 join.
- [ ] 구현:
  - 신규 ref: `currentRunningIds: useRef<Record<BackgroundTaskPersona, Set<string>>>`
  - working 분기 (runningCount >= 1) — 현 running task 들의 id 를 `currentRunningIds.current[p]` 에 add
  - done 분기 (prevCount >= 1 && runningCount === 0) — `currentRunningIds.current[p]` 의 id 들 중 현 tasks 에서 done/error 상태인 것만 description 추출 → join → setPersonaState. 그 후 `currentRunningIds.current[p] = new Set()` 로 reset (다음 batch 준비)
- [ ] `processedDoneIds` ref 는 deprecated — batch-scope 로 충분. (또는 이중 안전망으로 유지해도 OK — dev 판단)
- [ ] 회귀: single batch 정합 (1 task 또는 N task 모두 batch 단위 표시). 새 dispatch 시 이전 batch 안 보임.
