# T-P4-010: `productune init` — developer/planner 분기 + `.productune/config.json` 생성

**Round**: phase4-r1  **Stage**: impl  **Status**: todo  **Assignee**: pdt-developer

> planner/developer mode를 결정하는 init flow. GUI와 CLI 양쪽에서 호출 가능한 core 함수로 구현.

## Request

### 1. `packages/core/src/init.ts`
- `initProject(opts: { slug: string; mode: 'planner' | 'developer'; projectDir: string })` 함수
- 작업: `projectDir/.productune/config.json` 생성 (mode, slug, created_at, version)
- `projectDir/.productune/` 디렉터리 없으면 자동 생성
- 이미 존재하면 config 읽어서 merge (mode toggle 지원)

### 2. `packages/core/src/index.ts` re-export
- `initProject` export 추가

### 3. IPC 채널 (`packages/gui/electron/main.ts`)
- `ipcMain.handle('init:project', (_, opts) => initProject(opts))`

### 4. `packages/gui/electron/preload.ts`
- `api.initProject(opts)` 노출

## Acceptance
- [ ] `initProject()` 호출 시 `.productune/config.json` 생성됨
- [ ] config 포함 필드: `slug`, `mode`, `created_at`, `version: "0.4.0"`
- [ ] 이미 존재하면 mode만 업데이트 (다른 필드 보존)
- [ ] IPC 채널 `init:project` 동작
- [ ] renderer에서 `window.api.initProject(opts)` 호출 가능
