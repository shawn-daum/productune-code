# T-P4-010: `productune init` — slug + `.productune/config.json` 생성 + `project:installAt` IPC

**Round**: phase4-r1  **Stage**: impl  **Status**: done  **Assignee**: pdt-developer

> 새 프로젝트 init flow. GUI 와 CLI 양쪽에서 호출 가능한 core 함수로 구현. 단일 모드 — mode 필드/분기 없음.

## Request

### 1. `packages/core/src/init.ts`
- `initProject(opts: { slug: string; projectDir: string })` 함수
- 작업: `projectDir/.productune/config.json` 생성 (slug, created_at, version)
- `projectDir/.productune/` 디렉터리 없으면 자동 생성
- 이미 존재하면 config 읽어서 merge (slug 보존, created_at 보존)

### 2. `packages/core/src/index.ts` re-export
- `initProject` export 추가

### 3. IPC 채널 (`packages/gui/electron/main.ts`)
- `ipcMain.handle('init:project', (_, opts) => initProject(opts))`
- `ipcMain.handle('project:installAt', (_, { projectDir }) => initProject({ slug: path.basename(projectDir), projectDir }))` — 기존 폴더에 직접 init

### 4. `packages/gui/electron/preload.ts`
- `api.initProject(opts)` 노출
- `api.installAt(projectDir)` 노출

## Acceptance
- [ ] `initProject()` 호출 시 `.productune/config.json` 생성됨
- [ ] config 포함 필드: `slug`, `created_at`, `version: "0.4.0"` (mode 필드 없음)
- [ ] 이미 존재하면 slug/created_at 보존 (다른 필드 보존)
- [ ] IPC 채널 `init:project` 동작
- [ ] IPC 채널 `project:installAt` 동작 — 선택한 폴더에 직접 init
- [ ] renderer 에서 `window.api.initProject(opts)` 및 `window.api.installAt(dir)` 호출 가능
