## Request

> "skill matrix에 반영한 번역 tickets tab이나 버전 히스토리 탭에도 적용해줘." — user (2026-05-18)

Apply the T-P4-123 ⓘ-button + expand-on-demand popover UX pattern to truncated text
fields in the Version History and Version Detail tabs.

**Designer decisions:**
- **i18n translation layer**: does NOT apply — ticket titles, activity results, promo deltas
  are user-authored content. No static key mapping or Google Translate fallback.
- **Shared component extraction**: extract `InfoPopover` from SkillMatrixTab's inline code
  to `components/shared/InfoPopover.tsx`. Refactor SkillMatrixTab to use it.
- **Tickets kanban tab (TicketDashboardView)**: SKIP — titles wrap freely, no info hidden.

## Inputs

- Plan: `docs/design/T-P4-128/plan.md`

### New file

`packages/gui/src/components/shared/InfoPopover.tsx`

Props: `{ text: string; threshold?: number; ariaLabel?: string }`

- `threshold` default: `50` (no button if `text.length <= threshold`)
- Local `open` + `pos` state — no parent state needed
- Same positioning logic as SkillMatrix: viewport collision detection (flip-right / flip-above)
- Same ⓘ button style (`infoBtnStyle`) as SkillMatrix — see plan §6
- Esc key + outside-click close via `useEffect` (runs when `open === true`)
- `role="tooltip"` on popover, `aria-expanded` on button
- `aria-label` fallback: `t('workspace.common.viewFullText')`

### SkillMatrixTab refactor

Remove inline popover state/logic (currently ~55 lines):
- States: `openSkillId`, `popoverPos`
- Ref: `popoverRef`
- Function: `handleInfoClick`
- `useEffect` for Esc/outside (lines 78–100)
- Popover JSX block (lines 262–287)

Replace in-row `<button>` + popup with `<InfoPopover text={...} />`:
```tsx
<InfoPopover
  text={t(`skills.descriptions.${skillIdToI18nKey(skill.id)}`, { defaultValue: skill.description })}
/>
```

### VersionHistoryView — apply to TicketCard

`activityResult` (currently `textOverflow:'ellipsis'`):

