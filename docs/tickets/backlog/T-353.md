## Request

**구조적 마찰 (shawn 기기에서 2026-07-14 하루 2회 발생)**: repo의 CLI/hook을 고쳐도 `~/.prdt` 미러(bin/hooks/discipline)가 구버전으로 남아, 수정이 "반영 안 된 것처럼" 보임.

- 사례 1: T-336 hook 신설 → GUI가 "install.sh 먼저 실행하세요" 안내. 사례 2: T-331 stage 프롬프트 제거 → 다른 폴더에서 여전히 stage를 물음 (미러된 `~/.prdt/bin/prdt`가 구버전).
- 방향 (설계 판단): dev 기기(PRDT_REPO가 살아있는 경우) 한정으로 —
  - (a) `prdt` 실행 시 repo 원본과 미러의 버전/해시 불일치 감지 → "미러가 구버전 — install.sh 재실행" 1줄 경고, 또는
  - (b) 자동 재미러(멱등·빠름), 또는
  - (c) dev 기기는 심링크 직결.
  - 배포 기기(repo 없음)는 현행 유지.

## Acceptance

- On a machine where PRDT_REPO points at a live repo, running a stale mirrored `prdt` either self-heals or clearly warns within the same invocation.
- No behavior change on machines without the repo.
- Covered by tests (stale mirror → warn/heal; fresh mirror → silent).
