## Request

**CLI 제안 (shawn, 2026-07-13)**: init 안 된 디렉토리에서 `prdt` 첫 실행 시, **하위 폴더 중에 이미 prdt 프로젝트가 있으면** 현재 위치를 워크스페이스(프로젝트 모음 폴더)로 판단하고, 확정된 slug 이름으로 **하위 폴더를 만들어 거기서 init 진행**.

- 동기: `~/dev/products` 같은 워크스페이스 루트에서 실수로 init하면 `.prdt`/`docs/`가 워크스페이스에 흩어짐. 하위에 prdt 프로젝트 존재 = "여긴 프로젝트 폴더가 아니다"라는 강한 신호.
- 방향 (설계에서 상세화): 자동 생성이 아니라 **확인 프롬프트 경유** — 감지 시 "여긴 워크스페이스 같아요. `./<slug>/`를 만들어 진행할까요?" → 예: slug 하위 폴더 생성 + 그 안에서 init / 아니오: 현재 위치에 기존대로 init (모노레포 루트가 진짜 프로젝트인 경우 대비).

## Acceptance

- Running `prdt` (uninitialized) in a directory whose subfolders contain at least one prdt project triggers a workspace prompt before init.
- Confirming creates `./<slug>/` (from the confirmed slug) and completes init inside it; declining falls back to the current in-place init unchanged.
- No behavior change when no subfolder contains a prdt project.
