## Request

v1.2 PRD(`docs/prd/PRD.md` §v1.2) 핵심 모듈: **메타 전용 git**을 `packages/core`(git-workflow)에 구현 — CLI·GUI가 같은 모듈을 호출해 parity 보장.

- two-git/one-worktree: 메타 repo = `.prdt/meta.git`(별도 git-dir, work-tree = 프로젝트 루트), allowlist만 추적
- allowlist는 `.prdt/config.json`에 저장 — 기본값 = PRD 경계 결정 1의 메타 경로
- 메타 auto-commit = 기존 §10 autosave 라이프사이클 신호 재사용 (`AutosaveChangeReason` 동일 beat, diff-empty skip, `naturalize` 메시지 재사용)
- 메타 히스토리 조회 API + 원격 backup opt-in용 remote add API (자동 push 없음)

## Acceptance

- Core exposes: meta repo init, allowlist-scoped auto-commit on existing autosave signals, history read, opt-in remote add.
- Meta changes never appear in the code repo's `git status`/diff; code files never appear in the meta repo.
- One logical change = one meta commit; empty diff = skip.
- Unit tests cover allowlist scoping and commit lifecycle (test-first where logic lives).
