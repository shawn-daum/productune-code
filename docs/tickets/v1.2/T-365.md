## Request

신규 프로젝트 init 시 메타 분리 기본 적용 + 코드 repo `.gitignore` 관리 블록 주입 (PRD 경계 결정 3).

- init: 코드 `.git` + 메타 `.prdt/meta.git` 함께 구성, allowlist config 기록
- `.gitignore`: `# >>> prdt meta (managed) >>>` … `# <<< prdt meta (managed) <<<` 마커 블록 — prdt는 마커 안쪽만 재작성, 사용자 라인 불가침
- allowlist 변경 시 다음 turn에 블록 idempotent 재동기화
- `.prdt/meta.git/` 자신과 파생물(`index.db` 등)은 양쪽 모두 gitignore

## Acceptance

- Fresh init produces both repos, injected managed block, and allowlist config with zero user git interaction.
- Managed block rewrite is idempotent and never touches lines outside the markers.
- Derived files and the meta git-dir are ignored by both repos.
