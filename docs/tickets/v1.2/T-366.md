## Request

기존 프로젝트 마이그레이션 경로 — CLI 명령 + GUI 진입점 (PRD 경계 결정 4).

- 절차: ① `.prdt/meta.git` 초기화 → ② 현재 메타 스냅샷 최초 커밋 → ③ 코드 repo `git rm --cached` 추적 제거 + `.gitignore` 관리 블록 주입 → ④ 양쪽 `git ls-files` 검증
- 히스토리 rewrite 없음 — (a) 추적 제거 only. rewrite는 범위 밖(명시적 opt-in, 자동화 금지)
- 이미 분리된 프로젝트 재실행 방지 · git 없는 프로젝트 미지원

## Acceptance

- Running migration on a mixed repo leaves `git ls-files` (code repo) meta-free and the meta repo tracking exactly the allowlist.
- Migration is refused/no-op on an already-split project.
- No force-push, no history rewrite anywhere in the automated path.
