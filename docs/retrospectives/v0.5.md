## Wins / Misses

### Wins — process

- **Discretionary gate 무조건부化 확립.** 194→211/212→215 3연속 재발이 결국 "doctrine 편집 default=grill" unconditional rule을 만들었다. 재량 게이트가 안 통하는 상황을 인정하고 rule로 박은 것이 중요한 메타 학습.
- **load-bearing 게이트 훅 2단 grill 패턴 확립.** plan-grill(설계 오류 사전) + post-impl-grill(구현 회귀 사후) — T-PATCH-237에서 설계 오류 2건(false-block)을 impl 전에 잡아 outage 예방. T-234에서 dev self-test 23/23 green인데도 GRILL이 2건 잡음.
- **팀 dmg 최초 배포 성공.** cua-VM clean-install + post-smoke 7/7로 배포 파이프라인이 실제 검증됐다.
- **IPC traversal 가드 패턴 정착.** T-014/016/098 3건 반복을 통해 "새 IPC fs 핸들러 = traversal/containment 가드 필수" 가 fail-patterns.md area-tag 2건으로 등록됨.
- **PLAN-GRILL 도입.** impl 착수 전 설계 단계 grill이 아키텍처 오류 제거에 실증됨 (T-PATCH-233/237).

### Wins — product

- 4-region IDE 셸 + PDS See layer 전 구현 완료 — 아티팩트·티켓·팔레트가 GUI 내 통합.
- 브랜드 chrome 정비 (persona hue-separation + Pretendard UI-text rule).
- OS notification + tray 기초 레이어 완성.
- doctrine 4-tier 재설계 — wiki 폐기 후 Tier0/1/2 구조 안정화.

### Misses — process

- **North star cycle 미실시.** 인프라 shipped 후 dogfood cycle 관찰을 v0.5 내에 실행하지 않았다. "dmg 막 배포 → 다음 기회" 결정이 반복 carried 패턴.
- **시각 smoke 사각지대.** playwright-electron이 mount + console error만 확인 → T-PATCH-095(5루프)의 구조적 원인. 자동화 미비 상태 지속.
- **blind-iterate 재발 다수.** Electron headless QA 불가 → dev self-verify + shawn hands-on 패턴이 패치 지연/strike 반복을 유발 (T-PATCH-066~075 등).
- **subagent envelope flaky 재발.** designer/qa subagent empty-return(0 tool) → fresh 재디스패치 패턴이 2~3차례 반복됨 (T-PATCH-232/233/234/235 등).
- **doctrine cap-breach trim debt 누적.** `phase2-3-ticket-sequence.md`(150/100) · `ux-principles.md`(108/100) · `design-review.md`(100/100) — dedicated trim 티켓 미발행으로 backlog 누적.

### Misses — product

- **T-PATCH-255 (TCC silent-fail) 이월.** PO 턴 tool 실패가 사용자 무안내 silent 종료 — 5차 dmg cua 재현 확정했으나 v0.5 내 미착수.
- **Round9 full-cycle dogfood 미실시.** v0.4에서 이월됐음에도 v0.5도 cycle 관찰 미달성 → v0.6 P1 재이월.
- **설정 round-trip 회귀 테스트 부재.** `loadSettings()` integrations silent-wipe 선례(T-PATCH-083) 이후 재발 방지 테스트 미작성 상태 지속.

## 반복 실패 모드 (fail-patterns 집약)

### F1: IPC path-traversal / containment 가드 누락
T-014(`artifacts:readFile`) · T-016(`tickets:read`) · T-PATCH-098(clipboard paste) 3건 — 확장자 whitelist만 있고 `startsWith(root)` 부재. 신규 IPC fs 핸들러마다 1차 FAIL 반복. area-tag `*/ipc-security` 2건 등록 (3번째 도달 시 `type:test` 트리거).

### F2: 시각 렌더 / smoke 사각지대
T-PATCH-095 (loops=5): sticky-scroll bleed → stale ancestor → depth-1 collapse 연쇄가 매 라운드 tsc clean + console 0을 통과. smoke가 시각 렌더를 미검증하는 구조적 원인. dev 임시 vite+chromium 스크린샷 하니스로만 수렴.

### F3: doctrine ghost-ref / cap breach
T-016: `pdt-persona-blink` CSS class ghost-ref (어떤 스타일시트에도 미정의 → silent no-op). T-PATCH-248(loops=3): artifact-lifecycle doctrine cap 154/100 → trim → 모델 통합 재author. trim debt 3파일 잔존.

### F4: load-bearing 게이트 훅 false-block / false-negative
T-PATCH-237: `---` 수평선을 frontmatter delimiter 오인(false-block 14줄). T-PATCH-234: `*/*` blanket 가드가 slash-bearing 값 Bash 채널만 통과(Write/Edit parity 깨짐). dev self-test green이어도 GRILL이 잡음 — 독립 GRILL 비협상.

### F5: "additive ≠ safe" grill-skip 재발 (3연속)
T-PATCH-194 → T-PATCH-211/212 → T-PATCH-215 — 매번 "순수 add"로 합리화해 GRILL skip → 각각 QA가 must-fix 발굴. 결론: discretionary gate 전폐, doctrine 편집 default=grill로 무조건부化.

### F6: TCC permission silent-fail (이월)
T-PATCH-255: macOS TCC(Downloads/Desktop/Documents) 거부 시 응답 텍스트 없이 silent 종료. 5차 dmg cua 재현 확정. v0.6 carry.

## Calibration anchors (다음 버전 반영)

1. **load-bearing 게이트 훅은 2단 grill 필수** — plan-grill(설계오류) + post-impl-grill(구현회귀). dev self-test matrix green 무관 (T-PATCH-233/234/237).
2. **doctrine 편집 default=grill, 예외 없음** — "순수 add" / "clarify 비례" 자기판단으로 skip 금지 (T-PATCH-194/211/212/215 패턴).
3. **시각/스크롤 산출물은 user-verify eyeball 또는 스크린샷 하니스** — smoke green≠pass (T-PATCH-095 5루프).
4. **신규 IPC fs 핸들러 = traversal/containment 가드 즉시** — 확장자 whitelist만으론 부족 (T-014/016/098).
5. **mass-edit 시 system awk/sed 금지** — BSD awk 한글 multibyte 손상(NUL 포함). UTF-8-safe Python 사용 (T-PATCH-233).
6. **migration completeness grep = 게이트 훅이 실제 쓰는 정규식과 동일** — col-0 vs 들여쓰기 불일치가 구조적 사각 (T-PATCH-233).
7. **subagent empty-return(0 tool) = 디스크 직검(ls/grep/git) 후 fresh 재디스패치** — 메시지 추적 불필요 (T-PATCH-232/233/234/235 패턴).
8. **배치에서 같은 파일 만지는 티켓은 한 dev 직렬화** — concurrent-edit 충돌 회피 (T-220/221/231 교훈).
9. **Tier 분류 논거 = "누가 실제로 그 Tier를 읽나" 먼저 확인** — "committed=공유" 오논거 (T-PATCH-232).
10. **activation 가정 확인** — 훅이 settings.json repo source 직참조 시 install.sh 재실행 불요·즉시 LIVE (T-PATCH-224 교훈).
