라우팅 의사코드

// resolve viewer by file extension
function resolveViewer(path) {
  const ext = extname(path);
  if (ext === ".md")   return "markdown";
  if (isMermaid(ext))   return "mermaid";  // reuse Phase-4
  if (ext === ".html") return "browser"; // <webview>
  return null; // → inline error state
}

단계 요약

  1. 좌측 산출물 tab 클릭 → 목록 전환
  2. 행 선택 → 확장자로 뷰어 라우팅
  3. 메인 패널 탭 open/focus (read-only)
