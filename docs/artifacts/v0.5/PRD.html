productune · v0.5 PRD

기획자 UX 1차 본격화

GUI 와 PO 가 backend↔frontend 기술 디테일을 흡수해, 계층화된 단순 정보 + 매 순간 명확한 다음 action 으로 전달한다.
● PRD ready · clarity A ≈ 0.04 3 트랙 · 14 항목 Phase 4 sub-cycle 작성 2026-06-01 · pdt-designer
v0.4 는 doctrine 아키텍처(4-tier 메모리 · 9 ticket type · 7 status)와 schema-driven GUI workspace 인프라를 검증했습니다. v0.5 는 "기획자 UX" 자체를 처음으로 1순위 목표로 삼는 사이클입니다. 정보를 flat 하게 다 던지지 않고, "지금 무엇을 해야 하는지"가 매 순간 보이는 형태로 바꿉니다. Phase 4 의 합격 정신("터미널을 한 번도 열지 않고 한 사이클 완주")을 한 단계 더 깊이 끌고 들어갑니다.

Why왜

기획자는 무엇을 만들지는 설명할 수 있지만 CLI 에 익숙하지 않고, 깊은 빌드·디버깅·아키텍처 지식은 없습니다. v0.4 까지 오케스트레이션 코어와 GUI 셸은 검증됐지만, 정보가 여전히 flat 하게 — 모든 게 한꺼번에 보이고, "다음에 이걸 하세요"라는 매 순간 신호는 없이 — 노출됐습니다. v0.5 는 그 간극을 메웁니다: 계층화된 정보 + 각 시점의 명확한 action. 사용자의 주의가 인터페이스나 그 밑의 기술 계층을 헤매는 데가 아니라 제품 의사결정에 쓰이게 합니다.

Who누가

마스터 PRD / Phase 4 와 동일 — 코드를 직접 짜지 않지만 무엇을 만들지 정의하는 기획자 / 1인 PM / 제품 오너. v0.5 는 특히 이 사용자가 예전엔 터미널로 내려가거나 raw 기술 산출물을 직접 읽어야 했던 순간들을 집중적으로 최적화합니다.
