회의록 자동 요약 도구

PRD · v1 · meeting-summarizer · R1 ready · authored by PO

Who

회의를 주최하고 후속 액션을 챙겨야 하는 1인 PM / 팀 리드. 녹취·노트는 있지만 정리할 시간이 없다.

회의가 끝나면 결정사항과 액션 아이템이 흩어진다. 다시 듣거나 노트를 뒤지는 데 매번 20–30분이 든다.

녹취/노트를 붙여 넣으면 결정 · 액션 · 미해결 질문 3섹션으로 자동 정리. 액션은 담당자·기한까지 추출한다.

P3 dev 핸드오프 — 공유 precondition 2종

클러스터 4건은 신규 배선 2개 위에 얹힌다. 4개 표면을 만들기 전에 이 둘을 먼저 깐다(PRD #9 In · 클러스터 노트 정합).

(i) 워커 subagent 상태/출력 → GUI 파이프 (#9 출력 · #10 상태)

po-runner 는 이미 subagent 이벤트를 인지한다(subagent-done presence 신호 · subagentCaptureByParentId). 다만 워커 라이브 출력은 PO 스트림 오염 방지를 위해 nested-event 필터로 막혀 GUI 로 흐르지 않는다.

  • 상태(#10): 위임 시작 → 해당 워커 setPersonaState(persona,'working',{task}), subagent-done → 'done'(2s)→idle. personaIdFromAgentType 매핑 재사용. PO 회귀(T-PATCH-252) 0.
  • 출력(#9): 활성 워커의 nested transcript 를 필터 통과시켜 read-only 라이브 텍스트로 presence store(또는 별 stream slice)에 파이프. PO 본문 채널과는 분리 유지.
  • 공유: backlog "PO Log Terminal 탭 미구현"(2026-06-16)과 동일 precondition. 그 배선이 있으면 재사용, 없으면 #9 가 먼저 깐다(또는 한 dev plan 으로 스코프). interactive shell 아님(node-pty 불요) — tail 표시만.

(ii) PO 라이프사이클 이벤트 → GUI 메인 패널 신호 (#11 레이아웃 · #14 오토-네비)

근본 원인: PO(백엔드)가 GUI 메인 패널 뷰를 직접 못 연다. version-open / PRD-ready 같은 lifecycle 이벤트를 GUI 가 구독해 레이아웃·네비를 구동하는 신호선이 필요하다.

  • 레이아웃(#11): poState.current_version + PRD 파일 유무 = derived predicate → chat-only ↔ full grid. WorkspaceShell 의 dynamicGrid 가 이미 grid-template 을 런타임 계산하므로 컬럼/area 세트를 조건부로 스왑(activity+welcome+chat ↔ activity+side+main+chat).
  • 오토-네비(#14): version-open/PRD-ready 이벤트 → openTab('prd:...', focus) + 해당 버전 진입. WorkspaceShell 의 기존 project-switch 오토-open 로직(pendingSwitchTabRef)과 정합 — 자동 + 수동 공존.
  • 1차 범위: version-open / PRD-ready 2개 이벤트만(모든 lifecycle 망라 아님). 수동 네비 경로 제거 안 함.

DS invariant: 신규 토큰 0 — 모든 색은 design-system.md §2 그대로(PO violet / designer orange / dev sky / qa emerald / warn amber). motion — persona-blink(§9.2) 재사용 + 탭 1회 진입은 banner-slide-in 톤 내. 단 1개 신규: 배너 CTA → ▶ Run 시선 유도용 nudge-pulse 링(1.4s, warn) — §9.2 "허용 4종 외" 이므로 P3 designer 리뷰 항목(또는 기존 focus-ring 으로 대체 가능). read-only 스트림 mono = --font-mono. reduced-motion 전부 정지. i18n 보호어(PRD/Design/Build/PO/persona slug) 영문 보존.
