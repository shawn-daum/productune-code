§1.3
왜 PRD가 카드 바로 아래인가 — 카드는 "이 버전이 무엇인가"(신원), PRD는 "무엇을 하려는가"(의도). 하나의 흐름으로 붙여 읽히게 한다. 아티팩트(결과물)는 그 다음, 가장 참조 빈도 낮은 .ENV(설정)는 맨 아래.
SCENE 2

프로젝트 히스토리 탭 — 타임라인 + 상세

아티팩트 탭 자리를 그대로 재사용(활동바 2번째 슬롯, 아이콘만 History로 교체). 사이드바 = 닫힌 버전 압축 타임라인, 클릭 시 메인 페인에 상세 탭. 진행 중 버전은 목록에 없다 — 대신 위에 옅은 안내行으로 "프로젝트 탭에서 보라"고 안내한다. 상세는 Outcome을 최상단에 둔다 — "이 버전, 그래서 성공했나"가 스크롤 없이 보이는 게 doctrine #7(user outcome over output)을 IA로 구현한 것.
