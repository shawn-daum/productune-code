§1

Principles

P1 — Token-driven

컴포넌트는 hex 가 아닌 semantic token (--surface-modal, --status-blocked) 만 참조한다. inline hex 는 마이그레이션 대상.

P2 — Monochrome 우선

neutral 그레이스케일이 베이스. accent / status / persona / stage / health 만 색을 가진다. 같은 화면에서 색 요소 4종 초과 금지.

P3 — Minimal motion

정보 변화 (loader, persona working blink) 외 장식 motion 금지. prefers-reduced-motion 에서 모두 비활성.

P4 — shadcn 패턴

Radix-style primitives + slot 합성. 현 단계 라이브러리화 X — 패턴·네이밍·구조 정합만 채택.

P5 — i18n 어휘 가드

한국어 모드에서도 보호어 enum (PRD, stage, slug) 은 영문 보존. T-P4-057 linter 강제.

P6 — Dark-only

light theme = Phase 5. 모든 hex 는 dark surface 기준. token 명은 테마 invariant — light 추가 시 hex 만 교체.
