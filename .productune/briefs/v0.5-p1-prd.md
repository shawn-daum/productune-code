## v0.5 Purpose (1 line)

기획자가 backend ↔ frontend 사이의 기술적 디테일을 직접 들여다보지 않아도, UI 와 PO 가 그걸 흡수해서 **계층화된 단순 정보 + 시점별 명확한 action** 으로 전달하는 GUI 본격화 단계.

> v0.4 = doctrine 검증 + GUI workspace schema-driven 인프라.
> v0.5 = 기획자 UX 1차 본격화 — flat 하게 다 던지지 않고 "지금 무엇을 해야 하는지" 가 매 순간 보이는 형태.
